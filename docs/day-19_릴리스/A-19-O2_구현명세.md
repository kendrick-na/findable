## 1. [P0] D19-3 — 미커밋 111파일 논리적 커밋 분할 계획

**원칙**: "한 커밋 = 한 목적". 111파일을 성격별로 묶어 순차 커밋. 컨벤셔널 커밋 규율 유지.

| 순서 | 커밋 묶음 | 대상(예) | 타입 | 선결 |
|------|-----------|----------|------|------|
| 1 | **sweep cron 단일화** | web·api sweep-stuck-jobs 이중구현 → 하나로 | `fix(cron)` | ⚠️**BL-Day17-01 먼저**(어느 앱 정본인지 결정) |
| 2 | 운영 cron 신규 | daily-ops-digest | `feat(cron)` | 1과 분리 |
| 3 | 개인정보 처리방침 정합 | legal/[slug]/page.tsx | `fix(legal)` | Day18 완료분 |
| 4 | 홈/랜딩 개선 | (home) 컴포넌트 11개 | `feat(home)` or `style(home)` | 실험분 제외 확인 |
| 5 | audit 개선 | audit 관련 12개 | `feat(audit)` | 완성분만 |

- **⚠️ 커밋 전 필수**: `git status`로 각 파일이 완성분인지 실험분인지 사용자 확인. 실험분은 stash 또는 제외.
- **⚠️ secret 점검**: `.env.local` 등 커밋되면 안 되는 것 gitignore 재확인([[feedback_api_key_no_chat_output]]).
- 각 커밋 후 `pnpm check` + 앱별 tsc.

## 2. [P1] D19-2 — 릴리스 노트 첫 도입 (`docs/_적용/릴리스노트.md`)

### 형식 (사용자·이해관계자向, 커밋메시지와 다름)
```
## [날짜] 릴리스 — <한 줄 요약>
### ✨ 새 기능
- (사용자가 체감하는 변화로 서술. "feat(audit): SoV 카드" → "진단 결과에 SoV를 매출로 환산해 보여줍니다")
### 🐛 개선·수정
- (버그·안정성)
### 🔒 내부·운영
- (사용자 비노출: cron·로그·리팩터)
### ⚠️ 마이그레이션/주의
- (스키마·env 변경 시)
```

### 이번 릴리스 노트 초안 (main..feature 13커밋 → 사용자 언어로 번역)

```markdown
## 2026-07-XX 릴리스 — 로그인 브랜딩 + 진단 신뢰도·안정성 강화

### ✨ 새 기능
- Findable 브랜드 로그인·회원가입 화면 (Clerk 커스텀 플로우)
- 대시보드 개선: 플랜별 권한 배지·요금제/잠금 UI
- 진단 결과에 'SoV→매출 환산' 카드와 경쟁사 벤치마크 카드 추가 (지불의사 시뮬)

### 🐛 개선·수정
- AI 진단이 백그라운드에서 영구 멈춤(stuck)되던 문제 방지 (queued 굳음 사각지대 보강)
- 진단 측정 파이프라인 결함 정합 (출처 오염·마크다운·엔진 수 표시 신뢰도)
- Perplexity 등 엔진 라우팅 안정화 (404 해결·공식 API 경로)

### 🔒 내부·운영
- 심층분석 haiku 모델 전환 + 유료/승인 파트너 게이트 (원가·마진 관리)
- 엔진 라우팅 다변화 (Letsur GPT·Claude + Google 무료 Gemini)

### ⚠️ 주의
- 스키마 변경 없음. env 신규: (해당 시 CREW·게이트 관련 확인)
```
- ⚠️ 위 초안은 커밋 메시지 기반 [AI 번역]. **실제 릴리스 시 사용자가 "정말 이게 사용자에게 나가는 변화인가" 검수** 후 확정.

## 3. [P1·문서] D19-1 — 릴리스 전략 (13커밋 어떻게 내보낼지)

### 안 A — 전량 머지 (feature → main 한 번에)
- 장점: 간단. 단점: 13커밋이 한 릴리스라 문제 시 원인 추적·부분 롤백 어려움. Vercel이 즉시 전량 배포(D16-1).
- 적합 조건: 13커밋이 모두 검증됐고 서로 의존적일 때.

### 안 B — 안정분 우선 릴리스 (권장)
- 이미 검증된 안정분(stuck 가드·측정 정합·로그인)만 먼저 main으로, 실험적/미검증분(원가전략·게이트 조정 등)은 feature에 남김.
- 장점: 릴리스 단위 축소 → 문제 격리 쉬움. 단점: cherry-pick 수고.

### 공통 — 롤백 계획 (D19-4)
- 머지 직후 www.findable.co.kr 스모크: `curl -sI https://www.findable.co.kr/ko`(200)·`/audit`·로그인·결제 진입.
- 문제 시 **Vercel Instant Rollback**(런북 §1). 릴리스 노트에 "이 릴리스 = 커밋 X~Y" 기록해 롤백 대상 특정.
