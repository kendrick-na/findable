### 1-e. ✅ 부분가림 방식 확정 — **Peec `f041` 3겹 방식** (👤 2026-08-15)

`[확인사실]` **4곳 중 데이터를 가리는 곳은 Peec 하나뿐이다.** 나머지 3곳은 다 보여주고 배너로만 판다.
⛔ **Scrunch는 가림이 아니라 하드 게이트** — $250/월 **카드 강제**. (마케팅엔 `No credit card required`라 써놓고 모순)

#### Peec이 한 화면에 쓰는 3겹

| 기법 | 대상 | 효과 |
|---|---|---|
| **① 진짜 블러**(Gaussian) | Sentiment·Position **열** | 숫자는 못 읽지만 ⭐**초록 색조가 남아 "긍정"은 전달**된다 |
| **② 그라데이션 페이드** | 5행 아래 | "더 있다"는 암시(밝기 실측 30→164→244) |
| **③ 선명 유지** | 순위 · **한국어 브랜드명** · Visibility `0%` | ⭐**"내 경쟁사가 진짜 보인다"** |

⭐ **핵심은 ③이다.** 지표 하나를 **완전히 읽히게** 둬서 *"이 제품이 진짜 돌아간다"* 를 증명한 뒤에 가린다.
한국어 브랜드명이 선명해서 **"내 얘기구나"가 먼저** 오고 가림이 나중에 온다.

#### 우리 적용

| 조각 | 처리 |
|---|---|
| **순위 충격**(`#51 우리`) · 점수 | 🟢 **선명** — "진짜 돈다"는 증거 |
| 진실의 거울 · 처방 · 네이버 격차 | 🟢 **선명** |
| **추세 그래프** | 🔵 **블러+페이드** — 모양은 보이되 값은 안 읽힘 |
| **경쟁사 벤치마크** | 🔵 **블러** — 브랜드명 선명, 수치만 가림 |
| **재측정** | 🔒 자물쇠 |
| **코파일럿 챗** | 🟢 **선명 + 3회 제한** |

**코파일럿 챗 = 횟수 제한**: 호출당 원가가 나가지만 막으면 핵심 체험이 사라진다.
📕 근거: *"가치를 보는 데 로그인을 요구하지 말고, **비싼 엔진을 소모하는 데** 요구하라"*(§1-c) · Semrush 3회/일.

⛔ **`(예시)`·`Sample` 라벨 금지** — Peec은 **진짜 데이터에 `Sample`이라 써서 스스로 신뢰를 깎는다.**
우리 데이터는 진짜다 → 진짜라고 말한다.

## 4. 🅱️ 기능 기획 — 탭 8개

### 4-a. ⭐ 공통 자산 — 지표 사전 (최우선)

🔴 **탭보다 먼저 만든다.** 탭 8개면 지표가 8화면으로 퍼지고, 사전 없이 하면 **같은 지표를 8곳에서 각자 설명**하게 된다.
이 저장소가 **세 번 겪은 사고**다(N-14 분모부재 → N-28 `7/6곳·117%` → N-30 `95% vs 7곳`).

⭐ **실물 근거 = Scrunch f062** — 우리가 설계만 해둔 구조가 경쟁사에 구현돼 있다:

```
Citation Mention Rate
Share of cited URLs where the entity is mentioned in the cited page's content.
Format     Percentage
Direction  Higher is better
```

```ts
// packages/audit/metric-dictionary.ts (신설)
export interface MetricMeta {
  label: string;        // "우리를 아는 AI"
  question: string;     // "AI가 우리를 아나?"        ← 카드 제목(질문형)
  description: string;  // 평문 한 줄 — 🔴 항상 표시(툴팁 아님)
  format: "percent" | "count" | "rank" | "score";
  direction: "higher" | "lower";
  denominator?: string; // "AI 7곳 중"
}
```

🔴 **읽는 코드 없는 필드를 만들지 않는다** → **같은 커밋에서 실제 화면에 연결**한다.
