## 무엇을 만들었나 (비교 화면 `/compare` 아래, Growth 이상)
| 기능 | 내용 |
|---|---|
| 답변 분석하기 | 최근 측정의 AI 답변(저장된 앞 1,500자)에서 브랜드 이름을 AI로 뽑아 `AnswerBrand` 표에 저장. 한 번에 최대 60답변, 점수·측정 결과 불변 |
| 함께 나온 브랜드 | 표·문장 나열까지 센 목록. 별칭 합침, 자사(이름·별칭·도메인 줄기)는 제외, 등록 경쟁사 표시 |
| 빈 질문 | 우리가 한 번도 안 나오고 다른 브랜드만 나온 질문 |
| 출처 빈틈 | 우리가 빠진 답변에서만 인용된 사이트 + 유형(블로그·커뮤니티·쇼핑·언론 등, 규칙 분류) + 할 일 한 줄 |
| CSV | `/api/export/gap.csv?brand=<id>` (유료, 브랜드 소유 확인) |
