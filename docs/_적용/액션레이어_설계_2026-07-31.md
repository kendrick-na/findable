## 1. ⭐ 근거 — Princeton GEO 논문 (arXiv 2311.09735, KDD 2024)

Princeton·IIT Delhi·Allen AI. GEO-BENCH 1만 쿼리, GPT-3.5-turbo, 5개 시드 평균.
**이 수치가 액션 레이어의 유일한 1차 근거다. 코드에서 인용할 때 반드시 이 표를 참조.**

### Table 1 — 방법별 절대 성능 (베이스라인 = 19.3)
| 방법 | Position-Adj. Word Count | Subjective Impression |
|---|---|---|
| **Quotation Addition (인용문 추가)** | **27.2** | **24.7** ← 1위 |
| Statistics Addition (통계 추가) | 25.2 | 23.7 |
| Fluency Optimization (문장 유려화) | 24.7 | 21.9 |
| Cite Sources (출처 인용) | 24.6 | 21.9 |
| Technical Terms | 22.7 | 21.4 |
| Easy-to-Understand | 22.0 | 20.5 |
| Authoritative | 21.3 | 22.9 |
| **─ 베이스라인 ─** | **19.3** | **19.3** |
| Unique Words | 20.5 | 20.4 ← 효과 미미 |
| **Keyword Stuffing** | **17.7** | 20.2 ← **베이스라인 이하** |

원문: *"The best methods improve upon baseline by 41% and 28% on Position-Adjusted Word Count and
Subjective Impression respectively."* / *"we evaluate keyword stuffing... we find such methods offer
little to no improvement on generative engine's responses."*

### Table 2 — 🎯 순위별 상대 개선율 (%) — **가장 전략적인 발견**
| 방법 | Rank-1 | Rank-2 | Rank-4 | Rank-5 |
|---|---|---|---|---|
| Cite Sources | **−30.3** | 2.5 | 15.5 | **+115.1** |
| Quotation Addition | −22.9 | −7.0 | 25.1 | **+99.7** |
| Statistics Addition | −20.6 | −3.9 | 10.0 | **+97.9** |

**1위 사이트는 GEO 적용 시 오히려 −30%, 하위는 +115%.**
원문: *"GEO is especially helpful for lower ranked websites."*
→ **후발주자·중소 브랜드용 무기라는 저자 결론.** Findable 고객군과 정확히 일치.
→ 경쟁사 중 이걸 액션에 반영한 곳 **0곳**.

### Table 4 — 실제 적용 예시 (원문 인용)
- Cite Sources: *"(According to a survey conducted by The International Chocolate Consumption Research Group [1])"*
  한 문장 추가 → **+132.4%**
- Statistics: *"with a staggering 70% increase in robotic involvement in the last decade"* → **+65.5%**

### Table 3 — 업종별 최적 전략 (같은 액션도 업종 따라 다름)
Authoritative→Debate/History/Science · Cite Sources→Statement/Facts/Law&Gov ·
Statistics→Law&Gov/Debate/Opinion · Quotation→People&Society/Explanation/History

### Table 5 — Perplexity 실전 검증
베이스라인 24.1 → Quotation 29.1 / Statistics 26.2 / **Keyword Stuffing 21.9(하락)**.
조합 최적 = Fluency+Statistics(평균 31.4%).

## 6. 설계 원칙 (필수)
1. **LLM 처방은 반드시 우리 DB의 실제 레코드에 grounding**하고 **근거 URL을 붙인다.**
   자유 생성 금지 — 할루시네이션은 GEO 툴 공통 신뢰 리스크.
2. **업종별로 달라져야 한다**(Table 3).
3. **효과 없는 액션은 "하지 마라"고 명시**한다(키워드 스터핑·llms.txt). 차별화 포인트.
4. 상관 근거는 **인과로 단정하지 않는다**(Ahrefs 0.664는 상관).
