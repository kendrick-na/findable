## 1. 확인된 결함 — 전부 실데이터로 입증됨

### D1. 프롬프트에 맥락이 없다 (동명이인 근본원인)
`packages/audit/runner.ts` `generateAuditPrompts()`가 **브랜드명만** 사용:
```
기아 추천해줘 / 기아의 장단점은? / What is 기아? Is it worth buying?
```
업종·도메인(kia.com)이 들어가지 않는다. **실증**: kia.com 측정에서 ChatGPT가
"무슨 의미의 기아를 원하시는지"(자동차/타이거즈/주식)를 되물었다. AI 잘못이 아니라 질문이 모호한 것.

### D2. 언급 판정 = 단순 부분 문자열 포함 검사
`packages/ai/lib/engines/utils.ts` `detectBrandMention()` = `text.toLowerCase().indexOf(brand)`.
**실증(kia.com, 28응답 전수)**:
| 잡힌 문자열 | 실제 정체 |
|---|---|
| "푸에기아, 아무아쥬" | 향수 브랜드 (부분 문자열 오탐) |
| "기아 타이거즈" | 야구단 |
| "기아자동차" | 정상 |

→ **28/28 전부 `brandMentioned=true`**, 화면은 팩트정합률 100%.

### D3. "팩트정합률"이 사실 검증을 하지 않는다
`apps/web/.../truth-mirror.tsx:12` 주석에 명시 — 실제로는 `언급 엔진 / 측정 엔진` 비율.
이름이 기능을 오해하게 만든다(사실 검증으로 읽힘).

### D4. 무명 브랜드 고득점 — 산식 구조 문제
`packages/audit/geo-score.ts` 실측 산식:
- sentiment 40점 중 **전부 중립이어도 30점 자동 지급**(기준선 0.75)
- recognition 20점 = D2의 문자열 매칭 기반
- SoV 분모 = "언급된 응답 / 전체 응답" → **경쟁사와 비교하는 분모가 없음**

**실증(라이브 DB SoV)**:
| 브랜드 | SoV | 정체 |
|---|---|---|
| 기아·현대 | 100 | 대기업 |
| 나이키 | 97 | 대기업 |
| **윈디플로** | **96** | 무명 |
| **forget.sh** | **89** | 무명 |
| **5throck** | **86** | 무명 GitHub 페이지 |
| Tesla | 69 | 대기업 |

`forget.sh` 응답 원문 확인 결과 **4개 엔진 전부 브랜드를 모름** — Claude는 BTS 노래,
Perplexity는 **영어 단어 "forget"의 뜻풀이**를 답했는데 전부 "언급됨" 처리.

### D5. 인용 오염 — 검색 엔진이 SERP를 인용으로 승격
`packages/ai/lib/engines/korean-adapters.ts:252(naver)·348(daum)` — 검색 결과 상위 N건을
관련성 판단 없이 `citedSources`에 그대로 복사. **실증**: nvidia 측정에 "집 사기 후회", "Apple TV",
"PDF 압축 방법"이 인용으로 저장됨. 질의어("추천해줘")만 겹쳐도 인용 승격.
→ 관련성 규칙 검증 완료: nvidia 제외율 67%, nike 45%, 정상 인용은 전부 보존(§4 참조).

### D6. 측정 1회 = 표본 1 (비결정성 무대응)
프롬프트당 1회만 실행. AI 답변은 매 세션 달라지는데 분산 처리가 없다.

### D7. 무료 진단이 인증 없음 + 유료보다 풍부
- `/api/audit`은 **이메일 문자열만** 받고 실제 인증 없음(아무 값이나 통과)
- 무료(비로그인): 진실거울·경쟁사·매출임팩트·네이버갭·코파일럿 = **6개 섹션**
- 로그인 대시보드: KPI 4개 + 추세선 + 이력 = **더 빈약**

## 2. 경쟁사 벤치마크 — 측정 방법론 (12개사)

### 🎯 최대 발견: 동명이인 처리는 업계 전체의 공백
상용 툴 12곳 중 **실질적 해법을 공개한 곳 0곳**.

| 회사 | 언급 판정 방식 | 동명이인 대응 |
|---|---|---|
| **Ahrefs** | **"string matches"** (자기 문서로 인정) | alias 등록만, 경고 없음 |
| **Scrunch** | **"pattern matching"** (자인) | 문서에 언급 없음 |
| **daydream** | **"exact whole-word matching"** | 없음 |
| **Semrush** | "Unlike a simple text match" | **유일하게 주장**(Tesla 회사/과학자/공항 구분), 단 "proprietary"뿐 비공개 |
| Profound | "proprietary entity extraction" | 미공개 |
| Otterly·Peec | 미공개 | alias 등록만 |

**업계 관행 = "사용자가 별칭(alias) 직접 등록"** → 누락(FN)만 줄이고 **오탐(FP)은 전혀 못 줄이는 비대칭 처리.**
제외 키워드·업종 컨텍스트 검증을 제공하는 곳은 한 곳도 확인되지 않음.

**피해 실사례**: 어떤 스타트업이 "30 mentions / 600K audience"로 집계됐으나
실제 자사 지칭은 1~2건, 나머지는 **동명의 가상 캐릭터**(RankScience).

### 학술 진영에 실제 답이 있다
표준 3단계 = **멘션 탐지 → 후보 생성 → 순위화/판정**. 학계는 "이게 X인가?"를 LLM에 바로 묻지 않고
**반드시 후보를 먼저 좁힌다**.

ZELDA 벤치마크(EACL 2023) SLINKS-SHADOW("더 유명한 엔티티에 가려진" 난이도 셋):
- **MFS(최빈의미 매칭) 0.149** → 단순 매칭은 **85% 틀림**
- LUKE 파인튜닝(SOTA급) 0.225
- **순진한 LLM 호출도 답이 아님**: Vanilla GPT-3.5 zero-shot 0.746, Llama2 0.40
- **EntGPT**(후보생성+multiple-choice) 0.821→**0.920** (arXiv 2402.06738)

검증된 설계 원칙: ①후보 생성 필수 ②yes/no 대신 **multiple-choice + 엔티티 설명 동봉**
③**"None of the candidates"(NIL) 옵션** ④self-consistency 다수결
⑤**ARTER식 adaptive routing** — 모호한 것만 LLM 라우팅 시 토큰 58% 절감(EMNLP 2025).

### 반복 측정 — 수치 근거 확보
- **arXiv 2604.07585**(장크트갈렌): 표준오차가 **n=7에서 0.10 미만, n=8에서 0.08 미만**.
  같은 논문이 한계도 명시: *"브랜드 탐지가 고정 사전의 부분 문자열 매칭에 의존… 오탐 유발"*
- **Evertune**: 프롬프트당 **100회**. *"1회 = ±44 points, 100회 = ±10 points"*
- **daydream**: *"Twenty runs per prompt, because one run is a coin flip"* + Wilson 95% CI
- ⚠️ **수확체감**: 반복은 5회 부근에서 체감(6회차부터 분산 감소 0.0003).
  투자 우선순위 = **언어 > 모델 > 프롬프트 변형 > 반복**(arXiv 2607.13304)
- **Scrunch 자인**: *"단 한 번의 체크로는 일관되게 노출되는지 알 수 없다"*, *"단일 실행은 오해를 부를 수 있다"*

### 프롬프트 구성 — 브랜드명을 빼는 게 표준
- **Evertune**: 브랜드명 **의도적 제외** — *"excludes brand names to capture true unaided awareness"*
- **daydream**: 브랜드명 삽입 금지 — *"leading question and it contaminates the answer"*
- Semrush는 같은 현상을 **"phantom inclusion"**으로 경고
→ **업종 맥락은 프롬프트가 아니라 "사후 엔티티 검증"에 쓰는 것이 정답.**

### 분모 — 경쟁사 대비가 표준
- **Profound**(분모 명시 유일): 브랜드 포함 응답 ÷ **최소 1개 브랜드가 포함된 응답**
- **Otterly**(산식 5종 전부 공개): SoV = 내 언급 수 ÷ **전체 브랜드 언급 수** × 100,
  Brand Mentions는 **1/0 이진**(한 응답에 3번 나와도 1)
→ 둘 다 **"아무 브랜드도 안 나온 응답은 분모에서 제외"**. Findable의 "언급응답/전체응답"과 근본적으로 다름.
- 비판 근거: Dan Taylor의 **"숨은 분모"** 지적(searchengineland.com/ai-share-of-voice-metrics-that-matter-more-479611)

### 순위 표기 금지
Rand Fishkin: *"Any tool that gives a 'ranking position in AI' is full of baloney."*
단 전면 부정은 아님 — *"Visibility percentages across numerous prompts run dozens of times
actually does seem to be a reasonable metric"*.
SparkToro 원 연구: 자원자 600명·2,961회 실행, **동일 목록 재현 확률 1/100 미만**.

## 3. 경쟁사 벤치마크 — UX·정보구조

### 무료 체험: 업계는 "이메일 게이트"를 버리고 "시간 게이트"로 수렴
| 근거 | 실제 문구 |
|---|---|
| HubSpot AEO Grader | **"No Account Required"** — 계정·카드·이메일 불필요, **사용량 제한도 없음** |
| Semrush | **로그인 없이 1일 3회** |
| Geoptie | "No account, no credit card, no setup" |
| Rankscale | "free audit requires no registration" |

전환 논리 = **결과 감추기가 아니라 "시점 vs 추세"**.
Geoptie 결과 하단 원문: *"이건 **live snapshot**입니다. **시간에 따른** AI 가시성을 추적하려면 대시보드로."*
→ Findable은 Tracking·자동갱신 cron·플랜별 `autoRefreshHours`를 **이미 구현**했다. 업계가 파는 게 정확히 이것.
→ **결론: 로그인 강제는 역행. 어뷰징은 IP 레이트리밋으로 막고, 무료는 "1회 스냅샷"으로 제한.**

### 정보구조: 무료=단일 리포트 / 유료=6분할 (둘 다 맞음)
5개사 네비 라벨이 거의 동일 = **사실상 업계 표준 IA**:

| 표준 축 | Profound | Peec | Semrush | Ahrefs |
|---|---|---|---|---|
| 노출 | Visibility | Dashboard | Visibility | AI Visibility |
| 질문 | Prompt Volumes | Prompts | Questions | Prompts |
| 출처 | Citations | Sources | Narrative Drivers | Mentions |
| 경쟁 | Share of Voice | Competitors | Competitor Research | SoV |
| 감성 | Sentiment | Sentiment | Perception | Sentiment |
| **행동** | Opportunities | **Actions** | — | — |

→ Findable 현황: 개요·프롬프트(마법사)·**출처**(세션J)·**경쟁사**(세션J) 보유. **빠진 건 감성·액션.**

### 히어로 KPI는 딱 3개
Peec 공식 문서가 못박음 — `Visibility / Position / Sentiment`.
Surfer도 Visibility Score → Mention Rate → Average Position 순.
→ **현재 Findable 대시보드에 "평균 포지션"이 없다**(SoV·커버리지·측정횟수·마지막측정 = 운영지표 위주).

### 업계 1위 불만 = "압도적이다" / 2위 = "진단만 하고 처방 없음"
- Profound: *"운전은 환상적인데 **뭐 하는 건지 모를 버튼이 잔뜩 달린 고급차**"*(G2)
- Peec: *"조밀한 지표와 시각화가 신규 사용자를 압도"*
- *"세 플랫폼 모두 **문제를 진단하지만 고쳐주지 않는다**… 안 보인다는 걸 아는 건 1단계일 뿐"*
- 반대로 **칭찬받는 건 단순함**(Scrunch "명확히 분류된 리포트", Otterly "쓰기 쉬움")

### 🎯 액션 레이어 = 최대 기회 (Peec 산식 공개됨)
액션 레이어 보유 = Peec·Profound·AthenaHQ **3곳뿐**. Peec은 **전 플랜 무료**로 무기화:
```
Opportunity Score = 출처 사용빈도 × (경쟁사 노출 − 내 노출)
출처 4분류: owned / editorial / reference / UGC
```
→ 세션J에서 만든 출처 유형 분류(자사/커뮤니티/위키/언론)가 **Peec 4분류와 거의 일치**.
이미 가진 인용 데이터로 **즉시 계산 가능**.

### 기타 채택 후보
- **원문 답변 = 모달/사이드패널 + 브랜드 언급 하이라이트**(Semrush Full Response Modal 방식).
  진실거울이 이미 원문을 보여주므로 하이라이트+화살표 네비만 추가하면 업계 최상위.
- **경쟁사는 AI 답변에서 역추출해 제안**(Peec: *"We detect competitor brands mentioned in AI responses"*).
  세션J의 경쟁사 추출을 **필터가 아니라 제안 엔진으로 뒤집으면** 온보딩 마찰 감소.
- **빈 상태(empty state)는 업계 공백** — Semrush·Surfer 공식 KB 모두 미문서화.
  "1회 측정 완료 — 추세를 보려면 재측정 필요(다음 자동측정 N시간 후)"로 업그레이드 동선화 가능.
- ⚠️ **Surfer의 실패 답습 금지**: *"프로젝트 생성 시에만 프롬프트 자동생성 가능, 이후엔 수동"*.
