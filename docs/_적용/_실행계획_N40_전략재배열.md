## 4. 🔴 N-40 신규 함정 (내가 오늘 직접 빠진 것)

1. 🔴🔴 **에러 화면이 글자를 갖고 있다.** Storybook 스토리 ID 를 **손으로 추측**해 2개가
   `Couldn't find story` 였는데, 그 **스택트레이스 1,049자를 「콘텐츠 있음」으로 셌다.**
   첫 측정이 `0px 인데 1,049자` 라는 **모순**을 냈고 그걸 넘겼으면 에러를 데이터로 보고했다.
   → ⭐ **ID 는 `index.json` 에서만 읽는다**(`title`+`name` 매칭).
   → ⭐ **빈화면 가드(글자 0자)로는 부족하다.** `.sb-errordisplay` 가시성도 함께 본다.
   📕 N-36 함정 *"화면은 PNG 를 열어봐야 한다"* 의 확장판 — **글자가 있어도 에러일 수 있다.**
2. 🔴 **「로그인벽이라 측정 불가」는 성급한 포기였다.** 👤 지적으로 바로잡았다 —
   Storybook 으로 **같은 컴포넌트를 로그인 없이** 렌더하면 된다.
   → ⚠️ `playwright-core` 는 **저장소 밖**(`/tmp/.../measure`)에 설치했다.
     저장소에 넣으면 Next 두 번째 복사본이 생겨 **web tsc 가 깨진다**(N-36 실측).
3. ⚠️ **DOM 구조를 추측해 섹션을 잘못 짚었다.** `main` 직계를 쟀더니 합계가 전체의 **3%**
   였다(실제 섹션은 `<section>` 8개). → **합계가 전체와 안 맞으면 측정 지점이 틀린 것.**
4. ⚠️ **교차검증도 틀릴 수 있다.** *"EN 에 날조 문구 남음"* → 실측하니 **KO/EN 대칭**이고
   EN 은 **307 로 노출조차 안 된다**. → 서브에이전트 결론도 **1차 확인 후** 쓴다.
