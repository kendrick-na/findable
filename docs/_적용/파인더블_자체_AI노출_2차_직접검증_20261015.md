# 파인더블 자체 AI 노출 — 2차 직접 검증 (2026-10-15)

> 1차 결과문서(`..._원인조사_결과_20261015.md`)의 가설을 Search Console·구글 검색·ChatGPT 화면에서 직접 확인한 결과. **1차 문서의 일부 결론은 이 문서로 대체**한다.
> 표기: [증명]=오늘 화면·DB·HTTP로 직접 확인 / [가설] / [확인필요]. 사이트·코드·운영 DB는 수정하지 않음(DB는 읽기만).

## 한 줄 결론

**"ChatGPT에서 검색이 안 된다"는 전제 자체가 오늘은 맞지 않다.** 대표님 계정의 ChatGPT는 "파인더블이 뭐야?"에 우리 사이트를 근거로 정확히 답했고, 이름 없는 "한국 GEO 도구 추천" 질문에서도 **1번으로 추천**했다. 그런데 우리 측정 도구는 ChatGPT를 **웹 검색 없이** 재고 있어서 "안 나온다"는 숫자가 나온다. 진짜 약점은 **구글 색인 품질, 동명 서비스, 우리 이름 오염, 측정 방식**이다.

**낭비되는 크롤링**: `app.findable.co.kr`(로그인 후 앱) 주소 — `/billing`, `/sign-in`, `/sign-up`, `_next/static/*.js` — 와 `clerk.findable.co.kr/`가 구글에 잡혀 있다. `app.findable.co.kr/robots.txt`는 **404(없음)** [증명].

### C. ChatGPT 화면 직접 질문 (대표 로그인 계정) [증명 — 단, 개인화 주의]
| 질문 | 결과 |
|---|---|
| 이름+도메인 포함 | 운영사 인디고차일드, 대표 나현덕, 제품 기능, 한계("베타, 자동 발행 개발 중")까지 사이트 기준으로 정확. 홈의 수치는 "402 진단·47 브랜드"로 **옛 캐시본** |

### D. 우리 측정 도구는 ChatGPT를 웹 검색 없이 재고 있다 [증명]
운영 DB 측정 결과(올바른 이름 브랜드 포함 7개 질문 기준)에서 **출처(citedSources)가 붙은 응답**: ChatGPT **0/113**, Claude 83/114, Gemini 100/116, Perplexity 96/96, 네이버 57/57.
ChatGPT 열이 전부 0이라는 건 측정 때 웹 검색이 꺼져 있다는 뜻이다(학습 지식만으로 답). 실제 ChatGPT 앱은 웹 검색으로 최신 사이트를 읽는다. 그래서 **신생 사이트는 측정 도구에서 구조적으로 낮게 나온다.** (측정 로직은 동결 중이라 수정하지 않고 사실만 기록. 동결 해제 후 검토 대상)

### E. 네이버 [미확인 ❌]
Claude 쪽 브라우저 두 종류(Chrome 확장·앱 내장) 모두 **네이버 도메인을 "안전 제한"으로 열 수 없었다**(search.naver.com·searchadvisor.naver.com 둘 다). 네이버 검색·서치어드바이저는 **대표님이 직접** 확인해야 한다. 이미 DB에 있는 네이버 측정(이름 포함 질문 11/57 ≈ 19%, 네이버 AI 브리핑 5/10)은 참고만.

## 5. 다음 단계 제안 (승인 필요, 아직 아무것도 바꾸지 않음)
