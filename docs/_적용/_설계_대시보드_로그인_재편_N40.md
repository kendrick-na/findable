## 0. 왜 두 번 지적받았나 — 원인

👤 지시(v4 4번째 줄에 기록됨):
> *"전체적으로 다 뜯어고쳐야해"* · *"4곳처럼 만들고, 그다음 내걸로"* · ***"로그인 화면도 다. 싹다"***

### 실패 경로 3단계 (추측 아님 — 전부 문서에 적혀 있다)

| 단계 | 무슨 일 | 증거 |
|:--:|---|---|
| **1. 우선순위 역전** | 지시의 본체(탭 8개 재편 = 대시보드 구조)가 **8개 중 6번**으로 내려갔다 | §6-e 표 |
| **2. 조건부 전환** | 6번에 「행수 실측 선행」·규모 **L**·결제충돌 🔴 3중 잠금이 붙었다 | §6-e |
| **3. 보류가 완료로** | N-39가 *"6번 빼고 전부 종결"* → **「v4 종결」**로 보고 | 마스터투두 |

### 🔴 근거 자체가 모순이었다

v4가 탭 재편을 미룬 근거:
> 📕 `quality.md` ②층: *"접기·**탭부터 하지 않는다**. 총량이 그대로면 체감도 그대로다"*
> 🔴 **탭 재편(6번)은 총량을 안 줄이는 ④순위 수단이다.**

**원칙 자체는 맞다. 그런데 적용 대상을 틀렸다:**
- 「총량 줄이기」(§0-b)는 **랜딩 12.2화면** 얘기다
- 👤가 지적한 건 **대시보드·로그인**이다
- **랜딩 총량과 대시보드 탭 재편은 다른 화면이다** → 랜딩용 원칙을 대시보드 차단 근거로 오용

### 🔴 그리고 「행수 실측 선행」 조건은 이미 해소됐다
원래 취지 = *"탭에 표시할 데이터가 있나"*(§3-①: 무료진단분 미적재 의심).
→ **N-36이 실측해 원인이 코드 버그(24회분 유실)임을 밝히고 고쳤다.**
→ 즉 **조건은 충족됐는데 「보류」 딱지만 살아남았다.**

### 🎓 내가 지킬 규율 (같은 실패 방지)
1. 👤 지시 원문과 문서의 우선순위표가 **어긋나면 지시가 이긴다.** 문서가 스스로 지시를 강등할 수 없다.
2. **「N개 중 M개 완료」를 완료 근거로 쓰지 않는다.** 안 한 1개가 본체일 수 있다.
3. **테스트 개수(495/495)는 v4 완수와 무관하다.** 완료 근거로 제시하지 않는다.
4. 보류 항목은 **보류 조건이 아직 유효한지** 매번 재확인한다.

## 1. 지금 구조 (실측 2026-08-17 라이브)

### 대시보드 `/` — **탭 0개.** 한 페이지 세로 스택
```
Header
 ├ h1 "가시성 대시보드" + [측정 시작]
 ├ BrandSwitcher        (브랜드 2개 이상일 때만)
 ├ DashboardKpis        히어로 3장
 ├ NextActionsCard      지금 할 일
 ├ SovTrendChart        SoV 추세 + 주석
 ├ PromptScoreboard     질문별 성적
 ├ TruthMirrorSection   진실의 거울
 ├ PartnerCTA
 └ UpgradeLadder        (무료일 때)
```
`Tabs`·`TabsList`·`TabsTrigger` **grep 0건** = 탭 구조 자체가 없다.

### 분석 기능은 **사이드바 별도 라우트**로 흩어져 있다
| 라우트 | 내용 | 잠금 |
|---|---|---|
| `/compare` | 경쟁사 순위표 | growth |
| `/sources` | **「AI별 등장 · 출처」**(둘이 한 화면) | growth |
| `/history` | 측정 이력 원장 | 무료 |
| `/actions` | 지금 할 일 | 무료 |
| `/alerts` | 추적 알림 | — |

🔴 **문제**: 「어느 AI가 우리를 모르나」를 보려면 사이드바 → `/sources` → 스크롤.
경쟁사 4곳은 **한 화면 안 탭**으로 준다.

## 2. 바뀔 구조 — 탭 7개 (§4-b 기준, 8번은 Q4)

### 2-a. 최상위 형태
```
Header
 ├ h1 + BrandSwitcher + [측정 시작]          ← 탭 바깥(전 탭 공통 문맥)
 └ Tabs
    ├ 한눈에 │ 질문별 │ AI별 │ 출처 │ 평가 │ 경쟁사 │ 진실의거울
```

⭐ **BrandSwitcher·h1은 탭 위에 남긴다** — 모든 탭이 그 선택에 종속되므로, 무엇을 보고 있는지가 탭보다 먼저다(현재 코드 주석의 D10 근거와 동일).

## 3. 🔴 이 재편이 깨뜨리는 것 (v4가 경고한 것 + 내가 찾은 것)

| # | 무엇 | 조치 |
|:--:|---|---|
| 1 | **잠금이 페이지→패널로 내려간다.** 현재 `/compare`·`/sources`는 무료 유저에게 **DB 조회조차 안 한다**(`compare/page.tsx:73`) | 패널 단위 `LockedSurface`. ⚠️ 가격 로직(`@repo/payments/catalog`) 미접촉 |
| 2 | **한 페이지가 가벼운 쿼리(1400행)+무거운 쿼리(120행)를 함께 돌린다** | 🔴 **탭 3·5는 가벼운 쿼리만으로 됨**(§5-c) → 무거운 건 탭 4·6·7 **선택 시 지연 로드** |
| 3 | `Tabs`는 `"use client"` | children 합성으로 서버 섹션 주입(§5-a). 서버 컴포넌트 깨지지 않게 |
| 4 | **N-37 사고 재발 위험**: 서버액션 물면 Storybook 전멸 | `emptyAction`·`annotationsSlot` 주입 패턴 유지 |
| 5 | 탭 6 `/compare` **0건 2갈래**(측정없음 vs 순위없음) | 이관 시 **반드시 보존**(`compare/page.tsx:106-108`) |
| 6 | 탭 4 함정: 엔진 3종(chatgpt·claude·hyperclova)이 **인용을 구조적으로 안 줌** | *"이 AI는 출처를 밝히지 않아요"*로 **0과 구분** |
| 7 | 탭 3 함정: **엔진 누락 = "0"이 아니라 "측정 안 함"** | 구분 표기 |
| 8 | 탭 7 함정: `isStub`이 `Tracking`에 **없다** | *"AI가 모른다"* vs *"아직 측정 안 함"* 구분 소실 주의 |
| 9 | 사이드바 `/compare`·`/sources` 링크가 **죽는다** | 탭 딥링크(`?tab=`)로 연결 + 리다이렉트 |
| 10 | 🆕 **`loading.tsx`** — 탭 전환 시 빈 화면 | §6-e 6번에 포함된 항목. 함께 신설 |
