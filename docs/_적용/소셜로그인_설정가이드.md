# 소셜 로그인(구글·카카오·네이버) 설정 가이드

> 작성 2026-07-23. 증상: 브랜드 로그인 화면에서 구글·카카오·네이버 3종 다 클릭해도 로그인 실패 후 되돌아옴.
> 원인: **코드 문제 아님.** Clerk에 등록된 각 provider의 Client ID / Secret / Redirect URI 불일치.
> 카카오 에러 메일 KOE010(= Client Secret 누락·불일치)이 결정적 증거.
> **실제 입력은 사용자(계정 접근 권한 필요)가 대시보드에서 진행.**

---

## 🔑 모든 provider 공통 — 이 값이 핵심

Clerk가 OAuth 콜백을 받는 주소(**Redirect URI / Callback URL**):

```
https://loved-robin-66.clerk.accounts.dev/v1/oauth_callback
```

- 각 개발자 콘솔(카카오·구글·네이버)에 등록된 Redirect URI가 **위 주소와 정확히 일치**해야 함. 한 글자라도 다르면 실패.
- ⚠️ 이건 현재 **개발용(development) Clerk 인스턴스** 주소. 나중에 프로덕션 인스턴스로 바꾸면 이 주소도 바뀌고, 세 콘솔 모두 다시 등록해야 함. (투두: "Clerk 개발키→프로덕션키 전환"과 함께 처리)

## 1️⃣ 카카오 (KOE010 에러 — 지금 가장 명확)

**에러 뜻**: 카카오 앱에서 "Client Secret 사용"을 켰는데, Clerk에는 그 Secret이 안 들어갔거나 틀림.

### A. 카카오 디벨로퍼스 (https://developers.kakao.com)
1. 내 애플리케이션 → **Findable (앱 ID: 1447465)** 선택
2. **[앱 설정] → [앱 키]** → **REST API 키** 값 복사해 둠 (= Clerk의 Client ID)
3. **[제품 설정] → [카카오 로그인]** → 활성화 ON 확인
4. **[제품 설정] → [카카오 로그인] → [보안]** →
   - **Client Secret** 코드 확인 (없으면 "코드 생성")
   - **활성화 상태 = 사용함** 으로 되어 있으면 → 이 Secret을 **반드시 Clerk에 넣어야** 함
   - (또는 여기서 활성화를 "사용 안 함"으로 끄면 Secret 없이도 되지만, 보안상 켜두고 Clerk에 넣는 걸 권장)
5. **[제품 설정] → [카카오 로그인] → [Redirect URI]** 에 아래 등록:
   ```
   https://loved-robin-66.clerk.accounts.dev/v1/oauth_callback
   ```
6. **[동의 항목]** 에서 닉네임·이메일(계정 이메일)을 "필수 동의" 또는 "선택 동의"로 설정 (Clerk가 이메일 필요)

### B. Clerk 대시보드 (https://dashboard.clerk.com)
1. Findable 앱 → **User & Authentication → SSO Connections** (또는 Social Connections)
2. **Kakao (custom OAuth)** 커넥션 열기
3. **Client ID** = 카카오 REST API 키 (2번에서 복사한 값)
4. **Client Secret** = 카카오 보안 탭의 Client Secret (4번 값) ← **KOE010의 직접 원인. 이거 정확히.**
5. 저장

## 2️⃣ 구글 (Google Cloud Console)

1. https://console.cloud.google.com → 해당 프로젝트 → **API 및 서비스 → 사용자 인증 정보**
2. **OAuth 2.0 클라이언트 ID** 열기 (없으면 생성 → 웹 애플리케이션)
3. **승인된 리디렉션 URI**에 아래 등록:
   ```
   https://loved-robin-66.clerk.accounts.dev/v1/oauth_callback
   ```
4. **클라이언트 ID / 클라이언트 보안 비밀** 복사
5. Clerk 대시보드 → SSO Connections → **Google** → Client ID / Secret 붙여넣기 + 저장
   - (참고: Clerk는 구글을 기본 지원해서, 별도 키 없이 Clerk 공용 자격증명으로도 개발 중엔 동작함. 프로덕션은 본인 구글 키 권장.)

## 3️⃣ 네이버 (네이버 개발자센터)

1. https://developers.naver.com → **Application → 내 애플리케이션 → Findable**
2. **API 설정 → 로그인 오픈 API 서비스 환경** → **Callback URL**에 아래 등록:
   ```
   https://loved-robin-66.clerk.accounts.dev/v1/oauth_callback
   ```
3. **제공 정보 선택**: 이메일 주소·이름 체크 (Clerk가 이메일 필요)
4. **Client ID / Client Secret** 복사
5. Clerk 대시보드 → SSO Connections → **Naver (custom OAuth)** → Client ID / Secret 붙여넣기 + 저장
