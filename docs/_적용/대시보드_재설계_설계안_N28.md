## 1. 🔴 먼저 — 인계서 진단을 검산했다

**절반은 이미 틀렸다.** 코드 실측(`apps/app/app/(authenticated)/page.tsx`):

| 인계서 주장 | 실측 |
|---|---|
| "다음 행동이 없다" | ❌ **`NextActionsCard` 가 이미 2번째 자리**(KPI 바로 아래)에 있다. 세션N-5가 같은 이유로 넣었다 |
| "재설계 급" | 🟡 **섹션 순서는 이미 설계돼 있다** — 요약 → 처방 → 추세 → 분해 → 원장 → 영업. 근거 주석까지 달려 있다 |

⭐ **그러니 "재설계"가 아니라 "카드 하나의 내용 문제"다.** 범위를 크게 잡으면 이미 잘 된 IA를 망친다.

### 진짜 문제 (b2b.md 판정 3문으로 다시 물었다)

현재 `NextActionsCard` 가 말하는 것:
```
[아이콘] 지금 할 일 보기
        엔비디아의 측정 결과에서 효과가 큰 순서로 정리했어요   →
```

| 판정 3문 | 답 |
|---|---|
| ① 이 화면은 어떤 **질문에 답하나** | ✅ "내 브랜드가 AI 답변에 얼마나 나오나" |
| ② **보자마자** 아나 | ✅ KPI + 추세가 위에 있다 |
| ③ 그래서 **뭘 하면 되나** | 🔴 **"할 일 보기"는 행동이 아니라 이동이다.** 무엇을 해야 하는지는 **클릭해야** 안다 |

🔴 **③이 진짜 구멍이다.** 대시보드에 머무는 동안에는 *"뭘 해야 하는지"* 를 여전히 모른다.

⚠️ 그런데 **그 카드가 건수를 안 세는 데는 근거가 있다**(코드 주석 §1-4):
> 액션 목록은 `scopedLatestRunTracking`(행당 수 KB) + `buildGeoActions` + Prompt 조회 +
> `ActionCompletion` 병합으로 만들어진다. 대시보드에 복제하면 **무거운 쿼리가 두 번** 돌고
> **두 화면의 숫자가 어긋날 위험**이 생긴다(세션N-2 `sovLabel` 사고의 구조).

⭐ **그래서 이 설계안의 핵심 질문은 하나다:**
> **"두 벌 계산 없이" 다음 행동 한 줄을 대시보드에 띄울 수 있는가?**

## 3. 설계안 — 8층

| 층 | 할 것 | 근거 | 🔴 안 할 것 |
|---|---|---|---|
| **①IA** | 섹션 순서 **그대로** | 이미 근거 있는 순서(요약→처방→추세→분해→원장) | ⛔ **재배치 금지** — 인계서의 "재설계 급"은 과잉 진단 |
| **②플로우** | `NextActionsCard` 에 **행동 1건의 제목**을 노출 | 판정 3문 ③ 미달 | ⛔ 목록 전체를 대시보드에 복제 금지 |
| **③레이아웃** | 해당 없음 | | |
| **④인터랙션** | 병렬화 **실측 확인**(N-28 배포 후) | 홈 7.76초였다 | ⛔ 캐싱 도입 안 함 |
| **⑤비주얼** | 해당 없음 | | ⛔ 색·폰트 안 건드림 |
| **⑥카피** | "지금 할 일 보기" → **행동을 말하는 문장** | 이동 라벨이라 행동을 안 알려줌 | ⛔ 없는 **건수** 지어내지 않기(기존 근거 유지) |
| **⑦상태정직성** | 액션이 아직 없으면(측정 직후·crew 미실행) **그렇다고 말하기** | 지금은 항상 같은 문구 | ⛔ 빈 상태에 영업 넣지 않기(N-19 규칙) |
| **⑧기본기** | 해당 없음 | | |

### 🔴 ②·⑥을 "두 벌 계산 없이" 하는 방법 — 3안

| 안 | 방법 | 비용 | 위험 |
|---|---|:--:|---|
| **A ⭐추천** | `/actions` 가 쓰는 **최상위 액션 1건만** 서버에서 가져와 제목을 카드에 넣는다. 계산은 `buildGeoActions` **그대로 재사용**(복제 아님) | 중 | 쿼리 1회 추가 → ④ 병렬화 안에 넣으면 체감 0 |
| **B** | 액션을 **측정 시점에 저장**해두고 대시보드는 읽기만 | 대 | 스키마 변경·마이그레이션 |
| **C** | 카피만 고친다(예: "AI가 우리를 덜 말하는 질문부터 고치기") | 소 | 🔴 **구체 행동이 아니라 여전히 일반론** |

⭐ **A안 추천 이유**: 같은 함수(`buildGeoActions`)를 부르므로 **숫자가 어긋날 수 없다**.
기존 주석이 경계한 것은 *"복제"* 이지 *"재사용"* 이 아니다.

## 6. 🔴 이 설계로도 안 고쳐지는 것 3개

1. **대시보드는 여전히 "보는 곳"이다** — 실제 실행(글 고치기·발행)은 제품 밖에서 일어난다.
   그건 [[project_findable_geo_agent_definition]] 의 3단계(실행 에이전트) 몫이지 이 화면이 아니다.
2. **유저 0명** — 이 화면을 아무리 고쳐도 병목은 유통이다(`audit-loop.md` 4절).
3. **실측 불가** — 대시보드는 로그인 벽 뒤라 `measure.mjs`·`align.mjs` 를 못 돌린다.
   👤 로그인 세션 없이는 **"검사된 적 없는 화면"** 이다. 눈확인도 마찬가지.
