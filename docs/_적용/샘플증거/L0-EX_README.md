# L0-EX 정적 샘플 증거 (무료 접점 0단계)

- 파일: `샘플증거_A-30.{ko,en}.{md,html}`, 입력 조각 `sample-parts.json`. 만든 스크립트: `scripts/proof/render-evidence-sheet.ts` (bun, DB·네트워크 없음).
- 다시 만들기: `bun scripts/proof/render-evidence-sheet.ts docs/_적용/샘플증거/sample-parts.json docs/_적용/샘플증거 --name 샘플증거_A-30 --sample [--lang en]`
- 출처: 레포에 이미 있는 **공개 측정 결과 1건**(저장된 공개 API 응답)의 칸 수만 옮겼다. 고객명·도메인·자사 브랜드명 없음, 익명 ID `A-30`, 「샘플」 표기, 기준일 있음. 운영 DB는 조회하지 않았다.
- 구간(15%~58%)은 이 샘플용으로 **손으로 계산한 Wilson 값**(5/15)이다. S1의 계산 함수가 머지되면 그 값으로 교체한다.
- 이 샘플은 반복이 1회뿐이라 일부러 「비교 불가」로 나온다(발견을 만들지 않는 동작 시연).
- ⚠️ 게시는 **대표 승인 후**. 이 세션은 파일만 만들었다. 익명 샘플의 원자료가 실제 고객 측정 결과이므로 게시 전에 대표가 「이 칸 수를 익명으로 써도 되는지」 확인한다(확인 필요).
- 한계: 「엔진 8·수집 7」은 기존 `countMeasurementCoverage`가 센 값이라 종료된 엔진·브리핑 행을 포함한다. 「제대로 앎 비율」의 분모(AI 답변 15건)와 범위가 다르다.
- O4 4-1표(「자사 브랜드·고객명 없음」)와 2-6(「자사 브랜드 샘플만」)의 충돌은 대표 확인 전까지 익명 ID 안으로 진행했다.
- 「화면 제공」이 아니다: 대표의 화면안 승인(묶음 2) 전이라 md/HTML 문서 출력이다.
