# EV-c 문구 사전·금칙어·허용 문장 표

> 코드: `packages/audit/evidence-copy.ts`(단일 소유). 시험: `evidence-copy.test.ts`.
> S3·S4 시험은 머지 전까지 이 목록의 **임시 복사본**을 쓰고, 통합 전담이 머지 후 일치를 확인한다.

## 검사 방식
1. 허용 문장(부정형)을 먼저 가린다(마스킹).
2. 남은 글에서 금칙어(`PROOF_BANNED_PHRASES` 부분 문자열, `PROOF_BANNED_PATTERNS` 단어 경계 정규식)를 찾는다.
3. 그래서 「독립이 아님」은 통과하고, 같은 줄의 「독립 기관 인증」은 잡힌다(시험 있음).

## 허용 문장 (모두 부정형, 시험이 강제 — 「최초 측정」만 일반 용법 예외)
| 허용 문장 | 쓰이는 곳 |
|---|---|
| 독립이 아님 / 독립이 아닙니다 | 한계 (2) |
| 독립 검증셋이 아님 / 아닙니다 | 일치율 문구(3-4b) |
| 독립 표본으로 세지 않음 / 않습니다 | 반복 설명 |
| 독립 기관이 아님 / 독립 기관의 검증이 아님 | 한계 보충 |
| 효과 입증 아님 / 효과 입증이 아님 | 푸터 |
| 정확도를 보장하지 않습니다 / 정확도 보장이 아닙니다 | 일반 한계 |
| 최초 측정 | 「최초 측정일」 같은 일반 용법 |
| not independent / not proof of effect / not a guarantee / does not guarantee | 영어 틀 |

## 금칙어 (요지)
효과 입증 · 덕분에 올랐 · 노출을 높여드 · 순위를 올려 · 1위로 · 매출을 늘려 · 최초 · 유일 · 독립 기관 · 독립 검증 · 독립적으로 · 정확도를 보장 · 객관적입니다 · 검증됨 · 한국 전용 · 글로벌 플랫폼 · 대표 계정에서만 · 동등 · 대체 · 호환 · SOC 2 · GDPR 준수, 영어 대응어(proof of effect, world's first, independent audit, verified, validated, guarantee 등).

## 알려진 한계 (통합 전담 확인 필요)
- 못 잰 표의 「다음 행동」 열은 기존 `GAP_ACTION_KO` 같은 **외부 상수 문구를 그대로 싣는다**. 그중 일부(예: robots 막힘의 「대체 측정」)는 금칙어 「대체」에 걸린다. 사전 시험은 사전 문구만 훑고, 정적 샘플은 해당 사유를 쓰지 않는다. 실데이터 연결(10/24) 때 최종 출력을 한 번 더 훑어야 한다.
- 「질문 수」「지역」은 K0에 칸이 없어 「확인 불가(계약에 칸 없음)」로 표시한다 → 계약 변경 요청(선택 필드 추가).

## 한계 3줄 (항상 3줄)
1. 대표 본인·영업 목적 측정에 치우친 표본.
2. 같은 질문의 반복 답변은 독립이 아님(변동으로만 본다).
3. 판정은 AI. 사람 검수는 단일 검수자 파일럿 — **N건이 있을 때만** 「N건」을 쓰고, 없으면 「사람 검수 결과 없음」.

## 첫 줄 (시안·시연 표기 포함)
「AI가 우리 브랜드를 어떻게 말하고, 무엇을 빠뜨리는지 한 장으로 확인하세요.」 + 「측정한 결과와 아직 확인하지 못한 항목을 구분해 보여줍니다.」 — 화면 맨 위에 「시안·시연용 문구 — 확정 전」 표기를 같이 낸다.
