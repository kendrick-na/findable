# C-a 별칭·동명 후보 사전 — 출처 규칙

> 코드: `packages/ai/lib/brand-variants.ts`, `packages/ai/lib/homonym-candidates.ts`. 시험: `brand-variants.test.ts`.
> **그림자·기록만.** 판정(`mention-verdict*.ts`)·`brand-aliases.ts`·측정 경로에 연결하지 않는다. 시험이 판정·측정 파일이 이 두 파일을 import하지 않음을 소스로 확인한다.

## 규칙
1. **출처 있는 항목만.** `source`(URL 또는 문서 식별자)와 `source_checked_at`(확인한 날)이 모두 있어야 한다. 비었거나 「확인 필요·TBD·추정」 같은 자리표시면 거부.
2. **언어 키(`locale`) 필수.** 지금 값은 `ko`·`en`. 채우는 것은 한국어만.
3. 같은 (표기, 언어)는 한 번만(대소문자 무시).
4. 표기는 40자 이하(`brand-aliases.ts`와 같은 상한).
5. **확인하지 못한 항목은 비워 둔다.** 번역·로마자 변환 같은 추측으로 채우지 않는다.
6. 동명 후보는 위에 더해 「다른 대상 한 줄 설명」이 필요하다(사실만).

## 현재 시드
| 사전 | 항목 수 | 사유 |
|---|---:|---|
| 별칭(한국어) | 0 | 이 세션은 외부 조회·운영 DB 조회가 금지라 출처를 확인한 항목이 없다. 구조 완료로 보고 |
| 동명 후보(한국어) | 0 | 같은 이유 |

## 쓰는 법(나중, 승인 후)
`splitBrandVariantEntries(후보들)`로 통과·거부를 나눈 뒤 통과분만 저장한다. 공식 사이트 표기는 `variantsFromOfficialSite(도메인, 사이트정보, 확인일)`이 기존 `officialSiteAliases`를 읽기만 하여 만든다.
판정에 연결하려면 대표의 동결 예외 승인이 먼저다(그림자 모드 → 비교 → 승인).
