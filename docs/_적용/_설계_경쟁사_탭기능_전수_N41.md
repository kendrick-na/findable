### P1 — 「질문」 탭 (개발 기획)

**왜 P1 인가**: GEO 는 *"어떤 질문으로 측정하나"* 가 결과를 전부 결정한다. 4/4 가 최상위 탭으로
갖고 있는데 우리는 `/brand` 페이지 **안에** 묻혀 있다. 자산은 이미 있고 **입구가 없다.**

**이미 있는 것**(재사용 · 새로 만들지 않는다)
- `features/brand/prompt-wizard.tsx` — AI 제안 ~20개 → 체크박스 승인 → 저장 · 플랜 상한 안내
- `actions/brand/suggest-prompts.ts` — `isAutoGenerated: true` 로 저장 · 상한 free5/starter30/growth150
- `components/prompt-scoreboard.tsx` — 질문별 성적(대시보드에 이미 렌더)

**신설**
| 무엇 | 내용 |
|---|---|
| 라우트 | `apps/app/app/(authenticated)/prompts/page.tsx` |
| 사이드바 | 「측정」 그룹 · `대시보드` 다음 · 아이콘 `MessageSquareIcon` |
| 화면 구성 | ① 현재 질문 목록(성적 붙여서) ② `PromptWizard` ③ 상한 표시(`N/30`) |
| 🔴 핵심 | **측정 후 재편집 경로** — 지금은 질문별 성적을 보고도 질문을 고칠 길이 없다 |

⚠️ `isAutoGenerated` 축 분리 유지 — `true`=고객이 고른 추적대상 / `false`=시스템 기본질문.
  (섞으면 무료 고객 할당량이 조용히 깎이고 마법사가 거짓 상한 안내를 한다 — N-36 사고)
⚠️ 상한 계산 2벌 금지 — `suggest-prompts.ts` 의 규칙을 화면이 다시 세지 않는다.

**가드**: 사이드바에 링크 존재 · 상한을 하드코딩 안 함 · `isAutoGenerated:true` 조회 유지
→ **뮤테이션으로 무는지 확인**.

#### 🔴 P1 착수 전 코드 감사 결과 (2026-08-17 · 실측)

| 확인한 것 | 결과 |
|---|---|
| `PromptWizard` 재사용 가능? | ✅ 완결됨(제안→체크박스→저장·플랜상한 토스트·업그레이드 경로) |
| 저장된 질문을 **보여주는** 화면 | 🔴 **0곳** — `prompt.findMany` 는 `/actions` 에서 처방용으로만 씀 |
| 질문 **삭제** 경로 | 🔴 **고객용 0곳.** `admin/measure.ts:191` 의 `deleteMany`(브랜드 전체 삭제)뿐 |
| 상한 규칙 위치 | `suggest-prompts.ts:138` — `count({isAutoGenerated:true})` vs `promptLimit` **누적 기준** |
| upsert 키 | `brandId_text` — 재실행 시 `promptId` 안정(시계열 선 분열 방지) |

🔴 **그래서 P1 의 진짜 값은 「탭 신설」이 아니라 「목록·삭제 신설」이다.**
  마법사는 **추가만** 할 수 있고 고객은 자기가 무엇을 추적 중인지 **볼 수 없다**.
  상한(free 5/starter 30/growth 150)에 걸리면 *"상한 도달"* 이라는 말만 듣고
  **무엇을 지워야 할지 모른다** = 막다른 길.

**신설 범위 확정**
| 무엇 | 하는가 |
|---|---|
| 라우트 `/prompts` + 사이드바 | ✅ |
| 저장된 질문 **목록**(카테고리·언어·성적) | ✅ **신설** |
| 질문 **삭제** 서버액션 | ✅ **신설**(org 스코프 검증 필수) |
| `PromptWizard` 재배치 | ✅ 재사용(수정 없음) |

⚠️ **삭제는 축을 지켜야 한다** — `isAutoGenerated: true`(고객이 고른 추적대상)만 지운다.
