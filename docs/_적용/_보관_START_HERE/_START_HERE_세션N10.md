## 3. ✅ 시각 타임존 — **결함 아님(내 오진)**. 재조사 금지

세션N-9가 처음에 "날짜가 하루 밀린다"고 보고했으나 **끝까지 실측해보니 정상이었다.**
다음 세션이 같은 착각을 반복하지 않도록 결론과 근거를 남긴다.

**최종 실측 (전부 확인함)**
| 항목 | 값 |
|---|---|
| 무TZ 컬럼 저장 기준 | **UTC** — `DB now()::timestamp` = `06:54:33` ≡ JS `new Date().toISOString()` = `06:54:33Z` |
| 프로덕션 API 출력 | `2026-08-03T11:25:43.677Z` = **DB 저장값과 완전 일치** |
| KST 환산 | 8/3 20:25 — 실제 작업 시각으로 자연스러움 |
| 화면 `91시간 전` | **정확함** |
| `AuditJob.createdAt` 시(hour) 분포 | 15시27건·16시13건 = UTC 대역(KST 밤 0~1시) → **UTC 저장 확증** |

**무엇이 나를 속였나**: 로컬 검증에서 `Jul 30 01:24 KST` 를 보고 오차라 판단했는데,
이건 **내 로컬 머신이 KST**라 Node 가 UTC 값을 KST 로 출력한 것뿐이다
(`2026-07-29T16:24Z` → KST 표기 `07-30 01:24`가 **맞다**). 값은 정상이고 표기 형식만 달랐다.
그리고 "진짜 100시간"이라던 계산은 **저장값을 KST 라고 잘못 가정**해 +9를 덧붙인 결과였다.

**⚠️ 하지 말 것**: `setTypeParser(1114, ...)` 로 파서를 바꾸면 **오히려 9시간이 틀어진다**
(검증함). DB 마이그레이션·헬퍼 추가 전부 불필요. 코드는 한 줄도 안 고쳤다.

🎓 **교훈**: 시각을 의심할 땐 `String(date)`(로컬 TZ 출력) 말고 **`toISOString()` 과
프로덕션 API 원문**을 먼저 볼 것. 그랬으면 5분에 끝났다.

## 10. 🎓 세션N-10 교훈 (감사 8번)

1. 🔴 **"보류 권고"도 전제를 실측할 것.** 세션N-9의 보류 근거(*"23건이 1위라 변별력 없음"*)는
   **숫자는 맞지만 해석이 틀렸다** — 그 23건 중 11건이 **코드가 지어낸 1위**였다.
   §9-1 교훈("문서의 결론이 아니라 전제를 확인")이 **내 자신의 직전 세션 결론**에도 적용된다.
2. **"버린다"는 주장은 오히려 기회 신호.** `matches.length` 를 버린다는 기록을 따라가니
   버려진 값 자체보다 **그 값을 안 쓴 탓에 생긴 거짓 1위**가 더 큰 문제였다.
   버려진 계산 옆에는 대개 그 계산을 안 해서 생긴 결함이 있다(세션N-2 `mentionQuality` 와 동형).
3. ⚠️ **내가 설계한 것도 경계 테스트로 깰 것.** 상대위치 `(pos-1)/(size-1)` 로 고쳤더니
   *"2개 중 1위"* 와 *"50개 중 1위"* 가 **둘 다 만점** — 고치려던 문제가 그대로 남았다.
   합성 경계 8종을 돌려 **직접 적발**하고 규모 가중을 곱해 해결했다.
   교훈: 새 공식을 넣었으면 **극단값 표를 만들어 보라**. 실데이터만으로는 안 드러난다.
4. **분모를 `matches.length` 로 쓰면 안 된다.** 한 답변에 "1.2.3." 목록이 두 번 나오면
   6이 되어 *"6개 중 1번째"* 라는 **새 거짓말**이 된다(나이키/Gemini 실측).
   정답은 **번호의 최댓값**.
5. **`AuditJob.result` 에는 `rawResponse` 가 없다**(`excerpt` 만). 원문 재실행이 필요하면
   **`Tracking` 을 쓸 것**. 이걸 모르고 AuditJob 2,026응답을 재실행해 "0건"이라는
   무의미한 결과를 냈다가 자체 적발했다.
6. **테스트 실패는 `git worktree` 로 기준선을 잡을 것**(`git stash` 금지 저장소).
   `git worktree add <경로> HEAD --detach` + `node_modules` 심링크면 HEAD 기준선이 나온다.
   vitest 2건·lint 19건이 **기존 결함**임을 이 방법으로 확정했다.
