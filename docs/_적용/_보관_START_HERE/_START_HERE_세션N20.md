## 4. ⚠️ 함정 (착수 전 필독)

### 세션N-19 신규
- 🔴🔴 **렌더링 테스트에는 `@vitest-environment jsdom` 도크블록 필수.**
  이 저장소는 **vitest 설정 파일이 없어 환경 기본값이 `node`** → `window is not defined`.
  ⚠️ **로컬 전체 실행에서는 통과한다**(다른 테스트가 만든 DOM 에 우연히 편승) →
  **단독 실행에서만 드러나고, Vercel 빌드가 그 조건이다.** 내가 이걸로 배포를 깨뜨렸다.
  → 새 `.test.tsx` 는 **`npx vitest run <파일>` 단독으로 먼저 돌릴 것.**
- ⚠️ **`@/env` 를 타는 컴포넌트는 테스트에서 `vi.mock("@/env")` 필요** — t3-env 가
  **import 시점에** 실 환경변수를 검증해 터진다(기존 테스트 12개는 이걸 안 타서 무사했다).
- ⚠️ **`screen` 대신 `within(container)`** — 이 저장소는 자동 cleanup 이 없어
  앞 테스트의 DOM 이 남아 *"여러 개 찾음"* 으로 실패한다.
- 🚧 **로컬 dev 로그인은 불가**(구조적) — dev 는 Clerk **개발 인스턴스**라
  QA 계정이 없다(*"Couldn't find your account"* + *"Development mode"* 스크린샷으로 확정).
  → 화면 눈확인은 **배포 후 `python3 scripts/verify-app.py`**(프로덕션 대상)로 한다.
- ⚠️ **dev 서버 대상 Playwright 는 `networkidle` 금지** — HMR 웹소켓이 안 닫혀 영구 대기.
  `domcontentloaded` 를 쓸 것.
- ⚠️ **JSX prop 정렬**(`useSortedAttributes`)이 lint 에러다 — 주석을 prop 사이에 끼우면
  걸린다. `npx biome check --write <파일>` 로 자동 정리.
- 🔴 **JSX 는 속성 사이에 중괄호 주석을 못 넣는다**(TS1005) → **요소 위**로 올릴 것.
  그리고 **JSX 주석 안에 주석 종료 기호를 글자로 쓰면 거기서 끊긴다**(TS1381). 둘 다 겪었다.
- 🔴 **요금제·기능 문구는 `apps/app/.../lib/pricing.ts` 와 `apps/web/.../pricing/page.tsx`
  둘 다 고칠 것.** 한쪽만 고치면 **같은 상품을 두 화면이 다른 이름으로** 부른다
  (app 파일 상단이 이미 요구하는 규칙인데 내가 처음에 놓쳤다).
- ⭐ **`app` 은 `lang="ko"`** 다(2026-08-11 수정). 되돌리면 **한국어 줄바꿈이 다시 깨진다**.
- 🔴 **`apps/web` 에는 테스트 러너가 없다**(vitest 미설치) → 규칙을 고정해야 하는 로직은
  **순수 함수로 `packages/` 에 빼고 `apps/app/__tests__` 에서 검증**할 것
  (`measurement-coverage`·`digest-filter`·**신규 `ssr-summary`** 가 이 패턴).
- 🔴 **`metrics.enginesCovered` 는 엔진 목록이 아니라 응답 목록**이다(실측 29개 = 고유 8엔진).
