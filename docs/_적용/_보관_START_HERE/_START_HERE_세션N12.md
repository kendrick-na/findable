8. 🔴 **"투두에 있으니 만든다"가 아니라 "지금 만들 수 있나"를 먼저 볼 것.**

   가려져 있던 뒤 항목이 드러난다. 증감 판정은 **규칙별·행별로 기준선과 대조**할 것.
