## 1. ⭐ 세션L 투두 — UX 개선 (사용자 지시, 원문 보존)

> 사용자 원문(2026-07-31):
> *"현재 랜딩페이지에서 무료로 진단받기하면 로그인도 안함. 모두 로그인 가능하도록 하고,
> 들어오면 무료버전은 여기까지 등등 제한하면 될것 같은데.*
> *그리고 측정시작 버튼이 무료로 진단받기 그 페이지랑 왜 다른지, 뭐가 좋은지 등 진단해.
> 대시보드가 좀 ui ux가 이상해. 그리고 전체 진단한 페이지 그 UI UX가 한 페이지로 나오는게 좋을지,
> 아니면 대시보드 여러 메뉴에 들어가면 좋을지. 진단페이지 ui ux는 괜찮은지 등
> 경쟁사 선두주자 비교해서 모두 개선해."*

### 🔴 L-1. 무료 진단 인증 — ⚠️ 사용자 지시와 리서치 결론이 다름. **먼저 합의할 것**

**현황(실측)**: `apps/web/app/api/audit/route.ts` — 이메일 **문자열만** 받고 인증 0. 아무 값이나 통과.

**사용자 지시**: "모두 로그인 가능하도록 하고, 무료버전은 여기까지 제한"

**⚠️ 리서치 결론은 반대**:
| 근거 | 실제 문구 |
|---|---|
| HubSpot AEO Grader | **"No Account Required"** — 계정·카드·이메일 불필요, 사용량 제한도 없음 |
| Semrush | **로그인 없이 1일 3회** |
| Geoptie | "No account, no credit card, no setup" |
| Rankscale | "free audit requires no registration" |

무료 체커가 흔해서 **결과를 가리면 옆 도구로 간다.** 업계 전환 축은 **"정보량"이 아니라 "시간"**:
> Geoptie 결과 하단 원문: *"이건 **live snapshot**입니다. **시간에 따른** 추적은 대시보드로."*

**→ 권고안(사용자 승인 필요)**:
- 로그인 강제 ❌ → **IP 레이트리밋**으로 어뷰징만 차단(현재 email+domain 24h dedup은 이메일 바꾸면 우회됨)
- 무료 = **1회 스냅샷**, 유료 = **자동 재측정·추세·알림** (우리는 이미 `autoRefreshHours` 구현돼 있음)
- 결과 하단 CTA를 "시점 vs 추세" 프레이밍으로 교체

**세션L 첫 행동**: 이 권고안을 사용자에게 제시하고 **로그인 강제 여부를 확정**받은 뒤 착수.

### 🔴 L-2. 가치 역전 해소 — 무료가 유료보다 풍부한 상태 (사용자 지적 "측정시작 vs 무료진단이 왜 다른지")

**실측된 격차**:
| | 섹션 |
|---|---|
| **www 무료 진단**(비로그인) | 진실거울 · 경쟁사 벤치마크 · 매출임팩트 · 네이버갭 · 코파일럿 · GEO점수 = **6개** |

**할 일**:

### 🟡 L-4. 진단 페이지 구조 — 단일 리포트 vs 분할 (사용자 질문)

**리서치 답: 둘 다 맞다. 용도가 다르다.**
- **무료 1회 진단 = 단일 스크롤 리포트** (데이터가 1회분이라 나눌 게 없음) → 현재 www 구조가 맞음
- **로그인 추적 = 6분할** (시간×엔진×프롬프트 3축이라 한 장에 안 들어감) → app 구조가 맞음
- **두 개를 억지로 통일할 필요 없음**

**할 일**: www 진단 페이지 자체 품질 점검(세션F·G에서 결함 24건 수정했으나 UX slop 재점검).
우선순위는 L-1~3보다 낮음.
