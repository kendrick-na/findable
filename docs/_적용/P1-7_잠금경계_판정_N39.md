## 1. 🔴 이 페이지는 플랜을 알 수 없다 (기술적 선행조건 부재)

| 경로 | 실측 |
|---|---|
| props | `{ jobId, locale }` **뿐**(`audit-result.tsx:64-67`) |
| `isPaid`·`getCurrentPlan`·`@repo/auth` | **0건** |
| `/api/audit/[jobId]` 응답 | `JobResponse`(212–242)에 plan·tier·subscription **없음** |
| `LockedSurface` | **0건** (있는 `blur` 는 전부 `backdrop-blur` CSS 장식) |

🔴 **더 큰 문제**: 이 URL 은 **비로그인 공개 링크**다(`robots.ts:36` 이 색인만 막는다 —
`jobId` 가 secret 역할). 그래서 응답에 플랜을 실으면
**익명 요청자에게 「이 진단 소유자의 결제 등급」을 노출**하게 된다.

→ 부분가림을 하려면 **인증 경계부터 다시 설계**해야 한다. UI 작업이 아니다.

## 2. 🔴🔴 코드가 이미 이 결정을 내렸고, 근거가 적혀 있다

`audit-result.tsx:4170-4174` (세션L L-1 재설계):

> *"무료 체커는 흔해서 **결과를 가리면 옆 도구로 간다**.
>  → 결과는 계속 전부 공개하고, 파는 것은 **정보량이 아니라 시간**."*
> 근거: HubSpot "No Account Required" · Semrush 비로그인 3회/일 ·
> Geoptie "no account, no credit card" · 📕`측정정확도_전면진단 §3`

`audit-result.tsx:3966-3971`:

> *"우리가 이기는 유일한 지점을 우리 손으로 **80% 잠가둔 상태**였다."*
> *"🔒 유료 축은 안 무너진다 — 가치 역전의 원인은 「무료가 **반복 확인할 이유**까지 주는 것」인데
>  **처방은 1회성 aha 라 반복 이유가 아니다.** 반복 이유(=유료 축)는 **시간·비교·알림**이고 그대로 둔다."*

⭐ 이건 [[reference_findable_traps]] §9 의 **흔들리면 안 되는 축**과 정확히 같은 문장이다:
*"유료가 이겨야 할 축 = 시간·비교·알림."*

→ **P1-7 을 그대로 하면 세션L 이 되돌린 결정을 다시 잠근다.**
   📕 규율: *"방향 뒤집기 전 `git log -S`"* — 실제로 뒤집힌 이력이 있는 자리다.

## 3. ✅ 그럼 유료 축은 이미 지켜지고 있나 — 그렇다

무료 결과에 **시간 축이 이미 잘려 있다**(정보량이 아니라 시간을 판다):

| 자리 | 실측 |
|---|---|
| `audit-result.tsx:226-227` | *"무료에는 **직전 1회만**, 전체 추세는 유료"* |
| `PreviousRunBadge`(347–369) | `job.history` = **직전 1회분만** 내려온다 |
| crew(심층분석) | **무료 1회 소진**(`useCrewTrigger` 2393–2446) → 소진 시 에러가 아니라 가입 유도(`CrewSignUpCard` 2461) |
| `UpsellCard`(4155) | *"지금 보신 건 **오늘 하루의 스냅샷**"* |

→ **경계는 이미 있다.** 축이 「패널」이 아니라 **「시간」**일 뿐이다. v4 가 찾던 경계가
   없는 게 아니라 **다른 축에 그어져 있었다.**

## 5. ⬜ 되살릴 조건 (그때는 맞는 작업이 된다)

이 항목을 기각이 아니라 **보류**로 둔다. 아래가 갖춰지면 재판정한다:

1. **결제 고객이 생긴다**(현재 유료 0명). 지금은 가려도 살 사람이 없고, 데이터도 안 쌓인다.
2. **`report_viewed` 로 분모가 잡힌다**(N-39 에 신설) — 무료 결과를 **몇 명이 실제로 보는지**
   모르는 채로 가리면 효과를 판정할 수 없다. v4 §P1-8 이 이걸 요구한 이유다.
3. **인증 경계 설계가 선행**된다(§1) — 비로그인 공개 링크에 플랜을 실을 수 없다.

⛔ 그전까지 **결과 패널을 가리지 않는다.** 가리는 축은 계속 **시간**이다.
