## 2. 🔴 핵심 발견 — **본류 프롬프트로는 브리핑이 안 뜬다**

이게 이 기획의 전부다. 실측 두 개를 겹쳐야 보인다.

### (a) 브리핑이 뜨는 질의 유형 (코드 주석 · 2026-07-23 실측)
```
✅ 노출 : "{브랜드} 효과" · "{브랜드} 후기" · "{브랜드} 장단점"   ← 정보/정답형
❌ 미노출: "{브랜드} 추천/어때" · "{카테고리} 추천" · 경쟁사 추천형
```

### (b) 그런데 본류가 실제로 던지는 질의 (DB 실측 · 최근 20개)
```
나이키 러닝화 추천받을 수 있을까?          ← 추천형
스포츠화 브랜드 추천 5개 알려줄래?          ← 카테고리 추천형
엔비디아와 같은 카테고리의 인기 브랜드 5가지 ← 경쟁사 추천형
sulwhasoo.com 추천해줘                    ← 추천형
나이키 말고 다른 러닝화 좋은 게 뭐야?       ← 경쟁사 추천형
```

🔴 **전량이 (a) 의 「미노출」 목록과 정확히 겹친다.**

> **그래서 브리핑을 본류 7엔진에 그냥 끼우면 거의 모든 행이 「미노출」로 찍힌다.**
> 그건 *"네이버가 우리를 모른다"* 가 아니라 **"우리가 안 뜨는 질문을 던졌다"** 인데,
> 화면은 그 둘을 구분 못 한다 → **`0` 을 실패로 오독**하는 이 저장소 최다 사고 유형
> (apple.com · N-36 Tracking 유실 · N-31 오판정과 동종).

### ⭐ 그래서 설계 원칙
**브리핑은 「엔진 하나 추가」가 아니라 「질의 축 하나 추가」다.**
7엔진은 *추천형*을 묻고, 브리핑은 *정보형*을 묻는다 — **질문이 다르므로 분모도 다르다.**
같은 표에 나란히 세우면 안 된다(N-30 "축이 다른 두 숫자를 나란히 두면 검산하려 든다" 사고).

## 4. 🔴 선행 ② — 질의 축 (이게 진짜 선행 조건이다)

현재 브리핑 질의는 `briefing-runner.ts` 에 **하드코딩**돼 있다:
```
ko: [`${brand} 효과`, `${brand} 후기`, `${brand} 장단점`]
en: [`${brand} review`, `${brand} pros and cons`, `Is ${brand} good`]
```

본류 편입 시에도 **이 축을 유지한다**(본류 프롬프트를 그대로 쓰면 §2 대로 전멸).

⚠️ 그럼 `promptId` 는 무엇으로 잇나 — N-36 의 **폴백 프롬프트 DB 적재**와 같은 문제다.
   브리핑 질의도 `Prompt` 로 심되 **`isAutoGenerated: false`**(시스템 기본질문 축)로 넣는다.

## 5. 본류 편입 설계

### 5-a. 어디에 붙나
```
runner.ts  DEFAULT_7 (한국어) ─ 그대로 유지
                 +
          브리핑 1콜 ← 별도 축. `after()` 백그라운드
```

🔴 **동기로 기다리지 않는다** — N-37 실측: 동기 대기는 300초 함수 상한에 걸려 사망.
브리핑은 5~10초라 여유가 있지만 **7엔진 + 브리핑 합계**가 상한에 가까워지므로 `after()` 를 쓴다.
(고객용 경로는 이미 `after()` 다 — 같은 규칙을 따른다.)

### 5-b. 원가
| 항목 | 값 |
|---|---|
| 호출 수 | 측정당 **최대 3콜**(뜨면 즉시 중단 → 실측상 대개 1~2콜) |
| 단가 | Firecrawl `/v2/scrape` · `proxy:auto` |
| ⚠️ 확인필요 | **Firecrawl 요금제 잔여 크레딧** — 측정마다 나가면 무료티어가 언제 마르는지 미확인 |

🔴 **이 칸이 비어 있으면 본류 편입을 하면 안 된다.** cron 이 매일 도는 구조라
   크레딧이 마르면 **브리핑만 조용히 실패**하고 그게 "네이버가 우리를 모른다"로 집계된다.

### 5-c. 화면 (P1-G 권역 카드에 이어 붙는다)
```
한국 시장                                          등장 84%
  HyperCLOVA X        등장 11/11        출처 안 밝힘
  네이버              등장 10/10           인용 80
  다음                등장  6/11          인용 143
  네이버 AI 브리핑     등장  1/1            인용 6      ← 신규
  └ 「효과·후기·장단점」으로 물었어요            ← 🔴 질의 축이 다름을 명시
```

- 🔴 **미노출은 `0` 이 아니라 「이 질문엔 브리핑이 안 떠요」** — §2 의 오독을 막는 장치
- 🔴 **분모를 섞지 않는다** — 브리핑 1/1 을 7엔진 등장률 평균에 넣으면 축이 섞인다
