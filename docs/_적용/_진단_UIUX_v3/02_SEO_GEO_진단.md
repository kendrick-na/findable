# 🔍 SEO / GEO / 구조화 데이터 진단 (세션N-17)

> 👤 요청: *"SEO GEO 메타데이터 구조화 데이터에서 높은 점수를 받아 검색 상단에 노출될 알고리즘을
> 웹서치나 깃허브 스킬에서 찾아 UI/UX 기획서를 만들었니?"* · *"기획서에 카피라이팅·SEO/GEO까지 포함됐니?"*

## 🔴 먼저 정직한 답 — **기획서에 없다**

UI/UX 기획서 2개(`UIUX_대개선_설계_v2`·`UIUX_대개선_기획서`)를 전문 검색한 결과:

| 검색어 | 기획서 내 언급 |
|---|---|
| JSON-LD | **0회** |
| 구조화 데이터 / schema.org | **0회** |
| 메타데이터 | **0회** |
| sitemap / hreflang | **0회** |
| 카피라이팅 | **0회** (`카피`·`라이팅` 각 1회 — 토스 문법 참조뿐) |

→ **UI/UX 기획서는 SEO/GEO를 다루지 않는다.** 별도 축으로 관리돼 왔고(세션N-11이 robots·sitemap·hreflang
버그를 고친 이력은 있음), *"검색 상단 노출 알고리즘을 리서치해서 설계에 반영"* 한 문서는 **없다.**
카피라이팅도 **토스 UX 라이팅 문법(해요체·다크패턴 금지)이 적용된 수준**이고,
**전환을 목표로 한 카피 설계는 없다.**

## 🔴 결함 1 — `og:image` 가 전 페이지에서 누락 (공유 시 썸네일 없음)

🔬 **교차 확인**:
- `apps/web/app/[locale]/opengraph-image.png` **파일은 존재**(58KB, Next 파일 규약)
- 그 URL 직접 호출 → **200 image/png** (서빙 정상)
- 그런데 HTML 소스에 `og:image` 메타태그 **0건**

🔴 **원인**: `packages/seo/metadata.ts` 의 `createMetadata` 가 `openGraph` 객체를
`{title, description, type, siteName, locale}` 로 **직접 조립**한다. `images` 는
호출자가 `image` 인자를 **명시적으로 넘길 때만** 채워진다(약 141행 `if (image && metadata.openGraph)`).
그런데 실측상 `createMetadata` 호출부 중 `image:` 를 넘기는 곳은 **1곳뿐**이다.
→ Next 의 `opengraph-image.png` 파일 규약이 자동 주입하려 해도, `createMetadata` 가 만든
`openGraph` 가 그 자리를 차지해 **파일 규약이 무력화된다.**

📉 **고객 영향**: 카카오톡·슬랙·링크드인에 링크를 붙이면 **썸네일 없는 맨 텍스트**로 나간다.
B2B 영업에서 링크 공유가 첫 접점인데 **가장 값싼 신뢰 장치를 안 쓰고 있다.**
리서치가 *"Day 30 종착점은 내보내기·공유"* 라고 한 것과 직접 충돌한다.

✅ **수정안**(작다): `createMetadata` 의 `defaultMetadata.openGraph` 에 기본 `images` 를 넣는다
(`${siteOrigin}/opengraph-image.png` 또는 로케일별 경로). 호출부를 전부 고치는 것보다
**단일 진실 1곳**을 고치는 것이 맞다(이 저장소의 기존 규율과도 일치).
⚠️ `twitter.card` 가 이미 `summary_large_image` 라 이미지가 없으면 **규격 위반 상태**이기도 하다.

## 🟡 결함 2 — `/pricing` 에 JSON-LD 0개

홈에는 `SoftwareApplication` 이 1개 있으나 **요금제 페이지에 구조화 데이터가 없다.**
가격 정보는 구조화 데이터의 대표 대상(`Offer`·`Product`)인데 비어 있다.

⚠️ **단, 신중해야 한다**: 가격을 `Offer` 로 신고하면 **표시가(세전)/청구가(VAT포함)** 중
무엇을 넣을지가 곧 **표시광고 문제**가 된다. 실청구는 108,900 / 429,000 / 1,089,000 이고
화면 표기는 세전이다. **아무 숫자나 넣으면 안 된다** → 넣기로 결정하면 `priceCurrency`·
`valueAddedTaxIncluded` 를 명시해야 한다.

## ⬜ 아직 못 한 것 (정직하게)

- ❌ **"검색 상단 노출 알고리즘" 리서치 자체를 안 했다.** 형덕님 질문의 핵심인
  *"높은 점수를 받는 알고리즘을 찾아서 기획에 반영"* 은 **미착수**다.
  (이번 세션은 **현재 상태 실측**까지만 했다.)
- ❌ **GEO 관점 자기적용 점검 안 했다** — 우리가 파는 게 "AI 답변에 인용되게 하는 것"인데
  **우리 사이트 자체가 AI에 잘 인용되는지** 측정한 적이 없다. 🔴 이건 아이러니이자
  **가장 설득력 있는 자기 증명 기회**다(우리 도구로 우리를 진단).
- ❌ **Lighthouse·Core Web Vitals 실측 안 했다**(성능이 검색 순위 요인).
