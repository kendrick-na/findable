# UI/UX 전문 진단 — 평가 기준 (외부 공인 프레임워크만 사용)

> 📅 2026-08-10 세션N-17 · 👤 사용자 요청: *"전문 진단 및 감사 검증 스킬 유명한 거 서치해서 진단해"*
> 🔴 **내 취향으로 판정하지 않는다.** 아래 3개 공개 기준으로만 판정하고, 항목마다 근거를 붙인다.
> 🎯 사용자 정의 목표: ***"고객사·회사·그 회사 직원이 봐도 직관적이고 이해 쉬울 것"***
>   → 즉 평가 대상은 **미감이 아니라 "이해 가능성(comprehension)"** 이다.

## 기준 A — Apple 공식 「Design principles」 (2026-06-08 갱신본, 실측 원문)
📕 https://developer.apple.com/design/human-interface-guidelines/design-principles
⚠️ **주의**: 검색 요약은 *"clarity·deference·depth"* 라고 했으나 **현행 원문은 8개이며 그 셋이 아니다.**
   (재사용 시 반드시 원문 확인 — 낡은 인용이 널리 퍼져 있다.)

| 원칙 | 원문 한 줄 | 우리 판정에 쓰는 질문 |
|---|---|---|
| **Purpose** | *"Make something meaningful."* | 이 화면이 무엇을 위한 것인지 3초에 드러나나 |
| **Agency** | *"Let people do things their own way."* | 사용자가 다음 행동을 스스로 고를 수 있나 |
| **Responsibility** | *"Act in people's best interest."* | 표시가 사실인가(과장·유도 없나) |
| **Familiarity** | *"Build on what people know."* | 업계 관행을 따르나(낯선 용어·구조 아닌가) |
| **Flexibility** | *"Adapt to diverse contexts and needs."* | 데이터 없는 사람·처음 온 사람도 되나 |
| ⭐**Simplicity** | *"Be clear and direct."* · *"every element earning its place"* | **불필요한 요소가 자리를 차지하나** |
| **Craft** | *"Care about every detail."* | 잘림·오타·깨짐 없나 |
| **Delight** | *"Make it human."* | 숫자만 던지지 않고 사람 말로 말하나 |

## 기준 B — Nielsen Norman Group 「10 Usability Heuristics」 (실측 원문)
📕 https://www.nngroup.com/articles/ten-usability-heuristics/
업계 표준 휴리스틱 평가법. 특히 우리에게 걸리는 것:
- **#2 Match between system and the real world** — *"speak the users' language … rather than internal jargon"*
- **#6 Recognition rather than recall** — *"minimize the user's memory load"*
- ⭐**#8 Aesthetic and minimalist design** — *"should not contain information that is irrelevant or rarely needed"*
- **#1 Visibility of system status** · **#9 Recover from errors** — *"plain language (no error codes) … suggest a solution"*

## 기준 C — Vercel 「Web Interface Guidelines」 (실측 원문)
📕 https://github.com/vercel-labs/web-interface-guidelines
코드 레벨 준수 항목(접근성·포커스·폼·모션·타이포·성능). `web-design-guidelines` 스킬로 로드.
> 이건 **구현 품질**용이다. 기준 A·B(이해 가능성)와 층이 다르므로 **따로 집계**한다.

## 판정 등급
- 🔴 **결함** — 기준을 명확히 위반. 고치면 이해도가 오른다
- 🟡 **의심** — 위반 가능성이 있으나 근거가 1개거나 취향 여지 있음
- 🟢 **양호** — 기준 충족
- ⬜ **미확인** — 실측 못 함(사유 명시)
