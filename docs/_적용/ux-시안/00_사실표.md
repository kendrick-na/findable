# FACT — 대표 사실 확인이 필요한 문구 목록 (사실표)

> 2026-10-20 S4 작성. **이 표는 사실을 채우지 않는다.** 문구가 사실인지 아닌지 단정하지 않고, **어디에 있는지(출처 위치)** 와 **대표가 답할 질문**만 적는다. 「대표 확인」 칸은 전부 비워 둔다.
> 코드·사전 JSON·공개 페이지는 한 줄도 고치지 않았다(읽기만). 읽은 기준: 브랜치 `docs/proof-s4-skills-20261021`(K0 `13510775` 기반, origin/main `7224a35d` 계열).
> 표기: [확인] 코드·문서에서 읽음 / [확인 필요] 못 정함 / ☐ 대표 확인 칸(비움).

쉬운 말 풀이: **사실표** = 공개 화면에 이미 적힌 문장 중, 대표가 「맞다」고 확인해 주기 전에는 믿고 쓰면 안 되는 문장의 목록. 심사관·고객에게 허위로 읽히면 안 되는 문장(수상·선정·측정 시간·엔진 수 등)이 대상이다.

## 0. 한 줄 결론

**확인이 필요한 문구는 4묶음이다: ① 가입 패널 수상·선정 문구 3개(공개 화면에서 내리는 것을 권고) ② 무료 진단 페이지 문구 4개(재활성화 전 필수) ③ 숫자가 서로 어긋나는 곳(AI 몇 곳·몇 분·원가) ④ 사전 계산 공개 페이지 3개 점검 목록. 대표가 확인하기 전까지 아래 문구를 대외 자료(IR·소개서·시연)에 재사용하지 않는다.**

### 3-3. FACT-7 「1회 비용」 숫자 6개

UX-S1 7절의 표와 같다. 추가로 **「약 621원(운영 실측)」**(`ko.json` 2256행 `app.salesDiscover.measureConfirm`)이 영업 발굴 화면에 있다. 코드 주석 `free-audit-budget.ts` 가 v1 규칙의 기록 원가 평균을 620.6원이라 적고 이를 v2 환산(≈777원)으로 올렸다고 설명하므로, 621원은 **v1 기록 값과 같은 숫자로 보인다** [추정 — 확인 필요]. 「운영 실측」이라는 표기가 지금도 맞는지 ☐ 대표(또는 담당) 확인. 모든 숫자는 설계 추정이며 실시간 청구액이 아니다.

- 대표 확인 칸은 비웠다. 사실로 단정한 것이 하나도 없다. 증빙 파일이 레포에 없다는 것은 「대표가 가진 증빙이 없다」는 뜻이 아니다.
- 서비스 종료 날짜(2026-04-09)는 코드 주석의 기록을 인용했을 뿐 외부 확인을 하지 않았다 [확인 필요]. 엔진 이름이 같아도 서비스·API가 다를 수 있어 4절 ②는 **질문**으로만 둔다.
- 영어 사전의 나머지 키와 EN 페이지 전체는 읽지 않았다(문구가 한국어와 같은 사실을 말하는지 대조하지 않음).
