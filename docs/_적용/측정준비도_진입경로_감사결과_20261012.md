## 2. 구멍 (프란츠 사건의 원인)
1. **B→A 경로에 경쟁사·질문 추천 단계가 없다.** 온보딩(H)에서만 호출된다.
2. **저장 질문이 0이면 러너가 기본 4개를 쓴다** — `audit-prompts.ts` `generateAuditPrompts`, 4개 전부 브랜드 이름 포함. 이름 없는 질문은 공식 사이트 문구에서 뽑을 때만 생기고(`generateDiscoveryPrompts`), 업종 단서가 없으면 0개다.
3. **C·D·F·G는 아무 검사도 없다.** cron은 B로 만든 브랜드를 그대로 정기 측정한다.
4. 기존 '측정 기준 확인 필요'(`brand/page.tsx` `identityReady`)는 이름·업종·시장만 본다. 경쟁사·질문은 안 본다.
