# 경쟁사 화면 구성 vs Findable — 항목별 대조표

> 🗓 2026-08-10 (세션N-14) · 사용자 지적에 대한 답
> 📕 근거 = `_리서치원본_UIUX_2026-08-06/` (**재리서치 금지** — 검색 200회 소진분)
> 🔬 우리 화면 = **라이브 실측**(로그인 캡처 + 무료진단 13개 페이지, 2026-08-10)

## 0. 사용자 지적 (이 문서가 답해야 할 질문)

> *"UI/UX 이전에 개선한 게 뭘 개선했다는 건지 모르겠음. 리서치했던 경쟁사·선두주자
> 화면 구성은 반영한 게 없음? 지금 화면 구성이 곧 UI/UX 인데 고객 입장에선 납득할 수
> 없을 것 같은데? 뭐가 뭔지 하나도 모르겠고."*

**결론 먼저**: 반영은 **됐다**(1~3단계 커밋 5건이 HEAD 에 있고 배포도 됐다).
문제는 **반영된 게 화면에서 안 보이는 상태**였다는 것이다 — 이유는 두 가지다.

| 왜 안 보였나 | 근거 |
|---|---|
| ① **데이터가 있어야 보이는 개선**인데 계정에 측정이 없다 | QA 계정 대시보드 = **빈 상태 화면**만 뜬다(라이브 캡처) |
| ② **화면이 실제로 틀린 말을 하고 있었다** | 오늘 5건 수정(엔티티 49건·측정0건 손실단언 7건 등) |

→ *"개선한 게 뭔지 모르겠다"* 는 **정확한 지적이었다.** 개선분이 빈 상태에 가려져 있었고,
   그 사이 화면은 코드를 노출하고 없는 손실을 단언하고 있었다.

## 1. 히어로 KPI — **따라야 할 표준** (15개 툴 수렴)

| 지표 | 경쟁사 채택 | Findable 현재 | 판정 |
|---|---|---|---|
| **Visibility %**(등장률) | Profound·Peec·Rankscale·Evertune·Goodie·Trakkr·Gauge·Otterly·Athena **전원** | ✅ "AI가 우리를 아나?" | ✅ **있음** |
| **Position**(평균 순위) | Profound(5.1)·Peec·Evertune·Trakkr·Otterly(2.05) | ✅ "몇 번째로 말하나?" | ✅ **있음** |
| **Sentiment** | Profound·Peec·Goodie·Gauge·Otterly | ✅ "좋게 말하나?" | ✅ **있음** |
| **0~100 점수** | Evertune·Semrush·Rankscale | ✅ GEO 점수(무료진단) | ✅ **있음** |

**질문형 라벨은 경쟁사 중 Trakkr 만 한다** — 우리가 채택했으므로 **동급 이상**.

> ⚠️ **남은 격차**: 업계는 **Visibility 와 SoV 를 따로 쓴다**(Visibility=몇 %의 답변에 등장 /
> SoV=경쟁사 대비 점유율). 우리는 **SoV 하나만** 있고 이름만 "등장률"로 바꿔 쓴다.
> 🔬 `packages/ai/lib/engines/index.ts:206` 주석이 이미 자백: *"이 값은 경쟁 점유율이 아니라 등장률"*.

## 2. 0점(=안 보임) 처리 — **업계 관행, 우리가 넘어야 할 기준선**

| 툴 | 방식 | Findable |
|---|---|---|
| **AthenaHQ** ⭐ | 갭을 **단일 원인 도메인까지 추적** — *"seranking.com이 30개 답변 중 4개에 인용됨"* | 🔴 **없음** |
| **Semrush** | *"Your brand not mentioned"* 태그 + **Topic Opportunities** | 🟡 부분(진실거울이 "모름"은 표시) |
| **Gauge** | Action Center — **임팩트/난이도 순 우선순위** | ✅ `/actions` 존재 |
| **Trakkr** | 엔진×포지션 **히트맵**(초록/빨강) | 🟡 프롬프트 성적표가 유사 |
| **Otterly** | 크롤가능성 체커 + 콘텐츠 브리프 | 🔴 없음 |

🎯 **가장 큰 격차 = AthenaHQ 의 "단일 원인 추적".**
우리는 *"안 보인다"* 까지는 말하는데 ***"누가 대신 인용되고 있는지"*** 를 도메인 단위로 못 짚는다.
🔬 **데이터는 이미 있다** — `citedSources[].domain` · `topCitedDomains` 실존(무료진단 화면에
   출처 도메인 칩이 이미 렌더된다). **측정 추가·원가 0으로 만들 수 있는 격차다.**

## 4. 우리 화면에만 있는 문제 (경쟁사 대조로 드러난 것)

### 4-1. 🔴 **빈 상태가 제품을 대표하고 있다**

라이브 캡처(로그인 후 첫 화면) 실측 구성:
```
"내 브랜드는 AI 답변에 얼마나 등장할까요?"  ← 랜딩 카피 재탕
STEP 1 / STEP 2 / STEP 3                    ← 설명
[브랜드 등록하고 측정 시작]
파트너로 신청하기                            ← 우리 사정
Growth로 업그레이드하면 …                    ← 판매
```
**측정 전 사용자가 보는 화면의 절반이 "우리 사정"(파트너 신청·업그레이드)이다.**

| 경쟁사 온보딩 | 방식 |
|---|---|
| **Profound** | 업종 기반 **추천 프롬프트 세트 자동 시딩**(편집·삭제 가능) |
| **Otterly** | 4단계 AI 지원 설정 → **첫 리포트 자동 생성** |
| **Ahrefs** | **"no setup required"** — 위저드 없이 즉시 브랜드 검색 |
| **Findable** | 3단계 설명 + 등록 폼 |

⚠️ 리뷰어가 Profound 를 칭찬한 대목: *"**온보딩·지원이 필요 없었다**"*.
우리는 **설명을 읽게 한다** — 업계 방향과 반대다.

### 4-2. 🔴 유료 화면이 무료보다 얇다 (가치 역전, 기획서 §1-3 재확인)

| | 섹션 수(🔬2026-08-10 코드 실측) |
|---|---|
| 무료 진단(비로그인) | **15개**(`CompletedView` 렌더 컴포넌트 전수) |
| 유료 대시보드(로그인) | 히어로3 + 할일 + 추세 + 성적표 + 이력 = **5개** |

📕 기획서가 이미 정답을 냈다: **축을 "시간·비교·알림"으로 바꾼다**(진실거울 복사는 ❌ 오답).

🔴 **그런데 그 축 3개가 전부 껍데기다** — 🔬줄 수 실측:
| 유료 축 | 파일 | 실측 | 상태 |
|---|---|---|---|
| 경쟁사 비교 | `compare/page.tsx` | **114줄** | `LockedSurface` + *"준비 중"* |
| 추적 알림 | `alerts/page.tsx` | **76줄** | `LockedSurface` + *"준비하고 있어요"* |
| 출처 링크 | `sources/page.tsx` | **100줄** | `LockedSurface` |

→ **유료가 이겨야 할 축이 "잠긴 메뉴 이름"으로만 존재하고 화면이 없다.**
   즉 지금 Growth 를 결제해도 **열리는 게 사실상 없다**(=판매 표시와 실제의 불일치).
   ⚠️ 정기결제 미구현(투두 P1)과 **같은 계열의 문제**다.

### 4-3. 🟡 디자인 레퍼런스 부재 = 우리가 만들어야 함
Dribbble GEO 샷 **1개** · Behance **0** · Figma Community **0**.
→ **베낄 디자인이 없다.** 시각 언어는 창작 영역이고, 그래서 **더더욱 정보구조로 승부해야 한다.**
