# 타깃 시장 선언 — SEO 20년 선례 (2026-08-02 세션M)

> **재리서치 금지.** 시장별 점수 표시 설계의 단일 진실.
> 발단: 사용자 지적 *"모두가 글로벌 브랜드 및 기업은 아니다"* — 국내전용 병원·학원·B2B에
> "글로벌 0점"을 보여주면 안 된다. 업계가 20년간 어떻게 풀었는지 조사.
> 짝 문서: `구조감사_언어축_2026-08-02.md`(내부) · `지역언어축_경쟁사_리서치_2026-08-02.md`(GEO 경쟁사)

## 한 줄 결론

**업계에 "타깃 시장 선언" 패턴이 명확히 있고, 핵심은 — 선언이 점수를 재가중하는 게 아니라
"무엇을 점수에 넣을지(분모)"를 정한다.**
시장 하나 = 캠페인 하나로 쪼개고, 각 캠페인은 자기 시장 안에서만 100점 만점을 계산한다.
반대로 뭉친 글로벌 단일 점수(DR·Authority Score)는 **국가 분해를 아예 제공하지 않는다.**

## 🎯 핵심 근거 (Semrush — 그대로 훔쳐올 메커니즘)

**선언은 1회, 되돌릴 수 없다** [확인사실]
> "Once your campaign is set up, the original location and device type cannot be changed."
> — https://www.semrush.com/kb/548-configuring-position-tracking

**여러 시장 = 재가중이 아니라 "타깃 추가"** [확인사실]
> "The new targets will be added as **new colored lines to the graph**."
> — https://www.semrush.com/kb/692-multi-targeting

**⭐ 점수의 분모가 "내가 선언한 것"이다** [확인사실]
> "Visibility % is based on the CTR ... for keywords **from the current tracking campaign**."
> "If this number is at 100% it would mean that the domain is ranking in the 1st position for
> **all of the keywords in the campaign**."
> — https://www.semrush.com/kb/697-what-is-visibility

→ **국내 전용 고객은 글로벌 엔진이 분모에서 빠지므로 "0점"이 산출될 수 없다. 감점이 아니라 비해당.**

## Q1. Google Search Console — 종합 점수 없음

| 항목 | 사실 |
|---|---|
| 상단 지표 | Total clicks / impressions / CTR / Average position |
| 종합 점수 | **없음** |
| 국가 | 점수 구성요소가 아니라 **집계 차원(dimension)** + 필터 |

[확인사실] "Data grouped by **Queries**, **Countries**, **Devices**, or **Dates** is aggregated by property."
— https://support.google.com/webmasters/answer/7576553

⚠️ [확인필요] **"구글이 단일 점수를 의도적으로 안 만든다"는 공식 근거 문서는 못 찾음.**
점수가 없다는 관측은 사실, 그 이유(rationale)는 미확인. **대외 인용 시 구분할 것.**

## Q2. Ahrefs / Semrush / Moz — 권위 점수는 전부 글로벌 단일

| 지표 | 국가별 분해 |
|---|---|
| Ahrefs DR | ❌ 없음 |
| Ahrefs Organic traffic/keywords | ✅ 있음 |
| Semrush Authority Score | ❌ 없음 |
| Semrush Visibility % | ✅ 캠페인(=위치)별 |

🎯 **결정적 증거** [확인사실] — Ahrefs "Metrics by country" API 반환 필드 전체:
`country, org_cost, org_keywords, org_keywords_1_3, org_traffic, paid_cost, paid_keywords, paid_pages, paid_traffic`
**DR이 목록에 없다.** Ahrefs는 권위 점수의 국가 분해를 제품에서 아예 하지 않는다.
— https://docs.ahrefs.com/en/api/reference/site-explorer/get-metrics-by-country

**UI가 단일 점수와 국가별 뷰를 관계짓는 방식 = 관계짓지 않는다.** 서로 다른 층위로 분리 배치
(권위 점수는 도메인 헤더, 국가 분해는 별도 트래픽 리포트).

## Q3. 타깃 시장 선언 패턴 — 존재함

| 도구 | 선언 시점 | 점수를 바꾸나 |
|---|---|---|
| Semrush Position Tracking | **캠페인 설정 시 1회**(변경 불가) | **측정 대상 자체를 정의**(분모가 됨) |
| Semrush Multi-targeting | 캠페인 추가 | 타깃마다 **별도 곡선** |
| Ahrefs Rank Tracker | 프로젝트/키워드 추가 시 | 위치별 순위 상이 |
| Moz Pro | 캠페인 설정 | 국가별 별도 캠페인 권장 [확인필요] |
| **GSC 국가 타기팅** | ❌ **폐지(2022-09)** | — |

**⚠️ GSC 폐지 사례 해석 주의** [확인사실]
> "the ability to target search results to specific countries ... was determined to have
> **little value for the ecosystem**, and is no longer supported."
> — https://support.google.com/webmasters/answer/12474899

구글이 폐지한 건 **"검색엔진에게 내 타깃 국가를 알려주는 입력값"**(랭킹 조작 목적)이지,
**"리포트를 내 시장 기준으로 보여주는 기능"이 아니다.** Findable이 하려는 건 후자 →
**이 폐지는 반대 근거가 아니다.** 구글도 국가 차원 리포팅은 그대로 유지 중.

## Q4. "B 시장이 실패가 아님"을 표현하는 법 — 업계 방식 2가지뿐

1. **분리 계열** — 시장마다 독립 곡선. 서로 뺄셈하지 않아 "B가 낮다"가 총점 하락으로 안 번짐.
2. **비선언 시장 = 미측정** — 캠페인에 없는 위치는 리포트에 아예 안 나옴. **0이 아니라 부재.**

[AI가설] 통하는 이유 = **0과 N/A의 구분**. 0은 "했는데 실패", 미표시는 "해당 없음"으로 읽힌다.
**Findable의 현재 문제는 정확히 N/A를 0으로 렌더링하는 것.**

## 🎯 Findable 적용 권고

### A ⭐ 최우선 — "시장 선언 = 점수 분모 결정" (Semrush 직수입)
온보딩 1회 선언: **국내 전용 / 글로벌 / 양쪽**. 선언한 시장의 엔진만 분모에.

| 고객 | 분모 | 표시 |
|---|---|---|
| 국내전용 병원 | 한국 3엔진 | "한국 시장 62점" |
| 수출 브랜드 | 7엔진 | "한국 62 / 글로벌 18" 나란히 |

✅ 업계 검증 패턴 · "0점" 공포 원천 제거 · 분모 축소로 국내 고객 점수 **상승**
❌ 고객 간 점수 비교 불가 → **점수 옆 시장 라벨 의무화**(라벨 없는 62점은 거짓말)

### B ⭐ 함께 — 통합 단일 점수 폐기, 시장축 분리 발행
✅ 실측 버그(정반대 브랜드가 동일 39점) 즉시 해소 · "언어가 브랜드보다 18배 큰 변수"와 정합
❌ "당신의 GEO 점수는 X" 한 마디로 못 팜 → 랜딩·무료진단 카피 재작성 필요

### C — 비선언 시장은 0이 아니라 회색 "측정 안 함"
✅ 겁주지 않으면서 업셀 경로 확보(수출 전환 고객 자연 흡수)
❌ 회색이 약하면 "미달"로 읽힘 → 문구를 **"측정 대상 아님"**으로 못 박을 것

> ⚠️ 3안 공통 전제: **점수 옆 시장 라벨 의무화.** 라벨 없이 숫자만 발행하면 어떤 설계도 오해 재발.
