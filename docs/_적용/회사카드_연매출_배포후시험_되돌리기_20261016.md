## 3. 운영 화면 시험 — 플래그가 켜져 있을 때만

사전 조건 둘 다 필요: 플래그 켜짐 · 시험용 회사 1행. 운영 DB를 쓰는 단계는 **3-1과 3-3(되돌리기)** 뿐이다.

### 3-1. 시험용 회사 1행 넣기 (운영 DB 쓰기 · 대표 승인 필요)

고정 ID를 써서 되돌릴 때 정확히 이것만 지운다. 사업자번호는 비나우(DART 공시 회사)이며 숫자 10자리로 저장한다.

```sql
insert into "Company"
  (id, "businessNumber", "legalName", "normalizedName", "matchConfidence", sources, tags, "createdAt", "updatedAt")
values
  ('00000000-0000-4000-8000-0000000b1a0f', '8338701017', '(주)비나우', '비나우',
   'exact', array['opendart'], array[]::text[], now(), now());
```

> 도메인은 비워 둔다(시험에 필요 없고 추정으로 채우지 않는다). 시험 후 지우므로 실제 영업 목록에 남지 않는다. 마이그레이션·스키마 변경 없음.

### 3-2. 시험 (화면)

1. `/admin/ax-mail/discover`에서 (주)비나우 카드를 연다(주소: 카드 URL 파라미터는 화면의 회사 행 클릭).
2. 기본 정보 아래 「연매출 · 확인 안 됨」이 보인다 → **[공시에서 찾기]** 클릭.
3. 기대: 「공시에서 가져왔어요.」 + 카드 목록에 **「연매출 약 3,249.6억 원 · 2025 연결 · 공시 기준」**. 「출처 보기」를 열면 금융감독원 전자공시와 기준일 2025.
4. **[직접 입력]**: 금액 `100`, 단위 `억 원`, 출처 `시험입력`, 사업연도 `2024` → 저장.
5. 기대: 두 줄이 나란히: 공시 값(2025 연결) + 「약 100억 원 · 2024 · 직접 입력」. (사업연도가 달라서 각각 한 줄이다.)
6. 실패 확인(저장 안 됨 확인): 출처를 비우면 저장 버튼이 막힌다.

저장된 값 확인(읽기 전용):

```sql
select field, source, "asOf", "sourceRef", value
from "CompanyFact"
where "companyId" = '00000000-0000-4000-8000-0000000b1a0f' and field = 'revenue'
order by "asOf" desc;
```

기대: `opendart | 2025 | 20260331002615 | amount 324958207706, basis audit_report, fsDiv CFS` 1행과 `input | 2024 | 시험입력 | amount 10000000000, basis input` 1행.

### 3-3. 되돌리기 (시험이 끝나면 반드시)

시험 때 만든 것은 회사 1행 + 그 회사의 매출 사실 2행뿐이다. `Company` 삭제가 `CompanyFact`를 연쇄 삭제하지만(스키마 `onDelete: Cascade`), 확실히 하려고 사실부터 지운다.

```sql
delete from "CompanyFact" where "companyId" = '00000000-0000-4000-8000-0000000b1a0f';
delete from "Company"     where id          = '00000000-0000-4000-8000-0000000b1a0f';
```

되돌린 뒤 확인(읽기 전용, 둘 다 0이어야 한다):

```sql
select (select count(*) from "Company") companies, (select count(*) from "CompanyFact" where field = 'revenue') revenue_facts;
```

> 지우기 전에 시험 때 쓴 값만 지우는 것이다. 다른 `Company`·`CompanyFact`는 건드리지 않는다(운영 `Company`는 시험 전 0행이었다).
