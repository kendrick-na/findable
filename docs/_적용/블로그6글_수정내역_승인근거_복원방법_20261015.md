## 3. 복원 방법 (원문은 `ContentRevision`에 보존)

각 글의 **변경 전 버전**: seo-ko v4 · seo-en v1 · discover-ko v4 · discover-en v2 · faq-ko v7 · faq-en v5 (변경 후 새 버전은 5·2·5·3·8·6, `createdBy = claude-geo-audit-2026-10-15`).

```sql
-- ① 제목·본문·요약을 이전 버전으로
update "Content" c
set title = r.title, "bodyMarkdown" = r."bodyMarkdown", excerpt = r.excerpt,
    "updatedAt" = (now() at time zone 'utc')
from "ContentRevision" r
where r."contentId" = c.id
  and (c.id, r.version) in (
    ('5c88a5e5-4c5c-4356-a5d2-54260d748147', 4),
    ('675244a5-f2c7-4cd4-b0f8-2569b11aabbf', 1),
    ('1916e377-b8f5-4976-accc-3db4a21eb6ff', 4),
    ('06b70364-d14f-47b8-a304-c90ab945fc10', 2),
    ('6642461f-c111-4027-9f00-fcd331a33017', 7),
    ('927d14c6-352a-4f7a-a975-3e62cadeded9', 5));

-- ② seoTitle·seoDescription 은 이력 표에 없어서 값을 여기 기록한다(seo-vs-geo 두 글만 바꿨음)
update "Content" set
  "seoTitle" = 'SEO와 GEO의 차이 | 검색 순위와 AI 답변 노출을 함께 측정하는 방법',
  "seoDescription" = 'SEO와 GEO의 차이를 검색 결과 순위와 AI 답변 노출의 관점에서 설명합니다. SEO 성과와 GEO 성과를 함께 측정하고 개선하는 실전 체크리스트를 정리합니다.'
where id = '5c88a5e5-4c5c-4356-a5d2-54260d748147';
update "Content" set
  "seoTitle" = 'SEO vs GEO: Search Rankings and AI Visibility | Findable',
  "seoDescription" = 'Understand the difference between SEO and GEO and use separate, connected metrics to improve search and AI visibility.'
where id = '675244a5-f2c7-4cd4-b0f8-2569b11aabbf';
```
- 복원 후 `ContentRevision`에 되돌린 버전을 새 행으로 남기는 것이 앱의 관례다(선택).
- 사이트 반영: 재배포 또는 `revalidate`(최대 1시간) 후.
- ⚠️ 복원하면 영문 FAQ 글의 **깨진 링크(404)** 와 ko/en **번역 쌍 불일치**(hreflang 쌍)도 원래대로 돌아간다. 복원 시 `apps/web/lib/content.ts`의 번역 쌍 표(`TRANSLATION_SLUG_PAIRS`)와 맞는지 확인할 것.
