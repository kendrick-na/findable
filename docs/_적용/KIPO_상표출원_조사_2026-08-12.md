## 1. 💰 수수료 (2023-08-01 개정 현행)

| 구분 | 1류당 |
|---|---|
| **전자출원 + 고시명칭만** | **46,000원** ⭐ 최저 |
| 전자출원 | 52,000원 |
| 서면출원 | 62,000원 |
| **등록료(10년분)** | **201,000원** |
| 등록료 2회 분할 | 매회 122,000원(합 244,000 — **분할이 43,000원 더 비싸다**) |
| 갱신등록료 | 300,000원 |

- ⚠️ **지정상품 10개 초과 시 개당 2,000원 가산**(출원·등록 양쪽). → **10개 이내로 끊을 것**
- ⚠️ 떠도는 "전자출원 62,000원"은 **틀림**(그건 서면). 공식 실측 = 전자 52,000원
- ⚠️ "20개 초과 가산"은 **2012년 폐지 기준**. 현행은 **10개**

**Findable 예상(전자·고시명칭·3개류·각 10개 이내)**
```
출원료  46,000 × 3 = 138,000원
등록료 201,000 × 3 = 603,000원
─────────────────────────────
관납료 합계        = 741,000원   (+ 대리인 수수료 별도)
```

🔴 **감면 없음** — 개인 70%·청년 85% 감면은 **특허·실용신안·디자인 전용**이고
특허청 FAQ 에 *"상표는 감면대상에서 제외"* 로 명시돼 있다.

- 🔴 **함정**: 2021년 심사기준 개정으로 **소프트웨어 명칭에 "용도"를 명확히** 써야 한다.
  그냥 *"소프트웨어"* 는 거절 → *"검색엔진 최적화용 소프트웨어"* 처럼 용도를 박을 것

## 4. ⚖️ 선출원주의 — **서두를 실질적 이유**

**상표법 제35조**: *"다른 날에 둘 이상의 출원이 있으면 **먼저 출원한 자만이** 등록받을 수 있다."*
같은 날이면 협의 → 불성립 시 **특허청장 추첨**.

**오스트리아 `findableapp.com` 의 영향**
- 상표권은 **속지주의** → 오스트리아 등록 자체는 한국 심사에서 **인용되지 않는다**
- 🔴 **단, 그쪽이 마드리드로 한국을 지정하면** 그 국제등록일이 한국 출원일로 취급된다
  → **먼저 출원하는 쪽이 이긴다.** 이것이 서두를 실질적 이유다.

**마드리드 국제출원**
- 🔴 **국내 기초출원(또는 등록)이 반드시 선행** → 순서상 **국내 출원이 먼저**
- 기본수수료 흑백 **653 CHF** / 컬러 903 CHF · 3개류 초과 시 1류당 100 CHF · 지정국당 100 CHF
- 한국 특허청 송부수수료 전자 5,000원

## 5. 🔴 최대 리스크 — "Findable" 식별력

**상표법 제33조 제1항 제3호**(성질표시): 상품의 **효능·용도**를 보통으로 표시한 표장만으로
된 상표는 **등록 불가**.

🔴 **Findable = "찾을 수 있는"** → AI 검색 노출 서비스의 **효능·용도를 직접 기술**한다.
판례는 외국어 상표를 **국내 수요자가 뜻을 직감하는지**로 판단하는데, findable 은 평이한
영단어라 직감될 소지가 있다. (선례: 인쇄 관련 상품에서 "E PRINT" 식별력 부정)

**회피 실무**
1. **도형(로고) 결합 출원** — 등록 확률↑
   ⚠️ 단 권리범위가 **결합 전체**에 미쳐, 제3자가 같은 문자를 일반 폰트로 쓰면 **권리행사가 어렵다**
2. **한글 병기("파인더블")** 별도 출원 — 방어 폭 확대
3. **조어 결합** — 새로운 관념 형성
4. ❌ **제33조 제2항 "사용에 의한 식별력 취득"은 지금 못 쓴다** — **유저 0명**이라 사용 실적이 없다

⚠️ 개별 등록가능성 판단은 **변리사 영역**. 위는 일반 실무이고 Findable 건 최종판단은 `[확인필요]`.
