# 고객 테스트 키트 — 「오늘」·「내 브랜드 정보」 (2026-10-16)

> 목적: 5~10곳이 **실제로 쓰는지** 본다. n=1 사건에서 나온 기능이라 고객이 같은 문제를 겪는지는 아직 모른다(검증 전).
> 이 문서는 준비물이다. 대상 선정·연락은 대표님이 한다. 고객 데이터·연락처는 여기에 적지 않는다.

## 1. 누구에게
- **조건**: 이미 측정 결과가 있고(「오늘」은 데이터가 있어야 보임), 점수가 낮거나 "왜 낮은지" 궁금해하는 곳 우선.
- 5~10곳. 업종이 다양할수록 좋다. 영업 3곳 측정 진행 중인 곳은 **관제탑과 먼저 상의**(기준선 영향).

## 2. 켜는 방법 (대표님이 1줄)
- 파일럿 조직 목록 환경변수 `TODAY_VIEW_ORG_IDS` 에 조직 id 를 쉼표로 추가 → 앱 재배포.
- 켜지면 그 조직은 「오늘」(`/`)과 `/brand` 의 「내 브랜드 정보」가 보인다. 끄려면 id 삭제 후 재배포, 개별 되돌리기는 화면 아래 「예전 화면으로 보기」.
- ⚠️ 제가 환경변수는 못 바꿉니다(분류기 차단). 붙여넣을 명령은 대상이 정해지면 드립니다.

## 3. 무엇을 보나 (3문항 — 고객에게 시키는 일)
| # | 시키는 일 | 관찰할 것 | 성공 기준 |
|---|---|---|---|
| 1 | 「오늘」을 열어 보고 **"지금 우리 브랜드 상태가 어때요?"** 에 답하게 한다 | 5초 안에 큰 숫자로 답하는가 | 숫자를 읽고 한 문장으로 설명 |
| 2 | "**먼저 뭘 하면 될까요?**" 라고 묻는다 | 「먼저 살펴볼 질문」→ [처방 보기]를 누르는가 | 설명 없이 누름 |
| 3 | 「내 브랜드 정보」에 **아는 것만** 적게 한다 | 몰라서 막히는 칸, 「확인함」을 이해하는가, 미리보기를 복사하는가 | 3칸 중 1칸 이상 채우고 막힘 없이 저장 |

## 5. 결과를 어떻게 쓰나
- 5곳 중 3곳 이상이 1·2번을 막힘 없이 하면 → 메뉴 4개 통합 착수.
- 3번에서 반 이상이 막히면 → 입력 칸 수·문구를 줄인다(기능 크기 축소).
- 아무도 다시 안 들어오면 → 「오늘」이 아니라 **알림(메일)** 이 진짜 진입점일 수 있다(G8 알림 승인 근거).
- ⚠️ 위 기준(3/5, 반 이상)은 **제가 정한 시작점**이지 근거 있는 숫자가 아닙니다. 대표님이 바꾸셔도 됩니다.
