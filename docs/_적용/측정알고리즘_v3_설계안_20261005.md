## 1. 원칙
1. **질문은 실제 사람이 묻는 방식으로** — 부자연스러운 정식명 질문 금지. 자연스러움은 **검색량 데이터**로 판단한다.
2. **모호성은 판정이 해결한다** — 별도 「이름 충돌」 카드를 두지 않는다. 자연스러운 질문에서 실제로 혼동이 나면 일반 발견사항으로 보고.
3. **AI 추측은 판정 보조로만** — 질문 문장·공식 표기에 쓰지 않는다.
4. 숫자는 분포로 — 단일 실행 값을 확정처럼 보이지 않는다.

## 2. 파이프라인
### ① 엔티티 프로필 (등록 시 1회 + 주기 갱신)
- 공식 사이트에서: JSON-LD Organization/Product(`name`·`alternateName`·`sameAs`), og:site_name, 제목의 한글/로마자 구간 분리, 푸터 법인명·사업자번호·주소·이메일 도메인, 대표 제품명·성분·가격.
- 형제 도메인: sameAs·이메일 도메인·공식 링크로 소유 연결된 도메인(예: franzskincareusa.com).
- 별칭 신뢰 순위: 공식 표기 > 고객 입력 > 도메인 > LLM 추측(판정 전용).

### ② 모호성 탐침 (측정 전 1회, 캐시)
- 엔진 2곳에 「X는 뭐야?」「What is X?」 → 구조화 출력으로 서로 다른 대상 수·각 대상의 특징 단어(rival signature) 추출.
- 보조 신호: 위키데이터 동음이의(P31=Q4167410), 사전 단어 여부, 이름 길이.
- 결과는 화면 카드가 아니라 ③ 질문 선택과 ④ 판정 입력으로만 쓴다.

### ③ 질문 세트 = 실제 수요 기반
- 씨앗: (a) 사이트 제품명·성분·카테고리 (b) **네이버 검색광고 키워드도구 월 검색량**(브랜드·브랜드+제품·카테고리 키워드) (c) 연결된 고객의 GSC 장문 쿼리 (d) Google PAA.
- 키워드 → 대화형 질문 변환(의도: 정보·추천·비교·구매고민·문제해결).
- **이름만 질문의 사용 여부도 검색량으로 결정**: 브랜드 단독 키워드 검색량이 충분하면 자연스러운 질문으로 포함, 모호성 탐침에서 혼동이 크면 실제 많이 쓰이는 수식 조합(「프란츠 앰플」「franz pdrn」)을 우선.
- 시작 구성비 [AI가설, 브랜드별 검색량 비율로 보정]: 이름 없는 질문 60 / 브랜드+속성 25 / 비교 15. 언어는 시장 설정(국내 7:해외 3 기본).
- 가중치 = 씨앗 키워드 월 검색량. 월 1회 재계산.

### ④ 판정 v3 (5분류)
- 분류: 제대로 앎 / 다른 대상 / **모호함(여러 대상 나열·되물음, 우리가 목록에 있어도)** / 모름 / 판정 실패.
- 1차 규칙(전문 기준): rival signature 단독 → 다른 대상, 되물음·다중 나열 → 모호함, 공식·형제 도메인 인용 → 제대로 앎 후보.
- 2차 LLM: 입력 = 프로필 카드 + 경쟁 동명 카드들 + 답변(판정창=근거창 일치). **객관식(우리/동명A/동명B/해당없음) + 주장별 근거 인용** 구조화 출력, 온도 0.
- 신뢰도: 규칙·LLM 일치 또는 도메인 근거 = high, LLM 단독 = medium, 불일치 → 2번째 모델 재판정, 그래도 다르면 판정 실패.
- 골드셋(사람 판정 정답)으로 정확도(F1) 추적.

### ⑤ 표본
- 연구 근거: 같은 질문 재실행 변동이 분산의 35%, 언어 27%, 5회 초과 반복은 효과 미미.
- 일반 측정: 현행 1회 유지(비용). **영업 리포트·유료 확인: 질문당 3회**, 반복 대신 표현·언어 다양화. 리포트에 범위 표기.

### ⑥ 매출 기회(가정 기반) — 재도입
```
월 기회 = D × A × (S_목표 − S_현재) × CTR × CVR × AOV
D   = 네이버(+구글) 월 검색량 합 [실측]
A   = AI 답변 노출 비율   13.1 / 20.5 / 24.9 %  (Ahrefs AIO, 구글 기준 — 네이버 [확인필요])
S   = Findable 측정 언급률
CTR = 1 / 2.07 / 8 %  (Pew·Seer)
CVR = 1.5 / 2.93 / 7 %  (고객 GA 값 있으면 대체)
AOV = 공식몰 가격 [실측]
```
- 표기: 「놓친 매출 기회(가정 기반) 월 A~C원」. "확정 손실" 금지. 리포트 1쪽에 산식·가정·출처, 메일 1줄.

## 3. 출시 순서
1. 엔티티 프로필 + 별칭 순위 + 형제 도메인 (결함 1·2·6)

4. 매출 기회 v2 (결함 7)
5. 프란츠 재측정 → 리포트·메일
