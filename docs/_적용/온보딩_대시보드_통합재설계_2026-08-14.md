## 0. 이 문서가 푸는 문제

지금 온보딩과 대시보드는 **끊겨 있다.**

```
무료진단(도메인·브랜드명·언어 다 받음)
  → 가입 → 🔴 아무것도 안 넘어감
  → /brand 에서 같은 걸 다시 입력
  → "브랜드 등록" 클릭 → 🔴 측정 안 됨
  → "측정 시작"을 또 찾아 눌러야 함
  → 대시보드 → 🔴 측정 2회 전엔 추세 그래프가 빈 상태
```

Profound 는 이 구간이 **하나의 흐름**이다: 도메인 → 자동 분석 → 결과.

⭐ **설계 원칙 한 줄**: **입력 하나를 받으면 그 자리에서 산출 하나를 돌려준다.**

## 1. 실측 대조 (Profound vs Findable)

### 1-a. 온보딩

| 항목 | Profound | Findable | 우리 부품 |
|---|---|---|---|
| 필수 입력 | **도메인 1개** | 브랜드명+도메인 2개 | ✅ `resolveBrandIdentity(domain)` |
| 업종 | **안 물음**(추론) | 물음(선택) | ✅ `resolveIndustryProfile` |
| 국가 | 드롭다운 | 🔴 없음 | 🟡 `inferMarketScope`(추론만) |
| 언어 | 드롭다운 | 🔴 Brand 에 안 씀 | 🟡 컬럼만 존재 |
| 등록 후 | **자동 측정** | 🔴 버튼 또 눌러야 함 | ✅ `startOrgTracking` |
| 경쟁사 | **자동 순위** | 🔴 저장조차 안 됨 | ✅ `extractCompetitorLandscape` |

### 1-b. 대시보드

| 항목 | Profound | Findable |
|---|---|---|
| 메뉴 그룹 | Analytics / Action / Brand Hub / Reports | **실행 / 측정 / 분석** ✅ 이미 유사 |

| 처방 | **Content**: 템플릿→브리프→초안 | 🟡 `NextActionsCard`(글은 안 씀) |

## 2. 🔴 Profound 를 그대로 베끼면 깨지는 것 (전수)

착수 전에 반드시 읽는다. **4건 다 실측·기록 근거가 있다.**

| # | 베끼면 | 왜 안 되나 |
|:--:|---|---|
| **①** | 업종 **필드 자체** 제거 | 사고 이력: 업종 미상이면 crew 가 **반도체 회사에 화장품 채널을 처방**했다. → 입력칸은 숨겨도 **필드·enum 은 유지**하고 자동 추론으로 채운다 |
| **②** | 국가 드롭다운 도입 | 우리 축은 **국가가 아니라 엔진 지역**(korea/global/both). 국가로 바꾸면 8/3 에 바로잡은 오류가 재발한다("국내 중심"이 ChatGPT 를 빼버림 — 정작 한국인이 제일 많이 쓰는 엔진) |
| **③** | 언어 드롭다운 도입 | 우리는 **영어=4엔진 / 한국어=7엔진**이다. 그냥 두면 "AI 7곳" 광고와 어긋난다. → 옵션에 **엔진 수를 병기**해야 한다(무료 진단 폼은 이미 그렇게 되어 있다) |
| **④** | 경쟁사 순위를 그대로 저장 | 실측상 **약 절반**이 평평한 분포(2·2·2·2·2)라 화면이 이미 렌더를 거부한다(`discriminative`). 저장도 같은 조건을 걸지 않으면 쓰레기가 쌓인다 |

## 3. 통합 설계 — 3단 흐름

### 3-a. 단계 1 · 입력 (온보딩)

```
[ https://example.com          ]   ← 필수는 이것 하나
                                     (브랜드명·업종은 자동 추론 후 보여주고 고치게 한다)
[ 측정 시작 ]
```

- 무료 진단을 이미 한 사람은 **도메인·브랜드명·언어가 채워진 상태**로 도착한다(승계)
- 자동 추론 실패 시 **"웹사이트를 자동으로 읽지 못했어요"** 를 띄우고 수동 입력을 요청한다
  (AthenaHQ 방식 — 실패를 숨기고 빈값을 넣지 않는다)

### 3-b. 단계 2 · 확인 (Profound 에 없는 우리 단계)

자동으로 뽑은 것을 **초안으로 제시**하고 고치게 한다.

```
이렇게 파악했어요. 틀리면 고쳐 주세요.        ← 초안임을 먼저 말한다
  브랜드   인디고차일드          [수정]
  업종     마케팅/광고           [수정]
  타깃시장 국내 중심             ⓘ .kr 도메인이라 이렇게 잡았어요
  측정언어 한국어 · AI 7곳       ⓘ 영어만 고르면 4곳
```

> ⭐ **여기가 ②③의 답이다.** 국가·언어를 "묻지" 않고 **추론 결과를 보여주고 고치게** 한다.
> 그러면 Profound 의 편의(안 묻기)와 우리 정확성(축이 다름)을 둘 다 지킨다.
> 그리고 `marketScope` 를 되살리되 **8/3 에 지운 그 형태(국내/글로벌 라디오)가 아니라
> 근거를 붙인 읽기+수정 형태**라 같은 실수를 반복하지 않는다.

### 3-c. 단계 3 · 결과 (대시보드)

측정이 끝나면 **바로 여기로 온다**. 지금처럼 빈 화면을 보여주지 않는다.

## 4. 대시보드 재설계

### 4-a. 유지 (버리지 않는다)

| 지금 있는 것 | 판정 |
|---|---|
| 3그룹 사이드바(실행/측정/분석) | ✅ **유지** — Profound 4그룹과 같은 철학이고 이미 되어 있다 |
| `NextActionsCard` 2번째 자리 | ✅ **유지** — N-28 이 근거를 갖고 배치했다. 재배치 금지 |
| `DashboardKpis` · `SovTrendChart` · `PromptScoreboard` · `AuditHistoryList` | ✅ 전부 유지 |

### 4-b. 추가 (Profound 에서 가져올 것)

| # | 무엇 | 근거 | 비용 |
|:--:|---|---|:--:|
| **D1** | **지표마다 설명 한 줄** — `Citation Share ⓘ / How often nike.com is cited…` 방식 | 우리 감사: *"숫자 창고"* 문제 | 매우 작음 |
| **D2** | **기간 비교** — `최근 7일 ▾` × `이전 기간 대비 ▾` | 요금제 축(시간·비교·알림)과 일치. **유료 근거** | 중간 |
| **D3** | **엔진별 추세선** | Profound 는 4엔진을 각각 그린다 | 큼(집계 신규) |

⚠️ **D3 는 보류.** 우리 차트는 "2계열까지"라는 색 규율이 있고 7엔진은 그걸 깬다. 그리고 **측정 2회 이상**이 있어야 의미가 생긴다.

### 4-c. 🔴 Findable 의 색깔 (Profound 에 없는 것 — 여기서 이긴다)

| 우리만 있는 것 | Profound |
|---|---|
| **한국어 개체 그라운딩** (아모레/Amorepacific/아모레퍼시픽 묶기) | 없음 |
| **네이버·다음** 측정 | 없음(서양 엔진만) |
| **처방에 근거(evidence)** — `GeoAction`은 왜 이 액션인지 실측 숫자·도메인·프롬프트 원문을 준다 | Content 는 글은 주지만 근거 제시가 약하다 |
| **진실의 거울**(AI 원문 그대로 보여주기) | 없음 |

> ⭐ **전략 결론**: Profound 를 따라 "쓰기 쉬움"을 확보하고, **근거·한국어·네이버**로 차별화한다.
> Content(글 생성)를 그대로 베끼는 것은 **후순위** — 우리 `buildGeoActions` 가
> 이미 `evidence`·`how`·`priority` 를 주고 있어 겹친다. 먼저 이걸 화면에서 제대로 보여주는 게 싸다.

## 7. 🔴 이 설계로도 안 고쳐지는 것

1. **첫 결과까지 시간** — 우리는 7엔진 실시간이라 "즉시"가 불가능하다. Profound 도 24~48h 다. **Ahrefs 만 즉시**인데 그건 미리 긁어둔 창고를 파는 것이라 구조가 다르다.
2. **측정 2회 전에는 추세가 없다** — D2(기간 비교)의 전제. 첫 사용자는 여전히 스냅샷만 본다.
3. **유료의 진짜 근거** — 이 설계는 온보딩·화면을 고치지만, *"왜 돈 내나"* 의 답은 **알림 메일 스위치**(이미 크론 완성·기본 꺼짐)에 있다. 별건이다.
