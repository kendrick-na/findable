# 대시보드 개선 기획 (디자인 + 권한 + 신규 기능)

> 작성 2026-07-26. 호출: "파인더블 대시보드 이어가자"
> 대상 = `apps/app/(authenticated)/` (app.findable.co.kr). 소셜 로그인 프로덕션 전환 완료 직후.
> 결정: ①플랜 배지 + 잠금(🔒) 방식 ②있는 것 브랜딩 + 새 기능도 추가 ③권한 저장 = Clerk publicMetadata.plan

## 0. 지금 상태 진단 (실측)

**구조** (`(authenticated)/`)
- 사이드바: Platform(대시보드/새측정/측정이력) + 리소스(GEO리포트/벤치마크/고객사례/시너지/블로그) + 요금제/문의
- 본문: KPI 4장 + SoV 추세 차트 + 최근 측정 이력 / (이력 0건이면 온보딩 empty-state)
- 데이터: `AuditJob`을 **email 기준** 조회 (organizationId 없음)

**문제점**
1. 🎨 **브랜드 단절** — 대시보드는 shadcn 기본 `Card`(회색 카드+검정 배경)만 사용. 홈(apps/web)은 `.findable-glass`·`--findable-*` 토큰으로 브랜딩했는데 대시보드는 방치. "회색이랑 블랙으로 나눈" 밋밋함의 정체.
2. 🔒 **권한 개념 전무** — 무료/승인/유료 구분이 코드에 0. 누구나 같은 화면. "요금제"는 web으로 나가는 링크뿐. → 유료 전환 동선·가치 사다리 없음.
3. 📊 **가치 사다리 부재** — 무료 유저가 "더 있으면 뭐가 좋아지는지" 볼 표면이 없음. empty-state는 좋으나 그 이후가 평평.

**자산 (그대로 재사용)**
- `--findable-*` 토큰 = `packages/design-system/styles/globals.css`에 이미 존재 (canvas #010102, surface 1~4, ink 4단계, primary 오렌지, hairline). app도 이 globals import → **바로 사용 가능**.
- 요금제 4단계 = Free Audit(₩0) / Starter(₩99K/월) / Growth(₩390K/월·추천) / Enterprise(맞춤)

## 1. 권한 모델 (플랜 3.5단계)

Clerk `user.publicMetadata.plan` 값으로 구분. 없으면 `free`.

| plan 값 | 라벨(배지) | 누구 | 대시보드 권한 |
|---------|-----------|------|--------------|
| `free` | **Free** (회색) | 기본 로그인 전원 | KPI·차트 요약 + 이력. 측정은 web 무료 1회 유도. 심화기능 🔒 |
| `approved` | **파트너** (오렌지) | 내가 수동 승인 (오버엣지 등) | Free + 심화기능 일부 해제. "승인됨" 표시 |
| `pro` | **Pro** (그라데이션) | 유료(Starter/Growth) | 전 기능 해제. 프롬프트 추적·자동리포트·Export |
| `enterprise` | **Enterprise** | 대기업 계약 | Pro + 전담매니저·API. (지금은 pro와 동일 취급, 배지만 구분) |

**저장·전환 방법 (지금 단계, 결제 연동 전)**
- Clerk 대시보드 → Users → 해당 유저 → **Metadata → Public** 에 `{ "plan": "approved" }` 수동 입력.
- 코드는 `getPlan(user)` 헬퍼로 읽기만. 값 없으면 `free` 폴백.
- 나중에 PortOne 결제 성공 웹훅에서 `plan: "pro"`로 자동 세팅 (별도 작업, 지금 범위 아님).

**"누르면 다 무료로 나오는" 함정 방지 원칙**
- 잠긴 기능은 **버튼은 보이되(가치 노출) 클릭 시 업그레이드 유도** — 실제 데이터/기능은 서버에서 plan 확인 후에만 반환.
- 게이팅은 **서버 컴포넌트에서** (`getPlan` → 조건부 렌더/데이터). 클라이언트에서만 숨기면 우회 가능하므로 금지.

## 2. 디자인 개선 (브랜드 일관성)

**원칙**: 홈(apps/web)의 언어를 대시보드로. 단, 대시보드는 "작업 공간"이라 홈보다 **차분하게** (glow 과함 금지).

- **배경**: 순검정 대신 `--findable-canvas`(#010102, 푸른기 있는 검정) + surface 단계로 깊이. 회색/검정 이분법 제거.
- **카드**: shadcn `Card` → `.findable-glass` 계열 or surface-1/2 + hairline 테두리 + 안쪽 하이라이트. KPI 카드에 미세한 상단 하이라이트로 "떠 있는" 느낌.
- **강조색**: primary 오렌지는 **CTA·양수 델타·활성 상태에만** 점으로. 전면 도배 금지(홈 브랜딩 때 사용자가 "튄다"고 뺀 이력 존중).
- **타이포**: 워드마크만 Instrument Serif, 본문 Geist (홈과 동일 규칙).
- **KPI**: 숫자 `tabular-nums` 유지, 델타 배지 색(emerald/red) 유지하되 카드 자체를 브랜드화.
- **사이드바**: 그룹 라벨·활성 항목 하이라이트를 오렌지 점으로. 하단 UserButton 영역에 **플랜 배지** 노출.

## 3. 메뉴(IA) 재설계

**현재** Platform(3) + 리소스(5) + 요금제·문의(2). 리소스가 전부 web 외부링크라 대시보드 안에서 "할 일"이 빈약.

**개선안**
```
[상단] 워크스페이스 전환 (조직 optional이니 개인계정 표시)

── 워크스페이스 ──
  • 대시보드        /                (있음)
  • 새 측정         web/audit ↗       (있음, external)
  • 측정 이력       /history          (있음)
  • 경쟁사 비교 🔒  /compare          (신규·Pro) ← 새 기능
  • 추적 알림 🔒    /alerts           (신규·Pro) ← 새 기능

── 인사이트 ──
  • GEO 리포트      web ↗            (있음)
  • 벤치마크 리서치  web ↗            (있음)
  • 고객 사례       web ↗            (있음)

── 계정 ──
  • 요금제·업그레이드 /billing        (신규 in-app 요금제 표면)
  • 문의           web ↗            (있음)
```
- "시너지·블로그"는 인사이트 하위 or 제거(사용성 낮으면 정리). → 사용자 확인.
- 🔒 항목 = plan<pro면 잠금 배지. 클릭 시 업그레이드 표면.

## 4. 신규 기능 기획 (plan 게이팅과 함께)

CLAUDE.md: 새 API는 `app/api/[기능]/route.ts`, 기존 packages 우선. 아래는 **기획만**(구현은 승인 후).

### 4-1. 요금제·업그레이드 페이지 (`/billing`) — 우선순위 1
- **왜**: 지금 "요금제"가 web으로 튕겨 이탈. in-app에 현재 플랜 + 업그레이드 표면이 있어야 전환.
- **내용**: 현재 플랜 카드(내 plan 하이라이트) + 4단계 비교표(web pricing 재사용) + Free/approved면 "업그레이드" CTA(→ web/contact or 결제).
- **게이팅**: 없음(전원 접근). 단 현재 plan에 따라 "현재 이용 중" 표시.

### 4-2. 경쟁사 비교 (`/compare`) — Pro 잠금 — 우선순위 2
- **왜**: GEO의 핵심 질문 = "경쟁사 대비 내 브랜드가 AI에 얼마나 덜/더 인용되나".
- **내용**: 내 브랜드 + 경쟁사 도메인 최대 3개 SoV 나란히 비교(막대/레이더). 기존 AuditJob 데이터 재사용 가능하면 재사용, 없으면 "측정 필요" 안내.
- **게이팅**: free/approved = 잠금 화면(예시 블러 + "Pro에서 해제"). pro = 실데이터.

### 4-3. 추적 알림 (`/alerts`) — Pro 잠금 — 우선순위 3
- **왜**: 요금제 features에 "주간 자동 리포트·이메일 알림" 이미 약속됨. 그 관리 표면.
- **내용**: 추적 중인 프롬프트/브랜드 목록 + 알림 주기 설정. (실제 스케줄 발송은 백엔드 별도, 지금은 UI+설정 저장까지)
- **게이팅**: Pro만.

### 4-4. 대시보드 본문에 "업그레이드 사다리" 카드 — 우선순위 1
- free/approved 유저의 대시보드 하단에 "Pro면 이런 게 열려요" 카드(경쟁사 비교·자동추적·Export 미리보기). 강매 아니라 가치 노출.
