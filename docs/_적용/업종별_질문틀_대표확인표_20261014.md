# 업종별 질문 틀 — 대표 확인용 표 (2026-10-14)

> 질문을 자동으로 만들 때 업종마다 **무엇을 묻고, 무엇을 묻지 않는지** 정한 표입니다. 승인 전에는 푸시하지 않습니다.
> 공통 금지(모든 업종): AI 서비스 이름(ChatGPT·Claude·Gemini 등)이 들어간 질문 / 입력에 없는 회사·서비스 이름 / "~라고 했는데"처럼 들은 이야기를 전제로 까는 질문 / 브랜드 이름 뜻을 풀어 만든 질문.
> 경쟁사를 등록하지 않았으면 "다른 선택지" 질문은 AI가 아니라 아래 고정 문장을 씁니다.

## 이번 사고 6건이 어떻게 막히는지
| 사고 질문 | 막는 규칙 |
|---|---|
| "지메인이나 클로드 같은 AI 모델에서…" | AI 이름 사전(오타 포함) → 버림 |
| "센드버드나 인터콤 같은 …과 달리 …" | 입력에 없는 이름 → 버림, 경쟁사가 없으니 대안 질문은 고정 문장으로 대체 |
| "Findable은 어디서 사는 거야?" | B2B에서 구매처 질문 금지 → 버림 |

| "서울대 연구진 제품 있다고 했는데…" | 전제 깐 문장 금지 → 버림 |

## 한계 (솔직하게)
- 한국어에서 "입력에 없는 이름"을 완전히 가려내지는 못합니다. 모르면 버리는 쪽으로 판단해서 정상 질문이 일부 잘릴 수 있고, 그래서 모자라면 한 번 더 만듭니다(추가 AI 호출 1회).
- 브랜드 이름 뜻을 푼 질문은 "근거 표기"와 사이트 문구 대조로 대부분 거르지만 100%는 아닙니다. 마지막 방어선은 사람이 고르는 승인 단계(기본 미선택)입니다.
