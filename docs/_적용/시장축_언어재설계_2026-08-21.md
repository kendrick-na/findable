## 실측 — 언어축이 유효한가 (2026-08-21, 라이브 DB 701건)

### 1차 시도: 언급률로 비교 → 판별력 없음

| 도메인 | ko 언급률 | en 언급률 |
|---|---|---|
| sulwhasoo.com | 92% | 99% |
| apple.com | 97% | 100% |
| nvidia.com | 95% | 100% |

거의 모든 브랜드가 90%대로 비슷하다. **F11(recognitionRate 상수 100% 문제)과 같은 함정** —
"언급됐는가"는 유명 브랜드에겐 너무 쉬운 잣대라 시장 차이를 못 잡아낸다.

### 2차 시도: 감성·출처량으로 비교 → 뚜렷한 차이 확인

| 도메인 | ko 긍정율 | en 긍정율 | ko 출처평균 | en 출처평균 |
|---|---|---|---|---|
| sulwhasoo.com | 18% | 4% | 5.9 | 6.3 |
| apple.com | 24% | 8% | 3.6 | 1.5 |
| nvidia.com | 26% | 17% | 3.6 | 1.9 |
| innisfree.com | 38% | 6% | 3.5 | 2.4 |
| anua.com | 40% | 33% | 2.3 | **0.0** |
| themedicube.co.kr | 31% | 14% | 2.2 | **0.0** |

**결론: 언어축은 유효하다 — 단, "언급 여부"가 아니라 "감성·출처"로 봐야 차이가 드러난다.**
한국 브랜드는 한국어 질문에서 훨씬 긍정적으로 언급되고 근거도 풍부하다. 영어 질문에서는
존재감이 옅어지고(긍정율 급감) 일부는 근거 자체가 없다(출처 0). 이게 실제 "국내/해외 격차"다.

## 설계 — 무엇을 바꾸나

### 바뀌지 않는 것
- `runner.ts`의 F5 엔진 라우팅 로직 — 이미 정답이다. 안 건드림.
- `communityChannelHint()`(actions.ts) — `marketScope`를 "채널 처방" 목적으로 쓰는 건 정확하다. 안 건드림.
- DB 스키마(`Brand.marketScope` enum) — 값의 **의미**만 바꾸고 컬럼·타입은 유지.

### 바뀌는 것 — `market-scope.ts`의 분해 축

**기존(틀림)**: `engineRegion()` — 엔진의 "국적"으로 나눔. hyperclova·naver·daum=korea, 나머지=global.
→ "국내 중심" 선택 시 ChatGPT가 통째로 빠짐.

**신규(정답)**: 응답이 **어느 언어 질문에서 나왔는지**(`Prompt.language`, 이미 스키마에 있음)로 나눔.
→ "국내 중심" = 한국어 질문에 대한 7엔진 응답 전부(ChatGPT 포함).
→ "해외 중심" = 영어 질문에 대한 글로벌 4엔진 응답.

```ts
// market-scope.ts 변경 지점
// before: engineRegion(engineId) — 엔진 국적
// after:  promptLanguageRegion(promptLang) — 응답이 나온 질문 언어
export function promptLanguageRegion(lang: "ko" | "en"): MarketRegion {
  return lang === "ko" ? "korea" : "global";
}
```

`filterByRegion`·`filterByScope`가 받는 인자를 `{engineId}`에서 `{promptLang}`로 바꾼다
(`EngineResponse`에는 없지만 `TaggedEngineResponse`에는 이미 `promptLang`이 있다 — runner.ts:401-410).
새 데이터·마이그레이션 불필요, 필터링 키만 교체.

### 화면 — 무엇을 보여주나

1. **온보딩(`assign-brand-form.tsx`)**: 비활성 처리했던 Select를 복원. 단, 라벨을
   "국내 중심(한국어 질문 기준)"·"해외 중심(영어 질문 기준)"으로 — 엔진이 아니라
   언어가 기준임을 사용자에게도 명시한다(잘못된 기대를 만들지 않기 위해).
2. **결과 화면**: 통합 점수 옆에 "한국어 질문 기준"·"영어 질문 기준" 분해 점수를
   나란히 보여준다(F1/F3의 P2 제안 그대로). 지표는 언급률이 아니라 **감성·출처량**을
   우선 노출한다(실측으로 확인된 판별력 있는 지표).
3. **both(양쪽)**: 기존과 동일하게 유지, 라벨만 "국내·해외 함께"로.
