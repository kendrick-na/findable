### ⭐ shadcn/ui charts — 1순위
📕 [ui.shadcn.com/docs/components/chart](https://ui.shadcn.com/docs/components/chart)
- **Recharts v3** 기반. 컴포넌트: `ChartContainer` / `ChartTooltip` / `ChartLegend` + area·bar·line·pie/donut·radar·radial
- 🎯 **테마가 유일하게 1급 지원**: 색을 **CSS 변수**로 정의(`--chart-1`…`--chart-5`, **OKLCH**), `.dark` 클래스로 오버라이드, `var(--color-x)` 또는 Tailwind 임의 속성(`fill-(--color-desktop)`)으로 소비
- **npm 패키지가 아니라 CLI로 복사** → 코드를 우리가 소유(블랙박스 아님)
- 🔴 **약점**: 게이지·히트맵·스파크라인 템플릿 없음

### 🟡 게이지·히트맵 = 전 생태계 공백

## 6. 데이터비주얼 색 팔레트

### 🔴 다크모드 전용 자료 (가장 온토픽)
📕 **[Chameleon: Automated Color Palette Adaptation for Dark Mode Data Visualizations](https://arxiv.org/html/2512.00516v2)** (arXiv 학술)
라이트모드 차트 팔레트를 다크모드로 **자동 변환**하면서 지각적 차이와 의미적 색(빨강은 여전히 빨강)을 보존하는 알고리즘. **단순 반전이 왜 나쁜지**를 다룬 유일한 정면 자료

📕 **IBM Carbon 다크모드 규칙** — [v10 색 팔레트](https://v10.carbondesignsystem.com/data-visualization/color-palettes/)
> *"In light themes, **the darkest** color denotes the largest values. In dark themes, **the lightest** color denotes the largest values."*

## 7. 🇰🇷 한국어 웹 타이포그래피

### ⭐ Pretendard — 사실상 표준
📕 [github.com/orioncactus/pretendard](https://github.com/orioncactus/pretendard)
| 항목 | 값 |
|---|---|
| ★ | **~3.5k** (레포 페이지 직접 확인. 검색 스니펫의 463은 낡음) |
| 최신 | v1.3.9 |
| 라이선스 | **SIL OFL 1.1** — 상업 이용·수정·재배포 자유(폰트 파일 단독 판매만 금지) |
| 웨이트 | 정적 9종(Thin→Black) + **가변(`Pretendard Variable`, weight 축 45–920)** |
| 구성 | 한글=Source Han Sans/Noto Sans KR 기반, 라틴=**Inter**, 일부 일본어=M PLUS 1p |
| 유지보수 | 활발 |

🎯 **정부 채택(결정적 신호)**: **2024년 4월부터 한국 정부 공식 UI/UX 디자인 시스템(KRDS)이 `Pretendard GOV`를 기본 서체로 사용.**
→ 인디 폰트가 아니라 **한국 UI/대시보드 작업의 사실상 표준**

**Next.js 통합** (Google Fonts에 없으므로 `next/font/local`):
```ts
import localFont from 'next/font/local'
const pretendard = localFont({
  src: '../fonts/PretendardVariable.woff2',
  display: 'swap',
  weight: '45 920',        // 🔴 생략하면 WebKit/Safari가 잘못된 굵기 렌더
  variable: '--font-pretendard',
})
```
→ `--font-pretendard`를 Tailwind `fontFamily` 토큰에 바인딩하면 shadcn/ui와 바로 동작

**전달 방식**: 가변 폰트 1개 파일 권장(정적 전체는 큼). CDN 동적 서브셋(jsDelivr/cdnjs/unpkg)도 있으나, **Next.js+Vercel은 `next/font/local` 자체 호스팅이 표준**(preload/자체호스팅 최적화 이미 처리). 가변 woff2 1~2MB는 B2B 대시보드에 합리적 일회성 로드(마케팅 페이지가 아님)

**대안**: Noto Sans KR(구글, 커버리지 크나 무겁고 범용적) · SUIT(UI 우선, Source Han Sans 기반) · Wanted Sans(원티드랩, 기하학적, 7웨이트+가변) · ⚠️ Spoqa Han Sans(2022년 활동만 확인 → **레거시 취급**)

### 🔴 줄간격·자간 (한글 규칙)
| 항목 | 규칙 |
|---|---|
| **줄높이(본문)** | **~1.7 (170%)** — 라틴 관례 1.5보다 **넓게**. 이유: 한글/한자가 밀도 높고 정사각·전각이라 여유 부족시 답답하고 가독성 하락. **대시보드 작은 크기에서 특히** |
| 줄높이(조밀 표/그리드) | **1.4~1.5** 허용(CJK UI 밀도 관례) |
| 참고 | 한국 정부 KRDS: *"글자 크기의 1.5배 줄높이 권장"* |
| 🔴 **자간** | **한글에 라틴식 자간 조임(`tracking-tight`) 적용 금지** — 정사각 격자라 이미 시각적으로 조밀. 한글+라틴+숫자 혼용시 **한글은 기본값 유지**, 필요시 라틴/숫자 런에만 조정 |
| 🔴 **줄바꿈** | **`word-break: keep-all`** 필수 — MDN 확인 + **Mozilla bedrock이 한국어 로케일에 전역 적용**([이슈 #15450](https://github.com/mozilla/bedrock/issues/15450))해 리플로우시 음절 중간 분리 방지. ⚠️ **Tailwind v4 코어에 `break-keep` 유틸이 기본으로 없을 수 있음** → `@utility` 또는 임의값 `[word-break:keep-all]` 확인 |

**보조 도구**: [RichDeBourke/cjk-word-wrap](https://github.com/RichDeBourke/cjk-word-wrap) — CJK 단어를 span으로 감싸 잘못된 줄바꿈 방지(`keep-all` 보완)
**서브셋팅**: `fontTools`/`pyftsubset`(업계 표준) · [korsubset](https://github.com/SeokminHong/korsubset)(한국어 전용) · Google Fonts+Korean(~120 unicode-range 분할)
→ ⚠️ **우리 케이스는 서브셋팅 대체로 불필요**(가변 woff2 자체호스팅)

🔴 **한국어 전용 CSS 리셋/타이포 레포는 없음.** 한국어 전용 Tailwind 플러그인도 **없음** — **직접 쓰는 몇 줄의 CSS**(라이브러리 의존성 아님)

**토스 `es-hangul`** ([github.com/toss/es-hangul](https://github.com/toss/es-hangul), ~1.9k★, 활발) — 한글 **문자열** 처리(음절 분해/조립, **조사 을/를·이/가 받침 판별**, 초성 검색). 타이포/CSS 도구는 아니나, 한국어 검색·동적 라벨 생성에 유용

⚠️ **Geist Sans의 한글 커버리지는 별도 확인 필요** — 리서치에서 CJK 처리를 명시적으로 다룬 자료 없었음
