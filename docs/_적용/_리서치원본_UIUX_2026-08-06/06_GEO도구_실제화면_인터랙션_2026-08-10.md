## 9. 🔬 인터랙션 패턴 — 교차 결론

1. ⭐ **"숫자 → 근거 원문" drill-down 이 업계 표준이고 모달 2단 패널이 정답형**
   Semrush(완전 문서화) · Ahrefs(행 클릭 drillable) · Peec(`Recent Mentions` 전체 대화 맥락).
   → **신뢰는 점수가 아니라 점수를 만든 실제 응답을 즉시 열어보게 하는 데서 나온다.**
2. **필터 축이 4~6개로 수렴**(4개 도구 교차) — **Model(엔진)·Timeframe 은 전 도구 공통**, Topic/Tag 2순위
3. **같은 자리 지표 토글이 탭보다 선호** — Semrush `Mentions↔Cited Pages` · Peec `Domains↔URLs` ·
   Ahrefs `Relevance↔Search Volume`. **화면을 늘리지 않고 관점을 바꾼다**
4. 🔴 **필터/설정 영속성이 차별점** — **Profound 만 확인**(*"차트 배치와 필터가 다음 세션까지 유지"*).
   매일 같은 뷰를 보는 도구에서 **큰 리텐션 레버**
5. ⭐ **비용을 선택 시점에 노출** — Rankscale 크레딧 계산기.
   **우리 진단 원가 모델(150~300원)에 직접 이식 가능한 유일 사례**
6. **온보딩 = "AI 자동 제안 + 사용자 수락" 2단이 표준**(5개 도구).
   🔴 **빈 입력창을 주는 도구는 확인되지 않았다**

## 10. 🎨 비주얼 디자인 — 교차 결론

3. 🔴 **밀도가 곧 이탈 요인**(3개 도구 교차) — Otterly *"crowded·테이블 차트 과다"* ·

## 11. 🚶 유저플로우(온보딩 이후) — 교차 결론

1. 🔴 **Day 1 = "빈 대시보드 + 대기"라는 구조적 함정**

   경쟁 우위로 마케팅**됨. 최고 평가 근거로 인용된 반례:
   > *"온보딩 30초, **첫 로그인 30초 만에** 작동. 설정 후가 아니라 **첫 세션부터** 도구가 일한다"*
2. **Day 2~7 = 신선도 확인 루프.** Peec 의 **다음 갱신 카운트다운 타이머**가
   *"언제 다시 와야 하는지"* 를 UI 가 직접 알려주는 유일 사례. Otterly 사용자는 **주간 2~3시간** 검토
3. ⭐ **Day 30 = 대시보드가 아니라 "내보내기·보고"가 진짜 종착점**(강한 교차 신호)

   |---|---|
   | Profound | PDF + **최신 반영 공개 공유 링크** → ✅ 강점 명시 |
   | Peec | CSV 원클릭 → ✅ |
   | **Rankscale** | 리포트 생성 **없음** → 🔴 감점 |
   | **Otterly** | PDF **불가** → 🔴 감점 |
   | AthenaHQ | 협업 부재 → 🔴 감점 |
   → **"보고 가능성(shareability)"이 리텐션의 핵심**
4. **"숫자 → 행동" 전환은 여전히 업계 공백, 두 해법이 경쟁 중**
