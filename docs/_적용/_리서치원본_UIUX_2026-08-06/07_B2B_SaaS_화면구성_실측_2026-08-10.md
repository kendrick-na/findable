## 0. 🎯 Findable 3대 난제에 대한 직답 (먼저 읽을 것)

### ① 빈 대시보드 — "설명 벽" 대신
1. ⭐ **샘플을 실물로 렌더**(스티비 시드 + Plausible 라이브 데모).
   *"GEO 점수가 뭔지"* 를 설명하지 말고 **실제 브랜드 1건의 완성된 진단 결과**를 보여줄 것
2. ⭐ **Metabase 자기 소멸 원칙** — 사용자가 자기 진단을 1건이라도 저장하면 **샘플·안내가 자동 제거**
3. **Resend식 항목별 분해** — 진행 중일 때 통짜 스피너 대신 **엔진별/단계별 체크 상태**
4. 🔴 **Raycast 규칙** — **로딩 중에는 빈 상태를 절대 띄우지 않는다.**
   *"결과 0"* 과 *"아직 안 옴"* 은 **완전히 다른 화면**
5. ⭐ **June 식 분기** — 온보딩 첫 질문으로 *"측정할 브랜드가 있나요?"*
   (June 은 이걸로 **활성화 10%** 문제를 다뤘다)

### ② 잠긴 유료 기능 — 정직하게
- ⭐ **게이팅 축을 「기능」이 아니라 「시간·규모」로** (채널톡).
  진단 자체는 열고 **보관 기간·갱신 주기·엔진 수**로 나눈다.
  🎯 *기능 잠금은 "당했다"는 느낌을 주지만 **보관 기간은 그렇지 않다***
- **회색 처리 + 무엇이 열리는지 설명하되 클릭 경로를 막지 말 것**.
  맥락 내 **작은 카드**(Metabase), **전면 모달 금지**
- **한도 초과 시에도 수집은 계속**(Plausible) + **기존 데이터 열람 유지**(Notion) + **유예기간**
- **제한의 이유를 공개**(Clay)
- 🔴 **법적 요건은 §5 참조** — 이건 디자인 취향이 아니라 **시행 중인 법**이다

### ③ 나쁜 점수 — 절망시키지 않고 (ChartMogul + 스티비 **독립 일치**)
1. **"정해진 기준은 없다"를 먼저 선언**(스티비)
2. **절대값 → 상대 위치**(같은 업종·규모 비교군의 분위)
3. **수준과 방향을 분리** — *"낮지만 개선 중"* 과 *"낮고 악화 중"* 은 완전히 다른 이야기
4. **외부 요인 귀속 + 기회 언어** — *"room for growth"*, *"bucking the trend"*,
   *"market headwinds/tailwinds"*. **실패 서술 금지**
5. **모든 나쁜 숫자 옆에 처방 링크**(Resend `?` → 해결 문서)
6. ⭐ **자기 제한 문구 필수** — *"평균은 어디까지나 평균이기 때문에 참고만 하시길 바랍니다"*(스티비).
   **과신 방지가 오히려 신뢰를 만든다**
7. **Loops 식 지표 폐기** — 구조적으로 못 믿을 지표면 **제품이 먼저 선언하고** 갈아탄다

> 🔴 **중대 제약**: 벤치마크는 **표본이 실제로 있을 때만** 가능하다.
> 표본 없이 *"업계 3분위"* 를 표시하면 **숫자 조작**이다.
> **표본이 없으면 위 3·4번(방향·외부요인)만 쓰는 게 안전하다.**
> 색은 빨강 대신 **중립 표시**(기존 리서치 *"GSC 는 하락에 빨강 안 씀"* 과 일치).

## 10. 🔬 교차 결론

### 화면 구성
- **단일 페이지가 소비자향 분석의 지배적 선택**(Plausible·Fathom).
  사이드바는 **자산이 축적되는 제품**에서만 정당(Metabase·Notion·Attio)
- **행동 축과 탐색 축 분리**: Attio `cmd+k`(커맨드) vs `/`(검색), Height `cmd+k` vs `cmd+p`
- 🔴 **빈 섹션은 자리를 비우지 말고 렌더 자체를 생략**(Notion)
- **골격 고정 + 나머지 커스터마이즈**(Attio: Record Details·Lists 제거 불가)
- **섹션 순서**: 맥락 → 요약 지표 → 시간축 → 상위 N개 → 세그먼트(스티비 6단)
- 🔴 **큰 패딩 카드는 데이터가 쌓이면 무너진다**(Loops *"Limit scrolling"*)

### 인터랙션
- ⭐ 🔴 **로딩 중에는 빈 상태를 절대 표시하지 않는다**(Raycast API 강제)
- **빈 상태 4슬롯**: 아이콘 + 제목 + **왜 비었는지** + **행동 1개**. **설명 벽이 아님**
- **드릴다운은 모달이 아니라 필터 또는 전용 페이지** — **모달 중심 사례 0건**
  ⚠️ B트랙 Semrush 는 모달 2단 패널 → **용도가 다르다**(근거 원문 열람 vs 목록 탐색)
- **부분 실패 우선**: 엔진 1개 실패 시 **전면 실패 화면 금지**, 캐시/부분 결과 + 토스트
- **필터는 즉시 반영**(적용 버튼 없음)
- **랭킹이 곧 점진적 공개**: frecency·score 로 신규/파워유저 밀도 자동 분기
- 🔴 **모션 타이밍(ms)·이징은 전 제품 1차 출처 0건** — **인용 금지**

### 비주얼
- **색 예산은 극단적으로 좁다**: Raycast **9개**, Google Maps **700→25**
- 🔴 **색은 시맨틱 토큰으로만. 리터럴 hex 금지**(Metabase·Figma·Bezier **3곳 독립 일치**)
- **다크모드 = 반전이 아니라 역할 기반 토큰**. 라이트↔다크 **1:1 매핑 불가**를 명시
- **차트는 요소를 걷어낸다**: x축 레이블·y축 선·범례 제거, 시리즈 색을 **본문 텍스트에 밑줄로 연결**(Omni)
- **선 끝점의 점 = "지금 여기"** — 색으로 좋고 나쁨을 판정하지 않는 **중립 표시**
- **채도를 낮추는 것이 검증된 방향**(채널톡 *"피로감"*)
- ⚠️ 🔴 **Pretendard 실무 함정**(우리가 쓰는 폰트):
  기본 letter-spacing **약 -0.5px 내장** → **`tracking-tight` 추가 금지** /
  얇아서 **작은 regular 는 medium 으로 승격** /
  **숫자·영문 많은 화면에서 줄바꿈 유발**(대시보드가 정확히 이 조건)
- 🔴 **hex·spacing grid·radius·shadow 수치는 전 제품 미공개** — 실측 외 방법 없음

### 유저플로우/활성화
- **첫 데이터 연결 = 첫 가치 전달 시점**(Metabase 자동 탐색 제안)
- **활성화 3전략**: 시드 콘텐츠형(Notion·스티비) / 실작업형(Raycast Quickstart, 튜토리얼 오버레이 없음) /
  사람 코치형(Superhuman)
- ⭐ **가입 전 실데이터 라이브 데모가 최강 전환 장치**(Plausible·Baremetrics 자사 숫자 공개)
- **D2/D30 동력**: 비교·실시간·**벤치마크 월 1회 갱신**·frecency 학습에 따른 전환 비용 축적
- ⭐ **다크패턴 없는 페이월 5원칙**:
  ① **기존 무료 기능을 유료로 옮기지 않기** ② 사전 경고 ③ **기존 데이터를 인질로 잡지 않기**
  ④ 유예기간 ⑤ **과금 발생 업그레이드는 명시적 승인**
- **게이팅 축은 기능이 아니라 규모/시간**: 채널톡(보관 기간) · Attio(objects·records·credits) ·
  Clay(50행 — **제한의 이유까지 공개**)
