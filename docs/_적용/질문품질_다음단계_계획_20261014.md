# 질문 품질 다음 단계 계획 (2026-10-14 · 계획만, 구현 전 승인 필요)

근거: 경쟁 도구 리서치(Peec 질문 의도 태그 25/50/25, Peec 연구 "순위·목록·비교형이 브랜드를 더 띄움", 0신호 질문 자동삭제 기능은 확인 못 함, 사전 실행 검증은 업계 표준이 아님).

## 3. 사전 실행 검증 (질문을 추적 전에 미리 돌려 보기)
- **무엇:** 제안된 질문 중 고객이 담으려는 질문을 엔진 1곳에 1회 돌려, 답변에 브랜드가 몇 개 나열되는지 센다. 0개면 "브랜드가 안 나오는 질문" 표시(자동 삭제 아님, 고객이 결정).
- **왜 보수적으로:** 업계에 근거가 없는 기능이라 자동 탈락은 하지 않고 **표시**부터 한다. 답변은 매번 달라서 1회 결과로 단정하지 않는다("이번 1회 기준").
- **비용 추정(가정 포함):** 엔진 단가표(`engines/cost.ts`)로 계산 — 질문 1개 ≈ 웹검색 $0.01 + 토큰(입력 약 3천·출력 약 7백 가정) $0.018~0.02 → **질문당 약 ₩40**, 20개면 **약 ₩800**(chatgpt·claude 기준, 토큰 수는 가정이라 실측 필요). Gemini 무료 티어(일 1,500건)를 쓰면 거의 0원이지만 본 측정과 같은 한도를 나눠 쓴다. **권고: Gemini 1엔진, 질문은 고객이 고른 것만(최대 20).**
- **리스크:** 한도 소진 시 본 측정에 영향 → 일일 상한을 두고, 초과하면 사전 검증을 건너뛴다.
- **배포 시점:** 측정 엔진을 호출하는 새 경로라 영업 3곳 측정이 끝난 뒤.

## 2. 0신호 질문 분리 (화면 변경 · 승인 필요)
- 측정 결과에서 브랜드가 한 번도 안 나온 질문은 점수 계산에서 빼지 않고 **"참고용" 그룹**으로 따로 보여 준다(삭제 대신 기존 '보관' 기능 연결).
- 문구(안): "이 질문에서는 아직 어떤 브랜드도 답변에 나오지 않았어요. 점수에서 빼고 싶으면 보관할 수 있어요."

## 4. 점수 표시 (화면 변경 · 승인 필요)
- 절대 가시성 하나만 보여 주지 않고 **경쟁사 대비 순위·점유율 + 주간 추세 + 질문 유형별 분해**를 함께 보여 준다.
- 작은 브랜드는 낮은 점수가 정상일 수 있으므로(벤더 자료: 비브랜드 질문 평균 언급률 0.34% 등, 표본 불명) 첫 기준선을 저장해 **변화**로 진척을 보여 준다. 공개 벤치마크는 없어 수치 목표는 제시하지 않는다.
