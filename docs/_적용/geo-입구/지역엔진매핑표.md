## 2. 지역·검색 사용 열에 대해 (근거 없는 칸은 비움)

- **지역(어느 나라 화면·IP 에서 물었나)**: 코드에서 지역을 고정하는 곳은 `naver-briefing` 의 `location=KR` 요청 하나뿐이다 [확인]. 나머지 엔진은 호출 지역을 코드가 기록하지 않는다 → **[확인 필요]**.
- **웹 검색 사용 여부**: 엔진 이름만으로 정하지 않는다. 회차 행의 `engineSet`(`api-search-v1` 등)·출처 기록이 근거다. 사전 등록은 「웹 검색을 쓰는 엔진과 모델 지식 기반 엔진을 따로 판독」을 요구하므로, 효과 증명 판독 때 행 기록으로 분류한다(`19_사전등록_확정` 4절).
- **언어**: 표의 「코드상 언어」는 엔진 메타의 값일 뿐, 그 엔진이 한국어·영어 질문에서 실제로 쓰였는지는 회차 행의 `promptLang` 으로 본다. 언어가 다른 회차는 합치지 않는다(A1-a).

## 3. 이 표 밖의 것

- **Google AI Overviews(AIO)**: 엔진 id 가 아니다. AEO 레인 시범으로 따로 두며 점수·추세 분모에 섞지 않는다(`google-aio-adapter.ts` 머리 주석) [확인].
- 엔진 목록이 바뀌면(추가·종료) 이 표와 `ENGINES`·`DEFAULT_ENGINES` 를 같이 고친다.
