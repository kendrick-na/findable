# 설계안 — G6 오해 교정 (2026-10-16) · 상태: 설계만, **재측정(10/24) 이후 착수**

> 이유: 판정·측정 결과를 읽고 해석하는 기능이라 측정 동결(기준선→개선 후 재측정)이 끝나기 전에는 코드를 쓰지 않는다.

## 1. 한 문장
AI 답변이 우리 브랜드에 대해 **틀리게 말한 문장**을 찾아, 고객이 적어 둔 사실(「내 브랜드 정보」)과 견주고, **고칠 곳(출처)** 까지 안내한다.

## 2. 안 만들면 고객이 못 하는 것
"AI가 우리를 이상하게 말한다"는 걸 발견은 해도, **무엇이 틀렸고 어디를 고쳐야 하는지**를 한 화면에서 못 본다.

## 3. 재료는 이미 있다
| 재료 | 위치 |
|---|---|
| AI 답변 원문 | 측정 결과(AuditJob.result.engineResponses) |
| 답변에서 나열된 브랜드 이름 캐시 | AnswerBrand 테이블(운영 반영됨) |
| 고객이 확인한 사실 | BrandFactSheet(「내 브랜드 정보」, 운영 반영됨) |
| 사이트에서 읽은 상호·사업자번호 | 사이트 비교 기능 |

## 4. 1차 범위(작게)
1. 확인된 사실(한 줄 소개·운영 주체·제공 범위·상호) 중 **AI 답변이 정반대로 말하는 것**만 후보로 표시. 판단은 문자열 일치가 아니라 **사실 문장 1개 ↔ 답변 문장 1개를 나란히** 보여 주고 고객이 "맞다/틀리다"를 누른다(자동 판정으로 점수를 만들지 않음).
2. "틀리다"를 누르면 그 답변이 인용한 **출처 주소**를 보여 준다(있을 때만).
3. 새 점수·임계값 없음.

## 5. 안 할 것
- AI가 틀렸다고 **자동 판정**해 고객에게 단정하지 않는다(오탐 위험).
- 오해 교정을 자동 게시하지 않는다.
- 측정 로직·판정은 건드리지 않는다(읽기만).

## 6. 선행 조건
- 10/24 재측정 완료 → 측정 동결 해제 확인(관제탑).
- 고객 테스트에서 「내 브랜드 정보」를 실제로 채우는지 확인(채우지 않으면 비교할 사실이 없다).
- 승인: 화면 추가(새 화면 없이 「오늘」의 「먼저 살펴볼 질문」 안에 들어가는 것을 우선 검토).
