# 경쟁사 5곳 기능 전체 목록 + Findable 필요 여부 판단

실측 기준일 2026-08-21. `전체화면플로우지도_2026-08-21.md`(6개 제품 검증 완료본)를 근거로 경쟁사 5곳 각각의 기능을 빠짐없이 펼치고, 각 기능마다 Findable에 필요한지/이미 있는지/불필요한지와 사유를 판단했다.

**판단 기준 3가지** (이 중 하나라도 걸리면 "불필요"로 분류)
1. 여러 경쟁사 공통이 아니라 1곳뿐인 기능 → 대부분 불필요(업계 표준이 아닐 가능성)
2. Findable의 축(브랜드가 AI 답변에 얼마나 인용되는가)과 다른 기능(SEO 순위, 콘텐츠 생성, 서버 로그 연동 등) → 불필요
3. 1인 개발 체제로 유지보수 원가가 화면 하나보다 훨씬 큰 기능(멀티유저 권한, API 발급, 데이터소스 연동) → 보류/불필요

범례: 🟢 필요(만든다) · 🟡 검토(조건부/축소판) · ⚪ 불필요(스킵, 사유 명시)
