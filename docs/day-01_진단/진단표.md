## 1. 제품 진단 (누구의 어떤 문제)

| 항목 | 내용 |
|---|---|
| **대상** | 한국 시장을 노리는 B2B/서비스 기업의 마케팅·그로스 담당자 |
| **문제** | AI 검색(ChatGPT·Perplexity·Google AI 등)이 답변을 생성할 때 한국어 기업 정보가 거의 인용되지 않는다(메모리 기준 한국어 학습 비중 0.017%). 기존 SEO는 "검색 순위"를 다루지만 **AI 답변에 인용되는지(GEO/AEO)** 는 다루지 못한다. |
| **해결 명제** | Findable = 한국 최초 Agentic GEO 플랫폼. 내 브랜드가 AI 답변에 얼마나·어떻게 노출되는지 진단하고, 인용되도록 콘텐츠·구조를 개선한다. 랜딩 CTA "무료 진단 받기 (3분)" → `/audit`. |
| **왜 지금(Why Now)** | AI 검색이 구글 검색을 잠식하는 전환기 + 한국어 데이터 공백 → GEO 수요 태동기 (근거: 메모리 reference_geo_market_data). |

## 8. CLAUDE.md 효과 검증 — 전/후 비교 (A-01-O3, 2026-07-06)

동일 요청 **"사용자 프로필 컴포넌트 만들어줘"** 를 (A) 빈 폴더(규칙 없음) / (B) Findable 루트(CLAUDE.md 로드) 두 조건에서 실행해 계획을 비교. 각 조건은 독립 세션으로 실행.

| 항목 | 기준 없음 (baseline) | CLAUDE.md 있음 (Findable) | 차이 |
|---|---|---|---|
| **파일 위치** | 관례적 `src/components/UserProfile.tsx` (일반 Next.js 가정) | 모노레포 인식 → **인증된 `apps/app/components/`** (마케팅 web 아님) | ✅ 실제 구조·워크스페이스 격리 규칙 반영 |
| **타입 안정성** | 명시 타입 지향하나 "데이터 불명확하면 `any`로 넘어갈 수 있음" | **`any` 절대 금지, strict 유지** | ✅ any 허용 여지 → 완전 차단 |
| **서버/클라 경계** | 인터랙션 생기면 그때 `'use client'` 붙임 (임기응변) | 조회=서버, **입력부만 분리해 `'use client'`** (원칙적) | ✅ 서버 우선 원칙 명문화 |
| **보안 (service role)** | "요청 안 받으면 secret·service-role 신경 안 씀" | **Clerk 경유 + secret/NEXT_PUBLIC_/service_role 금지 능동 적용** | ✅ 보안 무관심 → 능동 방어 (가장 큰 차이) |
| **검증 명령** | typecheck/lint 언급 안 할 수 있음 | **check→tsc(오류 0 유지)→build + 패키지 설치 전 확인** | ✅ 검증 누락 → 강제 |

**결론: 5항목 모두에서 명확한 차이 발생.** 특히 보안(service_role)·타입(any)에서 baseline은 "신경 안 씀/넘어갈 수 있음"인데 CLAUDE.md 적용 시 능동 차단으로 바뀜. CLAUDE.md가 실제로 작동함을 확인.

> 실험 잔여물: baseline 폴더 `~/overedge-baseline`는 빈 채로 실험 종료(두 에이전트 모두 파일 미생성 — 계획만 비교). 정리 대상.
