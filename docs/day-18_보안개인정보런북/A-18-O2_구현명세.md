## 1. [P0·저위험·문서] D18-1·2 — 개인정보 처리방침 정합 정정

대상: `apps/web/app/[locale]/legal/[slug]/page.tsx` (privacy 객체 sections). **코드 로직 아님, 표시 텍스트만.**

### 정정 1 — §1 수집항목에 IP·접속기록 추가
```
현행: "무료 진단 신청 시 이메일 주소와 도메인 URL을 수집합니다. 유료 플랜 이용 시
      카드 결제 정보(토스페이먼츠 위탁), 결제 내역, 사용 로그를 수집합니다."

정정: "무료 진단 신청 시 이메일 주소와 도메인 URL을 수집합니다. 서비스 운영 과정에서
      접속 IP 주소와 접속 기록이 자동으로 수집·저장됩니다(부정 이용 방지 목적).
      유료 플랜 이용 시 결제 정보(결제대행사 위탁), 결제 내역, 사용 로그를 수집합니다."
```
- 근거: route.ts:146 IP 수집 실재. **자동수집 항목**임을 명시(사용자가 직접 입력 아님).

### 정정 2 — §2 이용목적에 부정이용 방지 추가
```
현행 (4) 뒤에 추가: "(5) 접속 IP·기록은 부정 이용 및 어뷰즈 방지, 서비스 안정성 확보 목적으로만 이용됩니다."
```

### 정정 3 — §3 보유기간에 IP 보존기간 명시
```
현행 뒤 추가: "접속 IP·접속 기록: 수집일로부터 6개월(부정 이용 방지 목적 달성 후 파기)."
```
- ✅ **[확인사실] 파기 로직 부재 확정** (2026-07-29 재검증): `ipAddress`는 route.ts:146·156 **수집만, null/삭제/파기 코드 0건**. cron 3개(keep-alive·daily-ops-digest·sweep-stuck-jobs) 중 IP·auditJob 파기 없음 → **현재 IP 무기한 보존 중**.
- ⚠️ **따라서 정정 3(6개월 문구)은 정정 4-B(파기 cron)와 반드시 세트.** 파기 로직 없이 방침에만 "6개월 파기"라 쓰면 방침이 또 거짓말 → BL-Day18-03을 같은 릴리스에 포함하거나, 파기 도입 전이면 문구를 "부정 이용 방지 목적 보관, 목적 달성 시 파기"(기간 미명시)로 완곡하게.

### 정정 4-A — 결제 위탁사 실명 정합 (§1·§4·약관 제4조)
```
✅ [확인사실] 실제 활성 PG = PortOne(포트원) V2 (2026-07-29 재검증):
- apps/web checkout+verify = @portone/browser-sdk/v2 · api.portone.io = 실사용자 결제 경로.
- Stripe = apps/api webhooks/payments 에만 존재(next-forge 잔재). apps/api 미배포 → 실동작 안 함.
- 결론: 방침엔 PortOne만 표기(Stripe 언급 불필요).

정정 문안:
- "카드 결제 정보(토스페이먼츠 위탁)" → "결제 정보는 결제대행사 포트원(PortOne)을 통해
  처리되며, 실제 카드 결제·정산은 포트원과 제휴한 카드사·PG사가 담당합니다."
- 약관 제4조 "토스페이먼츠 또는 PayPal" → "포트원(PortOne)을 통해 처리되며"로 정정.
```
- ⚠️ 남은 [확인필요](경미): PortOne↔실제 카드사 위탁 체인 상세(방침엔 "포트원 통해 처리"로 포괄 가능하므로 문안 확정에는 지장 없음).

### 런북 구조 (1페이지, 유형별 3열: 증상 / 원인 / 대응순서)

| 장애 유형 | 증상 | 대응 순서 |
|-----------|------|-----------|
| **배포 후 사이트 다운** | www 500/빌드깨짐 | ①Vercel Instant Rollback(직전 READY로) ②Sentry 확인 ③원인 커밋 revert |

## 3. [P2·중위험] D18-1 후속 — IP 자동 파기 (코드)

방침에 보존기간을 쓰면 **실제 파기 로직**도 있어야 정합(안 그러면 방침이 또 거짓말).
```
sweep-stuck-jobs cron(D17)에 IP 마스킹 스텝 합승 후보:
  auditJob 중 createdAt < 6개월 인 것의 ipAddress = null (updateMany, 멱등)
```
- 스키마 무변경(ipAddress 이미 nullable). cron 재활용. 🟡 방침 보존기간 확정 후.
