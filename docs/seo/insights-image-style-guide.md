# Findable Insights 대표 이미지 스타일 기준

인사이트 대표 이미지는 텍스트를 읽히게 만드는 카드가 아니라, 글의 주제를 시각적으로 보조하는 **절제된 편집형 인포그래픽**이다. SEO·Discover 정보는 HTML 제목·본문·alt·구조화 데이터로 전달한다.

이 문서는 최신 기준 자산 4개(`seo-geo-difference-cover.png`, `seo-geo-difference-cover-v1.png`, `ai-search-citation-conditions.webp`, `ai-search-citation-diagnostic.webp`)를 직접 대조해 정리한 것이다. 전체 대조 기록은 [`insights-image-style-audit-2026-09-04.md`](./insights-image-style-audit-2026-09-04.md)에 남긴다. 공통 스타일은 거친 한지 일러스트가 아니라, 아주 얕은 종이결 위에 검색·문서·출처·AI 결과·검수 흐름을 정돈된 평면 다이어그램으로 보여주는 편집형 인포그래픽이다.

## 고정 규칙

- 아주 미세한 종이 결만 보이는 따뜻한 한지 계열 아이보리 바탕. 한지 섬유감이 그림의 주제가 되거나 거칠게 보이면 반려
- 기존 자산과 같은 가로형 16:9, 기준 크기 1672×941
- 좌우 여백을 유지하면서 중앙에 핵심 검색/AI 결과 패널을 두는 편집 포스터 구성
- 검색창, 문서, 출처, 연결선, 결과 패널 등 **주제와 직접 연결된 3~7개의 평면 다이어그램 요소**
- 요소는 좌우 또는 방사형으로 정돈하되, 시선이 `검색/질문 → 근거/문서 → AI 답변/결과`로 흐르게 구성
- 검정·네이비·코럴·세이지의 제한된 색상
- 얇은 네이비·검정 외곽선, 낮은 채도의 코럴·세이지 강조, 낮은 그림자
- 검색창·문서·패널은 기존 자산처럼 평면적인 선화와 종이 레이어로 표현하고, 모바일 크롭에서도 중앙 핵심이 남도록 배치
- Findable 오렌지 `#ff7a4d`를 연결선·중심 포인트·결과 강조처럼 흐름을 읽게 하는 핵심 신호로 사용한다. 작은 장식 점 하나만 있거나 오렌지가 사라지면 반려한다.

## 반드시 지킬 것

- 이미지 안에 제목, 설명, URL, 브랜드명, 워터마크, 로고, 장식용 텍스트를 넣지 않는다.
- 이미지 생성 모델이 임의로 만든 글자·가짜 로고·깨진 한글이 없는지 확인한다.
- 이미지의 오브젝트와 아티클의 주제가 직접 연결되는지 확인한다.
- 다이어그램 안의 텍스트가 필요해 보이는 경우에도 글자를 생성하지 않고, 빈 줄·추상 블록·색상 마크로 대체한다.
- 기존 이미지와 나란히 놓았을 때 같은 시리즈로 보이는지 비교한다. 배경·선·색·질감·정보 밀도가 따로 놀면 반려한다.
- 대표 이미지 파일은 1,200px 이상, 16:9, 페이지 주제와 관련된 고해상도 파일을 사용한다.
- `alt`는 이미지 자체를 자연스럽게 설명하고 키워드를 반복하지 않는다.
- 생성 시안은 사용자 승인 전까지 게시물에 연결하지 않는다.

## 금지

- 순백색 또는 차가운 회색의 매끈한 배경
- 어두운 3D 테크 배경, 네온, 과한 글로우, 유광 렌더
- 의미 없는 카드·박스·칩·아이콘 나열. 단, 검색·문서·출처 흐름을 설명하는 기존 자산형 다이어그램 요소는 허용한다.
- 과도하게 큰 오브젝트, 좌우 여백이 없는 구성
- 텍스트를 이미지에 넣어 검색 노출을 노리는 구성
- 원본이 확인되지 않은 회사 로고나 AI가 만든 브랜드 마크
- 기존 인사이트와 무관한 일반적인 ‘AI 추상화’(큰 구형, 랜덤 연결 노드, 종이 더미만 있는 장면)
- 산·나무·식물·달·구름 등 주제와 무관한 장식적 풍경 요소
- 과하게 거친 한지 질감, 수묵화, 민화풍, 3D 제품 렌더, 유광 효과
