# Findable Medium 에디토리얼·배포 운영 기준

작성일: 2026-09-04  
적용 범위: Findable 공식 Medium 프로필(`@contact_22466`)의 초안, 게시글, 외부 배포 링크  
정본 기준: [Findable SEO·GEO 콘텐츠·검색 유통 마스터 기준](./FINDABLE_SEO_GEO_CONTENT_DISTRIBUTION_MASTER.md)

## 1. Medium의 역할

Medium은 Findable 인사이트의 복제본이나 검색 순위 조작 수단이 아니다. 다음 역할을 수행하는 **외부 에디토리얼 배포 채널**이다.

- 영어권 및 Medium 내 AI·SEO 독자에게 Findable의 문제의식과 방법론을 소개한다.
- Findable의 공개 인사이트, 리서치, 데이터셋으로 독자를 연결한다.
- 자체 사이트에서 이미 검증·공개한 원문을 바탕으로, 채널 독자에게 유용한 독립적 해설을 제공한다.

제품 설명, 공식 수치, 데이터셋, 방법론의 정본은 항상 `www.findable.co.kr`에 둔다. Medium 글은 정본 URL과 경쟁하거나 그 URL의 내용을 대량 복제하지 않는다.

## 2. 인사이트 원문 규칙과 달라지는 점

| 항목 | Findable 인사이트 | Medium |
|---|---|---|
| 목적 | 검색·AI가 인용할 수 있는 정본 콘텐츠 | 외부 독자 도달, 맥락 제공, 정본으로 유입 |
| 언어 | 국문·영문을 1:1 매핑 | 언어별 독자와 채널 맥락에 맞춘 별도 에디토리얼 허용 |
| 내용 | 방법론·수치·원문을 완결적으로 보관 | 핵심 근거를 요약하고 정본의 상세 방법론으로 연결 |
| 중복 | 같은 의도·구조의 새 URL 금지 | 사이트 원문을 그대로 복제하지 않으며, 새 관점·사례·해설을 추가 |
| CTA | 제품·가이드·관련 인사이트의 내부 흐름 | 과장 없는 단일 다음 행동: 원문 읽기, 데이터셋 보기, 감사 시작 |

다만 언어별 글이 같은 Findable 데이터나 수치를 인용할 때는 표본·기간·방법·한계를 동일하게 유지한다. 언어별로 사실을 바꾸거나 한 언어에만 새로운 성과 주장을 추가하지 않는다.

## 3. 발행 후보의 우선순위

Medium에 먼저 쓰는 글은 다음 중 하나를 만족해야 한다.

1. Findable의 공개 데이터·방법론·관찰을 외부 독자가 이해할 수 있게 해설한다.
2. 기존 Findable 인사이트의 질문을 다른 독자 문제나 실무 상황으로 확장한다.
3. 실제 운영 중 확인한 문제를 출처와 한계와 함께 설명한다.

다음 유형은 발행하지 않는다.

- 자체 사이트 글의 문단 순서와 결론을 거의 그대로 옮긴 글
- 키워드만 바꾼 GEO 정의·체크리스트의 반복본
- 출처 없는 성공 수치, 알고리즘 추측, AI 노출 보장
- 제품 기능만 나열하고 독자에게 새로운 판단 근거가 없는 글

## 4. 언어 운영

### 4.1 기본 원칙

- **영문**은 Medium의 국제 AI·SEO 독자에게 먼저 닿는 원문 에디토리얼로 사용한다.
- **국문**은 한국 브랜드 운영자, Naver·국내 AI 검색 맥락, 한글·영문 브랜드명 문제처럼 한국 독자에게 고유한 맥락이 있을 때 작성한다.
- 한 글 안에서 국문과 영문을 섞지 않는다.
- 자동 번역본을 그대로 재게시하지 않는다. 같은 데이터가 필요한 경우에도 제목, 사례, 도입 질문, 실행 맥락을 해당 언어 독자에게 맞게 사람이 편집한다.

### 4.2 사실 매핑 기록

국문과 영문이 한 주제 묶음이라면 아래를 내부 기록에 남긴다.

- 공통으로 인용한 Findable URL과 외부 1차 출처
- 공통 수치의 표본·기간·방법·한계
- 각 언어에서 달라진 독자 질문과 사례
- 서로 다른 제목·구조를 택한 이유

## 5. 원고 최소 기준

모든 Medium 원고는 다음을 충족한다.

- 제목은 구체적인 독자 질문이나 관찰을 말하고 클릭베이트가 아니다.
- 첫 2~3문장 안에 글의 직접 답변 또는 핵심 관찰이 있다.
- H2 성격의 소제목을 3개 이상 사용하고, 하나의 소제목은 하나의 주장만 다룬다.
- Findable 원문 링크 1개 이상과 외부 1차 출처 1개 이상을 포함한다.
- Findable 수치에는 측정일, 표본, 대상, 방법, 한계를 함께 적거나 정본 방법론으로 명확히 연결한다.
- 원문에 없는 경험·고객 사례·통계·인용을 만들어 내지 않는다.
- 마지막에는 독자에게 유용한 다음 자료 1~3개를 제시하며, 제품 가입 CTA는 관련성이 있을 때만 사용한다.
- 이미지는 선택 사항이다. 넣을 때에는 실제 주제와 연결되고, 원본 권리와 출처가 확인되어야 한다.

## 6. Findable 목소리와 안전한 주장

- `Findable의 측정에서는`, `공개 데이터셋의 범위에서는`처럼 관찰 주체와 범위를 밝힌다.
- `보장`, `반드시`, `알고리즘이 선호한다` 같은 단정 대신 근거·조건·예외를 함께 쓴다.
- SEO 노출, AI 언급, 인용, 전환은 서로 다른 지표로 구분한다.
- 고객 정보나 비공개 측정 결과는 고객의 명시적 승인 없이 쓰지 않는다.
- AI는 조사·초안 보조에만 사용하고, 사실·해석·톤·발행 적합성은 Findable 편집자가 검수한다.

## 7. Medium 편집·발행 체크리스트

### 초안 전

- [ ] 기존 Medium 글, Findable 인사이트, 리서치, 용어집과 주제·검색 의도·구조 중복을 확인했다.
- [ ] 외부 독자에게 제공할 새로운 관점 또는 해설을 한 문장으로 적었다.
- [ ] 원문 Findable URL과 외부 1차 출처를 정했다.
- [ ] 수치·사례의 공개 가능 여부와 측정 조건을 확인했다.

### Medium 편집

- [ ] 제목, 부제, 첫 문단이 같은 질문에 답한다.
- [ ] 소제목 3개 이상과 자연스러운 문단 구분이 있다.
- [ ] 제목·본문·태그가 과장 없이 일치한다.
- [ ] 링크는 정확한 국문 또는 영문 Findable 정본 URL을 가리킨다.
- [ ] 이미지는 텍스트·가짜 로고·권리 불명 요소 없이 주제와 연결된다.
- [ ] 사람 편집자가 사실, 수치, 링크, 톤을 검수했다.

### 발행 직전

- [ ] 배포용 글이며 자체 사이트 정본을 대체하지 않는지 확인했다.
- [ ] 외부에 공개해도 되는 정보만 포함했는지 확인했다.
- [ ] 공개 시점, 태그, 캡션, canonical 또는 원문 연결 방식을 확인했다.
- [ ] 발행 승인을 받은 뒤에만 Publish를 실행한다.

## 9. 현재 초안에 적용할 결정

- `AI Search Optimization: A 7-Step Brand Information Checklist`와 국문 체크리스트 초안은 본 기준 도입 전에 작성됐으므로 **발행 보류**다.
- 두 초안은 일반론 비중이 높고 외부 1차 출처·실제 측정 근거·소제목 편집이 부족하다.
- 향후에는 둘 중 하나를 정본 인사이트의 보조 해설로 재구성하거나, Findable의 공개 K-GEO-Bench 방법론을 중심으로 새로 작성한다.
- 이미지가 준비돼도 위 체크리스트와 사람 검수가 끝나기 전에는 발행하지 않는다.
