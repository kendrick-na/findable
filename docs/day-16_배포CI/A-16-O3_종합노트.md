## 4가지 실측 발견
- **D16-1**: `.github/workflows/`가 아예 없음. CI는 Vercel Git 자동배포에 위임돼 있음(push 감지→앱별 프로젝트 빌드·배포). → "GitHub Actions 도입"은 없는 문제 만들기에 가까움. 실질 gap = "머지 전 품질 게이트 부재".
- **D16-2**: cron = keep-alive 1개뿐(Neon 보온). 인증 패턴(CRON_SECRET Bearer / x-vercel-cron:1)은 stuck 스윕에 그대로 재사용 가능.
- **D16-3**: `skip-ci.js`는 품질 게이트가 아니라 `[skip ci]` 커밋 스킵 스위치. lint/tsc 실패는 안 잡음.
- **D16-4 (★가장 중요)**: crew route 함수 상한 = **300초**인데 crew-runner 내부 타임아웃 = **720초**. 함수가 먼저 죽으므로 runner 가드만으로는 stuck을 못 막음. → cron 스윕(사용자 조회 비의존)이 물리적으로 필요. Day14 P0의 정당성이 실측으로 확정됨.
