→ **"제품이 더 좋다"가 아니라 "다른 시장(한국)을 본다"에 가깝다.** 정직해야 함.

## 한국 경쟁사 대비: "최초"는 이미 3사가 다툼

GPTO·오픈타임·넥스트티 전부 "국내 최초 GEO"를 주장 → **마케팅적으로 무력**. GPTO는 이미 매출·고객·VC 다 앞섬.

## ✅ 살아있는 단 하나의 우위

> **네이버 AI Briefing 브랜드 가시성을 셀프서브로 주는 곳이 (네이버 포함) 아무도 없다.**
> 글로벌 툴은 네이버를 영원히 안 본다. 한국 에이전시(GPTO·오픈타임)는 서비스지 셀프서브 제품이 아니다.
> **이 공백 하나에 전부를 재정렬해야 한다.**

# PART 3. Findable이 필요한 이유 — 페인 (Q2 정직한 답)

## 판정: 현재 = Vitamin (얇은 painkiller 세그 존재)

**대부분의 한국 마케터는 아직 안 아프다.** 예산·KPI는 네이버광고·SEO·퍼포먼스가 지배. "AI가 우리를 틀리게 안다"는 아직 KPI로 안 잡힘.

**단 painkiller가 되는 얇은 세그 = Findable ICP와 겹침:**
1. **글로벌 진출 K-브랜드(K-뷰티·패션 D2C)** — 영문 AI가 미국 소비자에게 브랜드 누락 = **해외매출 직결**. (Profound 사례: Omnilux 매출 1%→3%)
2. **한국 진출 외국 브랜드** — 본사 보고용 "한국어 AI 가시성 KPI"를 만들 도구가 **0개**

## 대체재와 비교

| 지금 하는 것 | Findable이 나은가? |
|-------------|-------------------|
| **무시** (대다수) | ← **진짜 경쟁자.** 아직 남의 일 |
| 수작업(직접 ChatGPT 질문) | 무료·부정확. Findable이 나음 |
| 에이전시(GPTO 등) | ⚠️ 사람이 콘텐츠까지 뿌려줌 = 대표 입장엔 **더 완결적**. "측정만" 셀프서브가 오히려 불리 |
| 글로벌 툴 | 네이버 못 봄. 국내용엔 Findable |

## ★핵심 통찰

> 마케터가 자다 깨는 건 **"우리가 3등이래"(측정)가 아니라 "1등 만들어줘, 그게 매출이 되게"(결과)** 다.
> **측정만 팔면 vitamin, 결과를 팔면 painkiller.**
> GPTO가 처음부터 "콘텐츠 400채널 배포+순위상승"을 파는 이유가 이것.

# PART 4. 그래서 뭘 바꾸나 — 업데이트 기획 (Q3)

계획된 3레이어(측정→실행→데이터)는 **방향은 맞지만 순서·속도가 틀렸다.** "측정 먼저, 실행은 v1.5"는 vitamin 함정 직행.

## 재정렬된 우선순위

**P0 — 포지셔닝을 "GEO 측정"에서 "네이버 AI 가시성"으로 좁혀라** (지금, 코드 0)
- 유일한 방어 공백에 올인. + 🚨 Cue: 폐기, 추적대상=AI Briefing으로 문서 교체

**P1 — v1에 "결과"를 최소한이라도 넣어라 (vitamin→painkiller)**
- 주간 액션카드 1개(읽기전용 추천)를 v1 즉시
- **GA4 AI 리퍼럴 추적(F8)을 v1.5→v1로 당겨라** (AthenaHQ가 매출귀속으로 이기는 이유)

**P2 — 팩트정합률을 before/after 실측 케이스로**
- "메디큐브 75%"는 좋은 훅이나 **자기채점**. VC는 "그래서 100%로 올렸고 매출이 어떻게 변했나"를 물음. **한 브랜드라도 전후 케이스** 필요

**P3 — 데이터 해자를 "한국어 AI 가시성 표준 지수"로 외부화** (장기 유일 방어선)
- 400개 브랜드 데이터를 공개 지표/벤치마크로 표준화. GPTO가 서비스로 바쁠 때 Findable이 "데이터·표준" 선점

**P4 — COMPETITORS.md를 GPTO 정면 벤치마크로 재작성**

# PART 7. 🚨 적용 리뷰 — 코드 실체가 뒤집은 것 (적용 타당성)

**적용 리뷰가 실제 코드에서 발견 — 기획서 난이도 감각이 정반대였음:**

| 기능 | 기획서가 말한 것 | 실제 코드 | 교정 |
|------|----------------|-----------|------|
| 진실거울 | "3주 신규개발" | 🟢 **이미 8할 구현** (어댑터·gap 컴포넌트·크루) | UI 재조합만 |
| 네이버 실측 | "새 미끼" | 🟢 **이미 구현** (`naver-briefing-adapter.ts`) | "미끼" 아니라 **주력** |
| 엔티티 교정 배포 | "4에이전트 재활용, 중난이도" | 🔴 **미구현 + 최고위험** | 아래 |
| 귀속 픽셀 | "2위 big bet" | ⚠️ 이미 로드맵 F8 + PIPA 리스크 | 데모 후로 |

## ❌ 적용하면 독 (버릴 것)

1. **🔴 엔티티 교정의 "나무위키 직접 편집·배포"** — 나무위키는 대행편집을 **영구차단+문서삭제**로 처리, 광고성 은닉편집은 **표시광고법 위반**. "Findable=AI로 위키 조작하는 회사" 낙인 시 GEO 신뢰자산 붕괴.
   - **살릴 법**: 대상을 **브랜드가 소유·통제하는 소스로만 한정** (JSON-LD 스키마·자사 About/FAQ·구글 비즈니스 프로필·위키데이터 규범준수). 나무위키·타인 위키 쓰기 **제외**. → "조작"이 "정비"가 됨
2. **오프페이지 신호 오케스트레이션** — 같은 조작 리스크. 제외
3. **귀속 픽셀을 데모데이 스코프에** — PIPA(IP·리퍼러=개인정보) + 크롤러로그 접근. **데모 후 v1.5 F8로**
4. **벤치마크를 "완성 해자"로 데모** — N 작으면 역효과. "미리보기"만

## ✅ 적용하면 뭐가 좋아지나 (적용 효과)

# PART 8. 데모데이(10월)까지 실행 플랜

개인사업자·소수인원·10월 데모데이 제약. **이미 있는 자산 재조합만으로 임팩트:**

### 🥇 즉시 (1~3주, 현실적)
1. **진실거울 랜딩** — 이미 구현된 어댑터·gap 재조합. "ChatGPT는 2019년, Claude는 2021년, 둘 다 틀렸습니다" 3초 wow + 소유권 서사 카피
2. **포지셔닝 좁히기** — "GEO 측정"→"네이버 AI 가시성". 문서 Cue: 폐기

### 🥈 데모데이 전 (4~8주)
3. **팩트정합률 지표 전면화** + **before/after 케이스 1건**
4. **주간 액션카드 1개**(읽기전용) — 결과를 파는 최소 증거
5. 벤치마크 "미리보기" 1장 (N 정직하게)

### 🥉 데모데이 이후 (로드맵)
6. 엔티티 정비(자사 통제 소스 한정) / 귀속 픽셀(F8, PIPA 검토) / 데이터 표준 외부화

### ⚠️ 데모에서 하지 말 것
- 엔티티 "직접 배포" 시연 금지 → **"AI가 이렇게 고쳐야 한다고 진단합니다"까지가 안전선**
