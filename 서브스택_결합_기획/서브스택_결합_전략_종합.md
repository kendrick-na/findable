## ⚠️ 핵심 반전: "자동발행"에 대한 냉정한 진실
- Google "scaled content abuse" 2024 스팸 규정, 2026.3 코어업데이트 최우선 집행 → AI 대량 자동발행 트래픽 50~80%↓, 검색 제거
- 네이버 2026 제재 게시물 95%가 스팸/홍보성, AI 자동발행 5~8주 후 누락
- GEO 인용 최강 예측변수 = "고유 데이터·통계"(블로그 개수 아님). 무편집 대량발행은 GEO를 오히려 깎음
- ChatGPT 인용 47.9% 위키 / Perplexity 46.5% 레딧 / AIO 유튜브 → 자사 블로그는 조각, 오프페이지가 지배
- 자동발행·자동디자인은 Byword·Cuppa·AirOps가 이미 커모디티화

→ 정답: 풀오토 발행 X. **"GEO 레버 기반 반자동(인간 승인 게이트) + 오프페이지 신호 오케스트레이션"**

## 🏆 훔칠 것 랭킹
1. **관객 소유권 → "AI 노출은 빌린 것, 진짜 자산은 적립된다"** — SEO/광고=임대, GEO=복리 자산. "AI Presence 잔고" 위젯. 개발비 0, 세일즈 언어 전환. "어차피 알고리즘 바뀜" 반론 방어. (정직: "소유"보다 "적립 지분")
2. **공유되는 무료 AI 성적표 = 콜드스타트 flywheel** — "AI가 당신을 [틀린정보]로 답함" 공포 훅. 리포트가 영업사원. 30초 도메인 입력→리포트→이메일 캡처
3. **업종 벤치마크 데이터 flywheel** — 브랜드 상호추천은 경쟁상충으로 죽음 → 익명 집계 데이터로 우회. Findable만 여러 브랜드 실측 보유 = 복제불가 해자
4. **주간 가시성 리포트 이메일 = 리텐션 엔진** — GEO 약점("한번 진단하고 잊음")을 구독 습관으로
5. **Findable 자신이 "한국 GEO 주간 브리핑" 미디어** — 신생 카테고리는 교육하는 자가 소유

## 💰 BM 최종안 (실측 기반)
한국 GEO 대행 월 100~300만 vs 글로벌 SaaS 월 3~50만 = 6~20배 갭. 글로벌 툴 전부 진단만, 실행(발행) 아무도 안 함 = 공백
```
FREE    무료·5프롬프트·월1회·3엔진 → 바이럴 훅+이메일 캡처
GROWTH  월29만·50프롬프트·4엔진(+네이버)·경쟁추적·주간리포트 → 대행 진단 언번들
SCALE   월99만·200프롬프트·전엔진·API·⭐반자동발행(승인게이트)·CS → 대행 실행 흡수
```
- 1차 타겟: "대행 월200만 쓰다 아깝다 느끼는 중견·중소 인하우스 마케터"
- 자동발행 = 기능이 아니라 가격천장 3~6배 + churn lock-in 레버

## 🚀 실행 순서
