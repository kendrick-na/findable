## 1. "놀라운 AI 제품"의 공통 DNA 10패턴 (자로 쓸 기준)

2025~2026 히트작(Lovable·Cursor·Devin·Sierra·Harvey·Granola·Base44 등) 관통 패턴:

1. **Do, not Advise** — 측정/조언 넘어 결과물 완성 (★가장 강력)
2. **Time-to-Wow < 5분** — 가입·튜토리얼 없이 즉시 결과
3. **역대급 ARR 더블링** = 밸류 트리거 (성장 기울기에 베팅)
4. **Wedge 하나 깊게 → 인접 확장** (Land-and-Expand)
5. **유통이 제품력을 이긴다** (콜드스타트 채널 확보)
6. **자율성·병렬성 서사** (사람은 지시만)
7. **BYOK·오픈소스로 락인회피** (신뢰=채택)
8. **극단적 자본효율** (Base44 8명 흑자→$80M 엑싯)
9. **성과 ROI를 숫자로 증명** (Decagon CS 80%↓)
10. **멀티모델 오케스트레이션** (가치는 워크플로우 레이어로)

## 3. Findable 2.0 — 3-레이어 진화 구조

측정을 **버리는 게 아니라 미끼(get-in)로 강등**하고, 그 위에 죽지 않는 2개 레이어를 쌓는다.

```
┌─────────────────────────────────────────────────┐
│ LAYER 3. 데이터 해자 (MOAT)                       │
│  팩트정합 원장 + 한국어 AI 인용그래프 + 귀속 벤치마크  │
│  → 브랜드 많아질수록 복리. 카피 불가. 이관 불가       │
├─────────────────────────────────────────────────┤
│ LAYER 2. 실행 엔진 (수익·차별화) ★Do not Advise     │
│  엔티티 교정 에이전트(진단→초안완성→승인배포)          │
│  + 오프페이지 신호 오케스트레이션                     │
│  + AI답변→리드/구매 귀속 픽셀(ROI 증명)              │
├─────────────────────────────────────────────────┤
│ LAYER 1. 측정 (미끼·진입점) — 수익원 아님            │
│  ★네이버 AI 브리핑 실측(글로벌사 사각지대)            │
│  + 팩트정합률(순위 아닌 "정합"을 앞세워 비결정성 무기화)│
│  + "AI 브랜드 진실 거울"(3초 wow 첫화면)             │
└─────────────────────────────────────────────────┘
```

## 4. "이것만은" TOP 3 실행 (big bets 필터링 결과)

채점표 3기준(①자기잠식 방어 ②데이터해자 복리 ③3초 wow)으로 8개 big bet 필터링:

### 🥇 1위 — 엔티티 교정 에이전트 (진단→실행) | DNA #1,6,9
- **무엇**: AI 지식소스(위키데이터·스키마·나무위키·네이버 지식스니펫)를 직접 교정. CrewAI 4에이전트가 초안 완성→승인만 받으면 배포
- **왜**: 측정→실행 결정적 이동. Profound도 write 얕은 지금이 창. 한국어 소스 교정은 글로벌사 진입 불가 = 순수 해자
- **wow**: "고치기" → 2주 뒤 "ChatGPT가 이제 당신을 맞게 설명합니다" + 전후 비교 GIF
- **난이도**: 중~상 (4에이전트 재활용)

### 🥈 2위 — AI답변→리드/구매 귀속 픽셀 | DNA #9
- **무엇**: GA4가 놓치는 AI 유입(70.6% 오분류)을 크롤러로그·리퍼러 지문으로 복원. "이 매출은 ChatGPT에서 왔다"
- **왜**: GEO 아킬레스건(ROI 증명)을 뚫는 자가 시장을 키우고 먹음. 픽셀=지워지지 않는 락인
- **wow**: "지난주 Perplexity 답변이 리드 12건, 예상매출 340만원"
- **난이도**: 상 (MVP는 크롤러 로그 파싱부터. ⚠️PIPA 법무검토)

### 🥉 3위 — AI 브랜드 진실 거울 (첫화면 훅) | DNA #2
- **무엇**: 도메인 입력→3초→7개 AI가 지금 브랜드를 뭐라 아는지 원문 나란히. 틀린 사실 빨간 밑줄. 상단에 팩트정합률 %
- **왜**: 1·2위를 팔기 위한 문(門). 난이도 하, 2~3주. 기존 자산 재조합만으로 데모→계약 전환 즉시 상승
- **wow**: "ChatGPT는 당신을 2019년 설립이라 하고, Claude는 2021년. 둘 다 틀렸습니다"
- **난이도**: 하

> **실행 순서**: BET3(문, 3주) → BET1(심장, 교정) → BET2(ROI 증명). 그다음 GEO 코파일럿(접착제), 최종 API化(데이터 충분히 쌓인 뒤).
